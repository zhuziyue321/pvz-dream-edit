## 1. 机制口径与数据来源

血月是 **DLC 版（《Plants vs. Zombies: DLC Edition》）第 6 章「月夜屋顶（Moon）」** 的关卡级
gimmick；Halloween 活动关（Sanguine Sanctuary / Hemophilia / Monster Mash）把同一套借用到
**Night** 上，所以它**不是 Moon 专属**（本仓把开关放在场景层，见 §2）。

> 来源：<https://pvz-dlc-edition.fandom.com/wiki/Moon>
> "Between or during each flag, the Blood Moon event occurs, giving zombies a **significant
> boost in speed**, making the area slightly more difficult."
> 该章五项难点 = 无天降阳光、屋顶斜面、必须花盆、蹦极投人、**血月**。

**触发节奏**（波次口径见 `ZombieWaveManager`：每 10 波一面旗，旗帜波下标 `%10==9`）：

| wiki 措辞 | 落在第几波 | 本仓判据 |
| --- | --- | --- |
| "during each flag" | 旗帜波 9 / 19 / 29 | `wave % 10 == 9` |
| "between each flag" | 两旗正中间 4 / 14 / 24 | `wave % 10 == 4` |
| 合起来 | **每 5 波一次**：4 / 9 / 14 / 19 … | `(wave + 1) % 5 == 0`（`BloodMoonManager.is_blood_moon_wave`） |

**常驻形态**：活动关 Hemophilia <https://pvz-dlc-edition.fandom.com/wiki/Hemophilia>
是 Last Stand 关 + "**permanent Blood Moon effect**" —— 开战即挂上、整关不退
（`is_blood_moon_permanent`，不走 15 秒计时器）。

落在本仓库的取舍（**维基没给数值，以下为自定，改常量即可调**）：

| 项 | 取值 | 出处 |
| --- | --- | --- |
| 触发时机 | 每 5 波一次（旗帜波 + 两旗正中间交替） | 维基「between or during each flag」 |
| 持续 | 15 秒（常驻形态不计时） | 自定 |
| 移速 | ×2.0 | 自定（与「僵尸快跑」关 `speed_factor_zombie = 2` 同档） |
| 影响范围 | 移速 + **啃食 + 动画**一起变急 | 走 `signal_update_speed`，三条通道都连着它（见 §2） |
| 表现 | 全屏红屏渐入渐出 + 血月音效 + 期间换环境曲（无专属底图的场景另把底图染红） | 按 DLC 素材推断（见 §4） |

## 2. 实现

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 开关 | `SceneSettingBase.is_blood_moon` / `is_blood_moon_permanent` / `is_blood_moon_bg_art` → 同名字段进 `ResourceLevelData` | **场景**带出来（`scene_moon_roof.gd` 给 `is_blood_moon` + `is_blood_moon_bg_art`），关卡可自己覆盖；`apply_scene_setting()` 里同步 |
| 编排 | `src/managers/blood_moon_manager.gd`（`BloodMoonManager extends MainGameSubManager`） | 由 `MainGameManager.init_main_game_sub_managers()` new 出来、`init_manager()` 里初始化；开关关着时一行订阅都不做 |
| 触发 | `ZombieWaveManager.wave_started` | **每 5 波一次**（`is_blood_moon_wave`，见 §1）；常驻形态则每波都确认一次（开战即挂上） |
| 加速 | `Character000Base.update_speed_factor(值, E_Influence_Speed_Factor.BloodMoon)` | 走**乘积**通道，只写「血月」这一档；`signal_update_speed` 同时驱动**移动**（MoveComponent）/ **啃食**（AttackComponent）/ **动画**（AnimComponent），所以僵尸是整体变急 |
| 新僵尸 | `ZombieManager.zombie_created` 信号 | 血月期间才进场的僵尸靠它补加速（在场那批由 `start_blood_moon()` 当场刷一遍） |
| 光照豁免 | `Character000Base.illuminated_layers` / `is_illuminated` + `clear_speed_factor()` | **光域里的僵尸不吃血月加速**，已挂上的由光照蘑菇清掉（见 §2.1） |
| 红屏 | `EventBus` `CANVAS_LAYER_EFFECT_FADE` → `canvas_layer_effect.gd` | 常驻型染色（`alpha` 传 0 就是淡出）；`Panel_BloodMoon` 挂在 `main_game_base.tscn` 的 `CanvasLayerEffect` 下（layer 30），**所有场景**都有这一层 |
| 场景换图 | `EventBus` `BLOOD_MOON_VISUAL` → `src/world/background/main_game_bg_moonroof.gd` | 血月期间把**底图 + 房门遮罩**换成 DLC 的「血月」那套，结束换回「月夜」那套（见下）；只有配了 `is_blood_moon_bg_art` 的场景听这一条 |
| 底图染红（退化） | `BloodMoonManager._tint_background()` | 没有专属血月底图的场景（把 gimmick 借用到 Night 上）把底图乘一层红（`BG_TINT`），结束还原白色 |
| 音源 | `SoundManager.SFXOtherMap` | `bloodmoon_rise` / `bloodmoon_tension` / `bloodmoon_fall` / `bloodmoon` |

**月夜屋顶有两套底图，平时那套不能拿错**（DLC 的 id 见 `_unpacked/properties/resources.xml`）：

|        | 底图                                                   | 房门遮罩                                                          |
| ------ | ------------------------------------------------------ | ----------------------------------------------------------------- |
| 常驻   | `BACKGROUND6BOSS` = `background6boss.jpg`（深蓝月夜）  | `BACKGROUND6_GAMEOVER_MASK` = `background6_gameover_mask.png`      |
| 血月   | `BACKGROUND_BLOODMOON` = `background6moon.png`（紫红） | `BACKGROUND_BLOODMOON_GAMEOVER_MASK` = `background6moon_gameover_mask.png` |

⚠️ 移植时踩过：把血月那幅（`background6moon.png`，紫红夜空）直接登记成 `GameBg.MoonRoof` 的
常驻底图 —— 玩家一进关就是紫红一片，**视觉上像是血月已经开了**（血月其实要等旗帜波）。
现在常驻是月夜那幅，血月时才由 `BLOOD_MOON_VISUAL` 换图，血月这才真的「有来有去」。

**与 DLC 模组血橙的关系**：血橙那株植物（[`mods_builtin/dlc/bloodorange`](../../../mods_builtin/dlc/bloodorange)）
现在写的是**自己的档** `E_Influence_Speed_Factor.BloodOrange`（血月事件用 `BloodMoon`）。
~~两者曾共用 `BloodMoon` 一档~~ —— 共用时一方的计时结束把档设回 1.0 会顺带清掉另一方给的加速，
已分开：给血橙新开一档，两边的计时互不可见、互不清除。
**两者的关系**：wiki 说血橙给幸存僵尸的是**同一套** Blood Moon effect（Blood Orange 页
"Any zombies that survive the explosion receive the Blood Moon effect"），所以光照蘑菇清 buff 时
**两档一起清**（见 §2.1）。

### 2.1 光照清除增益（DLC 的 Lume-shroom）

> 来源：<https://pvz-dlc-edition.fandom.com/wiki/Lume-shroom>
> "all zombies within their range **lose all of their buffs** and drop small sun upon defeat"
> `special = Removes the Blood Moon and other buffs from zombies`

拆成两半，本体与模组各拿一半、互不认识：

| 半边 | 谁做 | 怎么做 |
| --- | --- | --- |
| **不再上**增益 | 本体 `blood_moon_manager.gd` | `_apply_speed()` 跳过 `zombie.is_illuminated` 的僵尸 |
| **清掉已挂上的** | 模组 `glowshroom_plant.gd` | 进光域时 `zombie.clear_speed_factor(BloodMoon / BloodOrange)` |

状态载体放基类 `Character000Base.illuminated_layers`（`is_illuminated` 是它的只读视图）：
光照蘑菇进出光域 / 睡着 / 自己消失时 `add_illuminated_layer()` / `remove_illuminated_layer()`
成对调用；**少摘一层那只僵尸就永久免疫血月**，所以光照蘑菇还连了 `tree_exiting` 兜底摘干净。

⚠️ **范围口径**：wiki 的信息框写 `range = 5x5`，图鉴却写 "all zombies in a huge area" —— 两处
冲突，**本仓取 5x5**（判定框 5 列 × 76 px = 380、5 行 × 85 px = 425，即 5×5 格；一株只保护
自己周围，不再「一株即全场免疫血月」）。改它只动 `plant_glowshroom.tscn` 的
`RectangleShape2D_glowshroom` 一处；可见的那圈光是路灯花同款的
`LanternShine.png`（按原版 `LanternShine.xml` 当**粒子**撒，自转 + 闪烁，发射盒半边距
170×190），**改判定框要同步改它的发射盒**，让玩家看见被照亮的那块就是真正起作用的那块
（蘑菇帽上那团小呼吸光是动画自带的 `GlowShroom_BigGlow`，只跟着动画亮 / 灭，
不参与判定，别拿它当光域）。

## 3. 可调常量（`blood_moon_manager.gd`）

```
SPEED_FACTOR  = 2.0          ## 血月期间全场僵尸移速倍率
DURATION      = 15.0         ## 一次血月持续秒数（常驻形态不走计时器）
FADE_TIME     = 1.5          ## 红屏渐入 / 渐出秒数
MAX_ALPHA     = 0.3          ## 红屏最浓时的 alpha（再高就看不见场面了）
FLAG_INTERVAL = 10           ## 每几波一面旗（与 ZombieWaveManager 的 %10==9 同口径）
WAVE_INTERVAL = FLAG_INTERVAL / 2  ## 血月每几波一次（5 = 旗帜波 + 两旗正中间交替）
BG_TINT       = Color(1.0, 0.72, 0.72)  ## 无专属底图场景的退化表现：底图染红
```

计时器用 `get_tree().create_timer(DURATION, false)`：`process_always = false`，**暂停时血月跟着停**。

## 4. 音源对应（按素材命名推断，DLC 未给官方文档）

| 文件 | 时长 | 用在 |
| --- | --- | --- |
| `bloodmoon_rise.ogg` | 6.75s | 事件开始：血月升起 |

## 5. 验证

```powershell
# 血月：场景开关 + 波次表 + 音源 + 实机（加速 / 新僵尸 / 红屏 / 还原）
#      + 光照清增益 + 常驻形态 + 无专属底图时的底图染红
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_blood_moon
# 月夜屋顶地图（血月的宿主场景）
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_moonroof_map
```

> ⚠️ `run_autopilot.ps1` 检测到已有 Godot 进程会直接 `STALE_PROCESS` 退出 —— 跑之前先关编辑器。

**人工肉眼验收**：调试窗口（Ctrl+Q，需先开控制台「调试 → 调试模式」）常用页有「触发血月」按钮，
按一下 → 全场僵尸明显变快（走路 / 啃食 / 动画一起急）、画面泛红、音乐换成血月环境曲，
15 秒后自动还原（再按一次可提前结束）。

- **周期性触发**：打一张 Moon 场景的关（现成演示关 `mods_builtin/dlc/levels/moon_roof_demo/`，
  主菜单 → 自制关卡）→ 第 5 / 10 / 15 / 20 波前各起一次血月（波次号 4 / 9 / 14 / 19）。
- **常驻形态**：关卡脚本里写 `is_blood_moon_permanent = true` → 一开战就是血月且整关不退。
- **光照清除**：在血月里种一株光照蘑菇（DLC 模组）→ 光域里的僵尸立刻恢复正常速度，
  铲掉 / 等它自走后血月加速重新生效。
