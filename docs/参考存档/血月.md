## 1. 机制口径与数据来源

血月是 **DLC 版（《Plants vs. Zombies: DLC Edition》）第 6 章「月夜屋顶（Moon）」** 的旗间事件。

> 来源：<https://pvz-dlc-edition.fandom.com/wiki/Moon>
> "Between or during each flag, the Blood Moon event occurs, giving zombies a **significant
> boost in speed**, making the area slightly more difficult."
> 该章五项难点 = 无天降阳光、屋顶斜面、必须花盆、蹦极投人、**血月**。

落在本仓库的取舍（**维基没给数值，以下为自定，改常量即可调**）：

| 项 | 取值 | 出处 |
| --- | --- | --- |
| 触发时机 | **旗帜波**开起来时（`wave % 10 == 9`，含最终波） | 维基「between or during each flag」 |
| 持续 | 15 秒 | 自定 |
| 移速 | ×2.0 | 自定（与「僵尸快跑」关 `speed_factor_zombie = 2` 同档） |
| 表现 | 全屏红屏渐入渐出 + 血月音效 + 期间换环境曲 | 按 DLC 素材推断（见 §4） |

## 2. 实现

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 开关 | `SceneSettingBase.is_blood_moon` → `ResourceLevelData.is_blood_moon` | **场景**带出来（`scene_moon_roof.gd` 给 true），关卡可自己覆盖；`apply_scene_setting()` 里同步 |
| 编排 | `src/managers/blood_moon_manager.gd`（`BloodMoonManager extends MainGameSubManager`） | 由 `MainGameManager.init_main_game_sub_managers()` new 出来、`init_manager()` 里初始化；开关关着时一行订阅都不做 |
| 触发 | `ZombieWaveManager.wave_started` | 只认旗帜波 |
| 加速 | `Character000Base.update_speed_factor(值, E_Influence_Speed_Factor.BloodMoon)` | 走**乘积**通道，只写「血月」这一档；`signal_update_speed` 同时驱动移动 / 啃食 / 动画，所以僵尸是整体变急 |
| 新僵尸 | `ZombieManager.zombie_created` 信号 | 血月期间才进场的僵尸靠它补加速（在场那批由 `start_blood_moon()` 当场刷一遍） |
| 红屏 | `EventBus` `CANVAS_LAYER_EFFECT_FADE` → `canvas_layer_effect.gd` | 常驻型染色（`alpha` 传 0 就是淡出）；`Panel_BloodMoon` 挂在 `main_game_base.tscn` 的 `CanvasLayerEffect` 下（layer 30） |
| 音源 | `SoundManager.SFXOtherMap` | `bloodmoon_rise` / `bloodmoon_tension` / `bloodmoon_fall` / `bloodmoon` |

**与 DLC 模组血橙的关系**：血橙那株植物（[`mods_builtin/dlc/bloodorange`](../../../mods_builtin/dlc/bloodorange)）
写的是**同一档** `E_Influence_Speed_Factor.BloodMoon`（「没被这一炸炸死的僵尸被血月加速一段时间」）。
两者共用一档：一方的计时结束把这一档设回 1.0 时，会顺带清掉另一方给的加速 —— 已知的小边界，
真要分开就给血月事件新开一档枚举。

## 3. 可调常量（`blood_moon_manager.gd`）

```
SPEED_FACTOR = 2.0    ## 血月期间全场僵尸移速倍率
DURATION     = 15.0   ## 一次血月持续秒数
FADE_TIME    = 1.5    ## 红屏渐入 / 渐出秒数
MAX_ALPHA    = 0.3    ## 红屏最浓时的 alpha（再高就看不见场面了）
```

计时器用 `get_tree().create_timer(DURATION, false)`：`process_always = false`，**暂停时血月跟着停**。

## 4. 音源对应（按素材命名推断，DLC 未给官方文档）

时长用 ogg 的 granule 位算出来，据此判断用途：

| 文件 | 时长 | 用在 |
| --- | --- | --- |
| `bloodmoon_rise.ogg` | 6.75s | 事件开始：血月升起 |
| `bloodmoon_tension.ogg` | 1.41s | 加速生效的一瞬间（短 stinger） |
| `bloodmoon.ogg` | 10.71s | 事件期间的环境曲（`loop = true` 后当 BGM 播，结束恢复本关曲） |
| `bloodmoon_fall.ogg` | 2.72s | 事件结束：血月落下 |

## 5. 验证

```powershell
# 血月：场景开关 + 音源 + 实机起一次血月（加速 / 新僵尸 / 红屏 / 还原）
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_blood_moon
# 月夜屋顶地图（血月的宿主场景）
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_moonroof_map
```

**人工肉眼验收**：调试窗口（Ctrl+Q，需先开控制台「调试 → 调试模式」）常用页有「触发血月」按钮，
按一下 → 全场僵尸明显变快、画面泛红、音乐换成血月环境曲，15 秒后自动还原（再按一次可提前结束）。
