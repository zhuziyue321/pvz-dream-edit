## 2. 怎么用

- **改代码前查机制**：按 §1 取对应的一份，不需要全读 —— 这里都是参考，读错不会挨打回。
- **文件名即主题**：新增参考文档时**不加任何前缀**（不用 `参考_xxx.md`），本目录名已经说明「这是参考」。
- **同一件事只写一处**：某个机制升级为硬约束时，正文写进 [../项目规范.md](../项目规范.md) §1，并从本目录对应文档里摘掉重复断言。
- **与其它文档冲突**：以代码现状与 [../项目规范.md](../项目规范.md) 为准，并在对应文档顶部标 `> **已过时**：<失效原因 + 替代做法>`。
