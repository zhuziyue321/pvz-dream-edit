# 场景设置 —— 一个场景一份脚本

## 1. 为什么

同一类关卡（浓雾 4-1 ~ 4-10、生存浓雾 ×3、种子雨……）要把同一串开关抄一遍：

```gdscript
game_sences = MainSceneRegistry.MainScenes.MainGameBack
game_BG = ConstLevelData.GameBg.Fog
game_BGM = ConstLevelData.GameBGM.Fog
is_fog = true
is_day = false
is_day_sun = false
```

这些值**由场景决定、不由关卡决定**，写 13 遍就有 13 个漂移点。  
现在的口径是：**关卡只认「场景的名字」，具体信息问场景脚本要。**

## 2. 三层结构

| 层 | 位置 | 内容 |
| --- | --- | --- |
| 场景名 | `ResourceLevelData.scene_name`（取值 = `SceneSettingRegistry.SCENE_*` 常量） | 关卡说「我是哪个场景」 |
| 场景脚本 | `src/world/scene/scene_*.gd`（`SceneSettingBase` 子类，一个场景一份） | 这个场景的具体信息 |
| 注册表 | `src/world/scene/scene_setting_registry.gd` | 场景名 → 场景脚本（延迟 `load`，避免循环依赖） |

场景脚本给出的字段（见 `SceneSettingBase`）：

| 字段 | 含义 |
| --- | --- |
| `display_name` | 场景名（日志 / 备注） |
| `game_sences` | 主游戏场景槽位（前院 / 泳池 / 屋顶） |
| `game_BG` | 底图 |
| `game_BGM` | 背景音乐 |
| `is_fog` | 是否有雾 |
| `is_day` | 是否白天（false = 夜晚，蘑菇不睡觉） |
| `is_day_sun` | 是否有天降阳光 |

**不在场景里的东西**：雨 / 闪电（`is_rain` / `is_lightning`）是**关卡级**天气开关（原版只有冒险 4-10 是雷雨夜，种子雨只下雨不打雷），关卡自己写；  
背景子场景 / 动画的装配仍归地图数据（`ResourceMapData.map_bg_scene` / `map_bg_script`），场景脚本只给数据、不建节点。

已登记的 6 个场景（对应 `ConstLevelData.GameBg` 的 6 个值）：

| 场景名 | 脚本 | 槽位 / 底图 / BGM | 昼夜 |
| --- | --- | --- | --- |
| `SCENE_FRONT_DAY` | `scene_front_day.gd` | Front / FrontDay / FrontDay | 白天 + 掉阳光 |
| `SCENE_FRONT_NIGHT` | `scene_front_night.gd` | Front / FrontNight / FrontNight | 夜晚 + 不掉阳光 |
| `SCENE_POOL` | `scene_pool.gd` | Back / Pool / Pool | 白天 + 掉阳光 |
| `SCENE_FOG` | `scene_fog.gd` | Back / Fog / Fog | 夜晚 + 不掉阳光 + 有雾 |
| `SCENE_ROOF` | `scene_roof.gd` | Roof / Roof / Roof | 白天 + 掉阳光 |
| `SCENE_BOSS` | `scene_boss.gd` | Roof / Boss / Boss | 夜晚 + 不掉阳光 |

## 3. 关卡怎么用（含覆盖工具）

`scene_name` **在赋值那一刻就套用**（setter 调 `apply_scene_setting()`），
所以**写在它后面的同名字段就是覆盖** —— 这是关卡改场景设置的主要工具：

```gdscript
func _init() -> void:
	## 场景：泳池·浓雾
	scene_name = SceneSettingRegistry.SCENE_FOG


func _init() -> void:
	## 场景：前院·白天，但原版 1-5 播小游戏曲 Loonboon 且没有天降阳光
	scene_name = SceneSettingRegistry.SCENE_FRONT_DAY
	game_BGM = ConstLevelData.GameBGM.MiniGame
	is_day_sun = false
```

覆盖项多 / 要按运行时条件改时，覆写 `apply_scene_setting()`：

```gdscript
func apply_scene_setting() -> void:
	super.apply_scene_setting()
	game_BGM = ConstLevelData.GameBGM.NoBGM
```

`scene_name` 留空 = 不套用场景设置，各字段照旧自己写 —— **老关卡 / 自制关一个字都不用改**，
迁移可以逐关进行（目前已迁：冒险 4-1~4-4 / 4-6~4-10、生存浓雾 ×3、迷你游戏 04 种子雨、冒险 1-5）。

## 4. 加一个新场景

1. `src/world/scene/` 下新建 `scene_xxx.gd`（`extends SceneSettingBase`，`_init()` 里写具体信息）；
2. 在 `SceneSettingRegistry` 加一个 `SCENE_XXX` 常量并在 `SCENE_SCRIPT_PATHS` 登记路径；
3. 关卡写 `scene_name = SceneSettingRegistry.SCENE_XXX`。

## 5. 踩坑

1. **覆盖必须写在 `scene_name` 之后** —— 场景是「赋值即套用」，写在前面的同名字段会被场景值盖掉。
   → **正解**：`scene_name` 放在 `_init()` 里这一组字段的第一行。
2. **新建的 `class_name` 不是立即可用** —— 下一次 Godot 启动 / 重新导入前全局类表里没有它，
   跑无头脚本会报 `Identifier "SceneSettingRegistry" not declared`。
   → **正解**：新建带 `class_name` 的脚本后先随便跑一次引擎再写引用它的代码（见 [关卡格式V2.md](关卡格式V2.md) §6）。
3. **`is_day` 语义极易写反** —— `true` = 白天 = **蘑菇睡觉**，`false` = 夜晚 = 蘑菇醒着
   （判定在 `ComponentSleep.judge_is_sleeping()`，全局只有这一个消费点）。
   曾经在迷你游戏 05 / 09（僵尸迷阵，夜晚前院）里只写了 `game_BG = FrontNight` 却漏了 `is_day = false`，
   注释还误写成「蘑菇是醒着的，所以 `is_day` 保持 true」，结果盘面上的小喷菇 / 磁力菇
   从头睡到尾，且 `sleep_influence_components` 里的攻击 / 磁力组件被 `Sleep` 因子禁用（不只是冒 zzz）。
   → **正解**：底图写成夜晚（`FrontNight` / `Fog` / `Boss`）就一并写 `is_day = false`；
   白天底图但要用蘑菇（例：迷你游戏 06 隐形战争的寒冰菇）也要显式写 `is_day = false`。
   改完用 `-Scenario probe_beghouled -Windowed` 复验（探针里有「夜晚关蘑菇不睡觉」这条断言）。
