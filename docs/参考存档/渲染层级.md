## 一个坑：跨画布层时 z_index 不起作用

同一棵树里决定先后顺序的是 `CanvasLayer.layer`，**层内的**才轮到 `z_index` 和树序；

一个 layer 100 的节点永远画在 layer 6 的节点之上，后者就算写 `z_index = 2000` 也压不过去

（`trophy.tscn` 的 `z_index = 2000` 只在 `CanvasLayerTemp` 这层里有效，它仍然排在 UI 层之下）。

所以要「某个画面元素必须压在某

个元素之上 / 之下」，只有两条路：

1. 调 `CanvasLayer.layer`（粗粒度，跨层的唯一手段）
2. 把两者放进**同一个** CanvasLayer，再靠树序 / `z_index` 排（参照 trophy.tscn：

   `PickUpGlow` / `AllRays` 排在 `TrophyButton` 之前 —— 本体才不会被自己的光糊掉）

通关掉落的收尾表演就是按这个排的（见 `src/fx/other_effect/canvas_layer_white_screen.gd` 文件头）：

- 发光组 `PickupAwardLight` 挂在 `CanvasLayerDropItem` 的**第一个子节点**：跟掉落物同层，

  且排在掉落容器之前，掉落物本体画在光之上
- 白屏单独占 layer 100：最上层，把 UI 也一起吃掉，最后才变白、才切场景
