## 商店货架分页（对齐原版：一页 8 格，分上下两行）

原版商店（`store.tscn`）的货架**一页 8 格、摆成上下两行各 4 格**
（`ConstShop.SHOP_ROW_SLOT_NUM` = 4，`SHOP_PAGE_SLOT_NUM` = 8），
翻页按钮 `PrevPageButton` / `NextPageButton2` 每按一次翻一整页（`StoreManager._show_page()`）：

| 页  | 第一行（上）                          | 第二行（下）                                        | 整页上架时机                    |
| -- | ------------------------------- | --------------------------------------------- | ------------------------ |
| 1  | `RowTools`：卡槽扩充 → 水路小推车 → 钉耙 → 屋顶小推车 | `RowUpgradeFirst`：机枪射手 → 双子向日葵 → 忧郁菇 → 猫尾草     | 3-4 商店解锁（屋顶车 5-1、忧郁菇/猫尾草 4-4） |
| 2  | `RowUpgradeSecond`：地刺王 → 吸金磁 → 冰西瓜 → 玉米加农炮 | `RowUpgradeThird`：模仿者 → 坚果包扎术 | 5-1（冰西瓜 / 玉米加农炮 / 模仿者与坚果包扎术要通关后）  |
| 3  | `RowGardenSprout`：植物盆×3（金盏花幼苗 $2500，每天限购 3）→ 黄金水壶 $10000（买断，一次浇 4 株） | `RowGardenTools`：肥料 $750/5 个 → 杀虫剂 $1000/5 个 → 留声机 $15000 → 园艺手套 $1000 | 5-5 花园解锁                 |
| 4  | `RowGarden`：蘑菇园 → 水族馆 → 蜗牛 $3000（买断，买了在花园里捡钱）→ 智慧树 | `RowTreeFood`：树肥料 $2500/袋（持有上限 10 袋，详见下） | 5-5 花园解锁                 |

- **页数随进度放开**：`ConstShop.PAGE_SHOP_LEVEL` 写死每一页的上架关卡（3-4 / 5-1 / 5-5 / 5-5），
  `StoreManager._refresh_valid_pages()` 在 `_ready()` 里据此筛出参与翻页的页（`valid_pages`）；
  没到关卡的页**不存在**，不会出现空白页。页数入口 `StoreManager.get_page_num()`，只有一页时翻页按钮自动隐藏。
  3-4 与 4-4 时 1 页，5-1 时 2 页，5-5 起 4 页。
- **紫卡的落位写在 `StoreManager.PLANT_CARD_ROWS`**（第 i 项对应 `plant_card_rows[i]` 那一行），
  不再全塞进一个网格靠自动换行；上架时机仍由 `ConstPlantUnlock.PURPLE_CARD_CAN_BUY_LEVEL` 决定，
  未上架的商品在 `GoodsPlantCard._refresh_goods_state()` 里 `visible = false`。
- 屋顶小推车不再是「商店解锁即有」：`ConstShop.CLEANER_SHOP_LEVEL` 规定它要通关 5-1 才上架。
- 禅境花园类（蘑菇园 / 水族馆 / 智慧树 / 金盏花幼苗 / 花园工具）从 5-5 花园解锁起才摆上货架（第三 / 四页），
  能否购买由各自脚本判定，**统一要求「花园已解锁」**：走 `Goods.apply_garden_unlock_lock()`
  （通关 5-5 前按钮禁用 + 戴夫提示「通关冒险模式 5-5 解锁花园后才能买这个」）。
- **花园工具买了才出现在花园工具栏**：`GardenManager._refresh_garden_tool_visible()` 按
  `GlobalGameState.is_garden_tool_available()` 双向刷新 —— 可用就显示按钮，没买的（按钮 + 道具）一起藏起来；
  刷新时机有三处：进花园 `_ready()`、**从商店回来 `_update_back_from_store()`**（买了当场出现，
  不用退回主菜单重进）、**消耗品用光那一次使用**（肥料 / 杀虫剂 / 巧克力，见 `ItemPlantNeedBase.use_it` 与
  `Chocolate.use_it`）；道具本体的 `visible` 是「激活态」，刷新只管按钮，不反向点亮本体；
  黄金水壶是水壶的买断升级件，买了才能一次浇 4 株（见 `WateringCan.use_it`）；
  肥料 / 杀虫剂是消耗品（一份 5 个，花园里用一次扣一个，持有上限 20，
  见 `ItemPlantNeedBase.NEED_ITEM_TO_GARDEN_TOOL`）；
  存档都在 `garden_data` 的 `bought_garden_tools`（买断数组）与 `garden_tool_num`（消耗数量）。
  历史口径：旧存档没有这两个键 = 未拥有任何工具，需要去商店重新买。
  ⚠️ **存档走 JSON，读回来的数字一律是 float**：`bought_garden_tools` 存的是 `4.0`，
  `Array.has(int)` 判不中，买断记录会读档即丢 —— 读取侧必须逐个 `int()` 比（见
  `GlobalGameState.is_garden_tool_bought`），并在读档后调 `normalize_garden_data_numbers()` 转回 int。
- **蜗牛（Stinky）已实现**：$3000 买断，摆在第四页第一行第 3 格（蘑菇园 / 水族馆 / 智慧树之间）；
  买了之后 `GardenManager._init_stinky()` 在花园里生成蜗牛（睡着状态，点一下叫醒，自己去捡掉落的钱）。
  **只在初始花园（阳光房）露面**：翻到蘑菇园 / 水族馆时 `GardenManager._refresh_stinky_visible()`
  把它藏起来并停掉 `_process`（不爬也不捡钱，`Stinky.is_hit` 判 `visible` 所以点不到也喂不到），
  翻回阳光房还是原来那只；每次 `init_new_page()` 都会按 `curr_bg_type` 刷一遍。
- **巧克力不在商店出售**：原版口径下它的库存只来自**僵尸掉落**，而且要**买了蜗牛之后**才开始掉
  （`DropItemComponent.drop_chocolate()` → `EventBus "create_chocolate"` →
  `DropItemManager.create_chocolate()` → `DIM_Chocolate` 实例化 `ChocolateDrop`，
  点开加一块库存，库存到 `ConstShop.TOOL_MAX_OWN_NUM` 就不再掉）；
  `ConstShop.CHOCOLATE_PRICE` 只用于把它标成消耗品（在 `CONSUMABLE_GARDEN_TOOL_PRICE` 里），货架上没有对应商品。
- **智慧树与树肥料已实现**（$10000 买树 + $2500 一袋肥料），见下节。
- 坚果包扎术（`goods_wall_nut_first_aid.gd`）已实现：$2000 买断、通关冒险模式后上架，
  买了之后在关卡里手持坚果 / 高坚果 / 南瓜头卡片，可以直接补种在**已经掉手或裂开**的同种植物上
  （不铲除旧植物，血量与外观一起复原，照样扣一张卡的钱与冷却）。
  它不是植物卡片，不走 `PLANT_CARD_ROWS` 动态生成，而是直接摆在 `RowUpgradeThird` 场景里。

## 商店商品的一次性（买完即售罄）

| 商品        | 脚本                        | 售价 / 判定)                                | 售罄条件                                    |
| --------- | ------------------------- | --------------------------------------- | --------------------------------------- |
| 卡槽扩充      | `goods_card_slot.gd`      | `ConstShop.CARD_SLOT_UPGRADE_PRICES` 分档 | 到 10 槽 → 售罄（已满级）                        |
| 钉耙        | `goods_rake.gd`           | `ConstShop.RAKE_PRICE`（$200，一次买 3 关）     | 用完可再买（双向刷新）                             |
| 水路小推车     | `goods_lawn_mover.gd`     | `ConstShop.POOL_CLEANER_PRICE`（$1000）   | 已购买 → 售罄                                |
| 屋顶小推车     | `goods_lawn_mover.gd`     | `ConstShop.ROOF_CLEANER_PRICE`（$3000）   | 已购买 → 售罄                                |
| 紫卡 / 模仿者  | `goods_plant_card.gd`     | `ConstPlantUnlock.PURPLE_CARD_PRICE`    | 已拥有该植物 → 售罄                             |
| 坚果包扎术     | `goods_wall_nut_first_aid.gd` | `ConstShop.WALL_NUT_FIRST_AID_PRICE`（$2000） | 已购买 → 售罄（永久生效）                       |
| 蘑菇园 / 水族馆 | `goods_garden_bg.gd`      | `ConstShop.GARDEN_BG_PRICE`（各 $30000）    | 已拥有该背景 → 售罄（见下）                         |
| 智慧树       | `goods_garden_tree.gd`    | `ConstShop.TREE_OF_WISDOM_PRICE`（$10000） | `garden_data["is_tree_of_wisdom_bought"]` → 售罄 |
| 金盏花幼苗     | `goods_garden_sprout.gd`  | `ConstShop.MARIGOLD_SPROUT_PRICE`（$2500） | 不售罄，但每个盆槽位每天限购 1 次，且花园没空位时不卖（见下节）         |

- **每个植物盆槽位一天只能买一次**（原版 `Only three can be bought per day`，货架摆 3 个盆 → 一天最多 3 个）：
  每个盆有一个槽位序号（`GoodsGardenSrpout.slot_index`，由 `StoreManager._fill_sprout_slots()` 复制时编好），
  该槽位最近一次购买的日期记在 `garden_data["marigold_sprout_slot_buy_date"]`（字典：槽位序号字符串 → 日期字符串），
  与今天（`GlobalUtils.get_today_date_string()`）相同就视为该盆当天已售罄，跨自然日自动恢复。
  买了第 1 个盆后该盆显示「卖光了」并禁用按钮，另外 2 个盆不受影响；售罄态按日期双向刷新，
  所以植物盆不会被永久锁死。戴夫提示「这个今天已经卖掉了，明天再来吧」。

### 蘑菇园 / 水族馆：购买 = 解锁背景，不是「加一页」

原版这两个背景要花 $30000 **买**，买之前玩家根本进不去。判定与写入都在
`GlobalGameState`（`is_garden_bg_owned()` / `get_garden_bg_page_num()` / `buy_garden_bg()`）：

- **拥有 = 该背景页数 >= 1**；`DEFAULT_GARDEN_DATA` 里蘑菇园 / 水族馆默认 **0 页**（阳光房默认 1 页）。
- 购买走 `buy_garden_bg()`：未拥有时置为 1 页，已拥有时返回 false，**不会重复加页**
  （旧实现是「页数 +1」，而默认就有 1 页，等于白送一个背景且买第二次才售罄）。
- 花园侧同步：`GardenManager` 翻页时只走已拥有的背景
  （`_get_next_owned_bg_type()` / `_fix_curr_bg_type_if_not_owned()`），
  页码标签 `N/M` 里的 M 也只统计已拥有的背景数。

> **老存档兼容**：旧档 `num_bg_page_1/2` 已经是 1，会被判定为「已拥有」，
> 即保留玩家原有进度（不会把已给的蘑菇园收回去），只是商店里显示为已售罄。

- **温室（阳光房）不是商品**：原版商店只卖蘑菇园与水族馆，温室是玩家默认就有的花园。
- **智慧树已实现**：$10000 买断后花园里多出「智慧树」这一页（`GardenManager.E_GardenBgType.TreeBg`，
  按原版的「从水族馆再往后翻一页」），详见下节的智慧树小节。
### 智慧树：买树 = 解锁花园的第四页 + 白送几袋树肥料

原版口径（一代 PC，见
[Tree of Wisdom](https://plantsvszombies.wiki.gg/wiki/Tree_of_Wisdom) 与
[Tree Food](https://plantsvszombies.wiki.gg/wiki/Tree_Food)）：

- **$10000 买断智慧树**，买下后花园里多出「智慧树」这一页 —— 原版说的是
  「从禅境花园往后翻、翻过水族馆」，对应本仓库的 `GardenManager.E_GardenBgType.TreeBg`，
  买 disks 时由 `GlobalGameState.buy_tree_of_wisdom()` 顺手 `buy_garden_bg(TreeBg)` 解锁，
  所以它也照样进 `_get_next_owned_bg_type()` 的翻页环与页码标签的 `N/M`。
- **买下时戴夫白送 5 袋树肥料**（`ConstTreeOfWisdom.TREE_FOOD_START_NUM`）。
- **树肥料 $2500 一袋**，一次一袋（与其他消耗型工具「一份 5 个」不同，所以
  `ConstShop.get_garden_tool_num_per_buy()` 对它单独判），**最多囤 10 袋**
  （`ConstShop.get_tool_max_own_num()` 对它也单独判）。
- **一袋树肥料长高一英尺**，喂一次它讲一句「智慧」（口径见下面那条提醒）。

落地位置：

  没买智慧树时按钮一起藏起来；买了树才有第 9 个按钮（工具栏原本正好按 8 个 75px 摆满，

  点工具栏不该把肥料喂出去。
