## 冒险模式没有选关界面：按进度只能打下一关（2026-10-16 改）

原来那张「5 页 × 10 关」的冒险地图（`src/menus/choose_level/adventure_choose_level.tscn`）**已删除**：
`MainScenesMap` 里 `ChooseLevelAdventure` 的槽位**故意不登记场景**，进冒险模式直接从主菜单进关。

| 关注点 | 落在哪 |
| ---- | ---- |
| 进冒险模式 | 主菜单木牌 → 3 秒僵尸手破土过场 → **直接进「该打的那一关」**：`StartMenuRoot._start_adventure_level()` |
| 「该打的那一关」是哪一关 | `GlobalGameState.get_curr_adventure_level_to_play()` = **本周目**已通关最大序号 + 1；新档 = 1-1，打通 5-10 后进下一周目、又回到 1-1（见 [二周目.md](二周目.md)）。与木牌上那个关卡号同一个函数（`ConstUnlockLevel.get_adventure_button_level`） |
| 进关参数 | `GlobalGameState.build_curr_adventure_level_para()`：关卡本体按序号走 `LevelRegistry.get_adventure_level_id()` + `get_level()`（**带上当前周目**：二周目及以后取的是 `adventure_XX_YY_round2.gd`，见 [二周目.md](二周目.md) §6），选关三件套仍走 `set_choose_level()` |
| 通关后回哪 | `MgmRewardManager.win_main_game()` 照旧走 `get_scene_path(game_para.game_mode, 兜底 StartMenu)` —— 冒险模式槽位没登记 ⇒ **回主菜单**（木牌上就是下一关的关卡号，再点一次就进下一关）。刚解锁商店 / 图鉴那两关仍优先跳商店 / 图鉴 |
| 「开放所有关卡」开关 | 只影响还留着选关页的迷你 / 解谜 / 生存；冒险模式要跳关用调试窗口的「通关所有冒险关卡」 |
| 联机退关 | `NetplayMod.choose_level_scene_of_mode()`：认不出选关页的 mode（冒险模式、自制关卡模组没装）**一律回主菜单**，不再把玩家扣在关卡里 |

- 两条护栏：`test/scenarios/probe_adventure_next_level.gd`（进的是哪一关 / 存档键 / 木牌号与实际进的那一关一致）、

### 主菜单两类未解锁入口：模式置灰、道具隐藏

- 模式入口（冒险 / 迷你游戏 / 解谜 / 生存）未解锁时置灰；
- 道具入口（图鉴、商店、禅境花园等）未解锁时隐藏。
  详见 `src/menus/start_menu/start_menu_root.gd` 的 `_update_mode_lock_state()`。
- 花园场景 `GardenManager` 自己不查 `is_garden_unlocked()`，靠主菜单这个入口挡住。

### 主菜单冒险模式按钮：通关 1-1 前是「开始冒险模式」，之后换成「冒险模式 + 关卡号」

- **通关 1-1 前**（还没有通关记录）用 `SelectorScreen_StartAdventure_Button1`（木牌刻「开始冒险模式」），
  **不显示关卡号**；
- **通关 1-1 后**换成 `SelectorScreen_Adventure_button`，并在木牌上那行「关卡 __」里填**本周目**当前关卡
  （如 `1-2`；二周目进档又从 `1-1` 开始。夹到 `5-10` 的那条兜底见 [二周目.md](二周目.md) §9 第 5 条）。
- **周目标记**（`2周目`）挂在同一块木牌的 `LevelText/RoundText` 下，只有二周目及以后才显示
  （见 `start_menu_root.gd::_apply_adventure_round_text()` 与 [二周目.md](二周目.md) §7）。
- 判定入口：`ConstUnlockLevel.is_adventure_started()`（门槛 `ADVENTURE_STARTED_ADVENTURE_LEVEL` = 1-1；读**历史最高**，所以二周目不退回「开始冒险模式」）
  与 `ConstUnlockLevel.get_adventure_button_level()`（读**本周目进度**）；落地在
  `start_menu_root.gd::_apply_adventure_button_state()`，由 `_update_mode_lock_state()` 统一调用，
  所以 `_ready()`、切换用户 `refresh_for_current_user()` 都会跟着重算。
- 换的是**贴图不是节点**：两块木牌尺寸几乎一样（331×146 / 329×143），点击遮罩继续用「开始冒险模式」那张。
- **贴图自带的那条短横就是分隔符**：木牌上那行本来就是「关卡 —」，横线在贴图里；原版也只画两个数字
  （原版数字贴图表 `pak/images/SelectorScreen_LevelNumbers.png` 还在包里），所以这里同样**不画连字符**。
- 关卡号挂 **两个** Label：`BG_Right/Menu/Button1/LevelText` 下的 `FirstNumber`（大关号，右对齐贴住短横左边）
  与 `SecondNumber`（小关号，左对齐）。分开挂是为了两个数字能各自挪位置 ——
  两边的 `offset_*` 是按美术需求一个一个 px 调出来的（两个数字各自还有 1~2px 的高低差），
  换字体 / 换字号 / 想挪位置时**短横不动、两个数字要各自重新对一遍**：
  短横是贴图里的死位置，只挪数字很容易把它挤到数字身上。
- 探针：`test/scenarios/probe_start_menu_unlock.gd`（STEP6 / STEP7）锁死「贴图 + 关卡号 + 切用户回退」。

## 商店货架分页（对齐原版：一页 8 格，分上下两行）

原版商店（`store.tscn`）的货架**一页 8 格、摆成上下两行各 4 格**
（`ConstShop.SHOP_ROW_SLOT_NUM` = 4，`SHOP_PAGE_SLOT_NUM` = 8），
翻页按钮 `PrevPageButton` / `NextPageButton2` 每按一次翻一整页（`StoreManager._show_page()`）：

| 页  | 第一行（上）                          | 第二行（下）                                        | 整页上架时机                    |
| -- | ------------------------------- | --------------------------------------------- | ------------------------ |
| 1  | `RowTools`：卡槽扩充 → 水路小推车 → 钉耙 → 屋顶小推车 | `RowUpgradeFirst`：机枪射手 → 双子向日葵 → 忧郁菇 → 猫尾草     | 3-4 商店解锁（屋顶车 5-1、忧郁菇/猫尾草 4-4） |
| 2  | `RowUpgradeSecond`：地刺王 → 吸金磁 → 冰西瓜 → 玉米加农炮 | `RowUpgradeThird`：模仿者 → 坚果包扎术 | 5-1（冰西瓜 / 玉米加农炮 / 模仿者与坚果包扎术要通关后）  |
| 3  | `RowGardenSprout`：植物盆×3（金盏花幼苗 $2500，每天限购 3）→ 黄金水壶 $10000（买断，原版矩形范围内一次全浇） | `RowGardenTools`：肥料 $750/5 个 → 杀虫剂 $1000/5 个 → 留声机 $15000 → 园艺手套 $1000 | 5-4 花园解锁                 |
| 4  | `RowGarden`：蘑菇园 → 水族馆 → 独轮车 $200 → 蜗牛 $3000（买断，买了在花园里捡钱） | `RowTreeFood`：智慧树 $10000 → 树肥料 $2500/袋（持有上限 10 袋，详见下） | 通关冒险（5-10）              |

- **页数随进度放开**：`ConstShop.PAGE_SHOP_LEVEL` 写死每一页的上架关卡（3-4 / 5-1 / 5-4 / 5-10），
  `StoreManager._refresh_valid_pages()` 在 `_ready()` 里据此筛出参与翻页的页（`valid_pages`）；
  没到关卡的页**不存在**，不会出现空白页。页数入口 `StoreManager.get_page_num()`。
  3-4 与 4-4 时 1 页，5-1 时 2 页，5-4 时 3 页，通关后 4 页。
- **只有一页时翻页按钮置灰**（原版 `SetDisabled`），页码 `PageLabel`（`[STORE_PAGE]` 的「X / Y页」）只有多页时才显示；
  翻页本身按原版走「关箱 → 换页 → 开箱」动画（`StoreManager._flip_page()`，期间锁交互），
  调试 / 探针要立即换页用 `StoreManager._show_page()`。
- **进店演出**：招牌滑入 → 开箱（`CarClosed` → `Car2`）→ 解锁交互（原版前 120 tick 不可点，见 `_play_intro_animation()`）；
  夜间关卡背景进店会换 `Store_BackgroundNight`（原版 `StoreScreen::Draw` 的 IsNight 分支）。
- **紫卡的落位写在 `StoreManager.PLANT_CARD_ROWS`**（第 i 项对应 `plant_card_rows[i]` 那一行），
  不再全塞进一个网格靠自动换行；上架时机仍由 `ConstPlantUnlock.PURPLE_CARD_CAN_BUY_LEVEL` 决定，
  未上架的商品走 `Goods.set_goods_on_shelf(false)`：**保留格位**（透明 + 按钮禁用），
  与原版固定 8 格的「洞位」一致（不再 `visible = false` 让后面的商品左移；判定用 `Goods.is_on_shelf()`）。
- 屋顶小推车不再是「商店解锁即有」：`ConstShop.CLEANER_SHOP_LEVEL` 规定它要通关 5-1 才上架。
- 禅境花园类（蘑菇园 / 水族馆 / 智慧树 / 金盏花幼苗 / 花园工具）从 5-4 花园解锁起才摆上货架（第三 / 四页），
  能否购买由各自脚本判定，**统一要求「花园已解锁」**：走 `Goods.apply_garden_unlock_lock()`
  （通完 5-4 前按钮禁用 + 戴夫提示「通关冒险模式 5-4 解锁花园后才能买这个」）。
- **独轮车**按原版 `IsComingSoon`：蘑菇园 / 水族馆都没买时是 Coming Soon（不可买），
  买到任一背景后可以 $200 买下 —— 买完 Sold Out，本身不做任何事（原版也没有实装「用独轮车搬花盆」）。
- **买不起时不禁用按钮**（原版 `CanAffordItem`）：点一下弹「金币不足」对话框，与售罄 / 未上架的禁用区分开；
  买完卡槽扩充会弹「更多卡片槽！」，买完智慧树会问「拜访智慧树？」，选是直接跳花园智慧树页。
- **花园工具买了才出现在花园工具栏**：`GardenManager._refresh_garden_tool_visible()` 按
  `GlobalGameState.is_garden_tool_available()` 双向刷新 —— 可用就显示按钮，没买的（按钮 + 道具）一起藏起来；
  刷新时机有三处：进花园 `_ready()`、**从商店回来 `_update_back_from_store()`**（买了当场出现，
  不用退回主菜单重进）、**消耗品用光那一次使用**（肥料 / 杀虫剂 / 巧克力，见 `ItemPlantNeedBase.use_it` 与
  `Chocolate.use_it`）；道具本体的 `visible` 是「激活态」，刷新只管按钮，不反向点亮本体；
  黄金水壶是水壶的买断升级件，买了才能按原版 `IsPlantInGoldWateringCanRange` 的矩形范围**一次全浇**（见 `WateringCan.use_it`）；
  肥料 / 杀虫剂是消耗品（一份 5 个，花园里用一次扣一个，持有上限 20，
  见 `ItemPlantNeedBase.NEED_ITEM_TO_GARDEN_TOOL`）；
  存档都在 `garden_data` 的 `bought_garden_tools`（买断数组）与 `garden_tool_num`（消耗数量）。
  历史口径：旧存档没有这两个键 = 未拥有任何工具，需要去商店重新买。
  ⚠️ **存档走 JSON，读回来的数字一律是 float**：`bought_garden_tools` 存的是 `4.0`，
  `Array.has(int)` 判不中，买断记录会读档即丢 —— 读取侧必须逐个 `int()` 比（见
  `GlobalGameState.is_garden_tool_bought`），并在读档后调 `normalize_garden_data_numbers()` 转回 int。
- **蜗牛（Stinky）已实现**：$3000 买断，摆在第四页第一行第 3 格（蘑菇园 / 水族馆 / 智慧树之间）；
  买了之后 `GardenManager._init_stinky()` 在花园里生成蜗牛（睡着状态，点一下叫醒，自己去捡掉落的钱）。
  **只在初始花园（阳光房）露面**：翻到蘑菇园 / 水族馆时 `GardenManager._refresh_stinky_visible()`
  把它藏起来并停掉 `_process`（不爬也不捡钱，`Stinky.is_hit` 判 `visible` 所以点不到也喂不到），
  翻回阳光房还是原来那只；每次 `init_new_page()` 都会按 `curr_bg_type` 刷一遍。
- **巧克力不在商店出售**：原版口径下它的库存只来自**僵尸掉落**，而且要**买了蜗牛之后**才开始掉
  （`DropItemComponent.drop_chocolate()` → `EventBus "create_chocolate"` →
  `DropItemManager.create_chocolate()` → `DIM_Chocolate` 实例化 `ChocolateDrop`，
  点开加一块库存；**持有 10 块以后僵尸就不再掉**（原版 `CanDropChocolate`，见
  `DropItemComponent.CHOCOLATE_DROP_MAX_OWN_NUM`），商店持有上限仍是 `ConstShop.TOOL_MAX_OWN_NUM` = 20）；
  `ConstShop.CHOCOLATE_PRICE` 只用于把它标成消耗品（在 `CONSUMABLE_GARDEN_TOOL_PRICE` 里），货架上没有对应商品。
- **智慧树与树肥料已实现**（$10000 买树 + $2500 一袋肥料），见下节。
- 坚果包扎术（`goods_wall_nut_first_aid.gd`）已实现：$2000 买断、通关冒险模式后上架，
  买了之后在关卡里手持坚果 / 高坚果 / 南瓜头卡片，可以直接补种在**已经掉手或裂开**的同种植物上
  （不铲除旧植物，血量与外观一起复原，照样扣一张卡的钱与冷却）。
  它不是植物卡片，不走 `PLANT_CARD_ROWS` 动态生成，而是直接摆在 `RowUpgradeThird` 场景里。

- **每个植物盆槽位一天只能买一次**（原版 `Only three can be bought per day`，货架摆 3 个盆 → 一天最多 3 个）：
  每个盆有一个槽位序号（`GoodsGardenSrpout.slot_index`，由 `StoreManager._fill_sprout_slots()` 复制时编好），
  该槽位最近一次购买的日期记在 `garden_data["marigold_sprout_slot_buy_date"]`（字典：槽位序号字符串 → 日期字符串），
  与今天（`GlobalUtils.get_today_date_string()`）相同就视为该盆当天已售罄，跨自然日自动恢复。
  买了第 1 个盆后该盆显示「卖光了」并禁用按钮，另外 2 个盆不受影响；售罄态按日期双向刷新，
  所以植物盆不会被永久锁死。戴夫提示「这个今天已经卖掉了，明天再来吧」。

### 蘑菇园 / 水族馆：购买 = 解锁背景，不是「加一页」

原版这两个背景要花 $30000 **买**，买之前玩家根本进不去。判定与写入都在
`GlobalGameState`（`is_garden_bg_owned()` / `get_garden_bg_page_num()` / `buy_garden_bg()`）：

- **拥有 = 该背景页数 >= 1**；`DEFAULT_GARDEN_DATA` 里蘑菇园 / 水族馆默认 **0 页**（阳光房默认 1 页）。
- 购买走 `buy_garden_bg()`：未拥有时置为 1 页，已拥有时返回 false，**不会重复加页**
  （旧实现是「页数 +1」，而默认就有 1 页，等于白送一个背景且买第二次才售罄）。
- 花园侧同步：`GardenManager` 翻页时只走已拥有的背景
  （`_get_next_owned_bg_type()` / `_fix_curr_bg_type_if_not_owned()`），
  页码标签 `N/M` 里的 M 也只统计已拥有的背景数。

> **老存档兼容**：旧档 `num_bg_page_1/2` 已经是 1，会被判定为「已拥有」，
> 即保留玩家原有进度（不会把已给的蘑菇园收回去），只是商店里显示为已售罄。

- **温室（阳光房）不是商品**：原版商店只卖蘑菇园与水族馆，温室是玩家默认就有的花园。
- **智慧树已实现**：$10000 买断后花园里多出「智慧树」这一页（`GardenManager.E_GardenBgType.TreeBg`，
  按原版的「从水族馆再往后翻一页」），详见下节的智慧树小节。
### 智慧树：买树 = 解锁花园的第四页 + 白送几袋树肥料

原版口径（一代 PC，见
[Tree of Wisdom](https://plantsvszombies.wiki.gg/wiki/Tree_of_Wisdom) 与
[Tree Food](https://plantsvszombies.wiki.gg/wiki/Tree_Food)）：

- **$10000 买断智慧树**，买下后花园里多出「智慧树」这一页 —— 原版说的是
  「从禅境花园往后翻、翻过水族馆」，对应本仓库的 `GardenManager.E_GardenBgType.TreeBg`，
  买 disks 时由 `GlobalGameState.buy_tree_of_wisdom()` 顺手 `buy_garden_bg(TreeBg)` 解锁，
  所以它也照样进 `_get_next_owned_bg_type()` 的翻页环与页码标签的 `N/M`。
- **买下时戴夫白送 5 袋树肥料**（`ConstTreeOfWisdom.TREE_FOOD_START_NUM`）。
- **树肥料 $2500 一袋**，一次一袋（与其他消耗型工具「一份 5 个」不同，所以
  `ConstShop.get_garden_tool_num_per_buy()` 对它单独判），**最多囤 10 袋**
  （`ConstShop.get_tool_max_own_num()` 对它也单独判）。
- **一袋树肥料长高一英尺**，喂一次它讲一句「智慧」—— 讲哪句按原版台词编号走
  （100 / 500 / 1000 英尺讲里程碑，其余 `clamp(高度-1, 1, 49)`），判定表见 [禅境花园.md](禅境花园.md) §6。
