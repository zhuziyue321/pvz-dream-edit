## 1. 三页图鉴与它们的数据源

```
src/almanac/almanac.tscn             ## 场景：索引页 + 三页内容页
src/almanac/main_almanac.gd          ## 索引页：三个「查看」按钮 + 各页的「图鉴索引」返回
src/almanac/plant_page.gd            ## 植物页
src/almanac/zombie_page.gd           ## 僵尸页
src/almanac/extra_plant_page.gd      ## 扩展植物页（调试模式植物 + 模组植物）
src/almanac/panel_container.gd       ## 右侧详情面板（AlmanacCharacterShowPanel），三页共用
data/almanac/almanac_data.json       ## 图鉴文本：Plant / Zombie / ExtraPlant 三段
src/core/autoload/global_read_data.gd ## 读 json + 运行期登记条目
```

| 页 | 收录谁 | 条目从哪来 |
| --- | --- | --- |
| 植物 | `curr_plant`（已解锁）里的**普通**植物 | `data_almanac["Plant"][PlantName]` |
| 僵尸 | `curr_zombie` 里的僵尸 | `data_almanac["Zombie"][ZombieName]` |
| 扩展植物 | `curr_plant` 里**追加类**的植物 | `GlobalReadData.get_extra_almanac_entry(plant_type)` |

> **入口**：主菜单道具栏第 2 个按钮（通关冒险 2-4 拿到大图鉴后才显示，判据
> `GlobalGameState.is_almanac_unlocked()`，见 [选关界面与解锁.md](选关界面与解锁.md)）。

## 2. 扩展植物页：为什么单开一页

植物页**只收有原版图鉴文本的植物**（`data_almanac["Plant"].has(名字)` 才建卡），
于是两类植物永远进不了植物页：

- **调试模式专属**：三种保龄球 + 反向双发（`ConstPlantUnlock.DEBUG_MODE_PLANT_TYPES`）；
- **模组新增**：运行期注册的（`CharacterRegistry.is_runtime_plant()`，例如水盆）。

判据与选卡界面**完全同一口径** —— 都是 `AllCards.is_appended_plant()`，
顺序都照 `AllCards.get_plant_types_in_choose_order()`（普通植物在前、追加类在后）。
两处必须同一口径，否则同一株植物在选卡界面与图鉴里会落在不同位置。

是否显示仍按 `curr_plant` 过滤（与植物页一致）：没开调试模式 / 没装模组时这一页是空的，
面板给一句「这一页收录调试模式专属植物与模组新增植物」的提示，不是空白也不是报错。

## 3. 扩展植物的图鉴文本：三级兜底

`GlobalReadData.get_extra_almanac_entry(plant_type)` 按顺序取：

1. **运行期登记的**（`extra_almanac`，键 = 植物 id）—— 模组自己填的，见第 4 节；
2. **json 的 `ExtraPlant` 段**（键 = 植物 **id**，与 Plant / Zombie 段按 PlantName 建键**不同**：
   这一页里有一半植物是模组运行期注册的，本体拿不到稳定的 PlantName）；
3. **兜底条目**：名字取注册表（取不到就退回 id），正文写「扩展植物：原版图鉴里没有它的条目」。

兜底是必要的：模组可以只装植物不写文本（控制台临时注册的也是），
点开它的卡片时面板不能是一片空白甚至报错 —— 所以
`AlmanacCharacterShowPanel.almanac_update_character_panel_common()` 里所有字段都用
`.get(键, 默认值)` 读，参数项最多 5 条（面板里只摆了 `PlantPara` ~ `PlantPara5`）。

条目字段（与 `Plant` 段同构）：

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `名字` | 是 | 面板标题 |
| `描述` | 是 | 一句话 |
| `参数` | 是 | 字典，最多显示 5 条 |
| `简介` | 是 | 原版风味的小传 |
| `背景` | 是 | 取 `Day / Ice / Night / Pool / Fog / Roof` 之一（面板里的 `CharacterBgMap`） |
| `提示` | 否 | 紫色提示行，写了才显示 |

## 4. 模组怎么自带图鉴文本

**本体不认识任何一个模组**（硬约束），所以水盆的条目**不在** `almanac_data.json` 里，
由模组装载时自己登记、卸载时摘掉：

```gdscript
func install() -> void:
	...
	Global.global_read_data.register_extra_almanac_entry(WATER_BOWL, {
		"名字": "水盆", "描述": "...", "参数": {...}, "简介": "...", "背景": "Pool"})

func uninstall() -> void:
	Global.global_read_data.clear_extra_almanac_entry(WATER_BOWL)
```

关掉模组 = 条目跟着消失，玩家不会在图鉴里看见一个谁都种不出来的盆。
现成样例见 `mods_builtin/water_bowl/water_bowl_mod.gd`。

## 5. 加一页（照扩展植物页抄）

1. `src/almanac/` 新建 `<主题>_page.gd`（`extends TextureRect` + `class_name AlmanacXxxPage`），
   两个 `@onready`：`$CardGridContainer` 与 `$AlmanacCharacterShowPanel`，
   一个 `init_almanac_page()`（建卡 + 默认展示第一张）；
2. `almanac.tscn` 里照 `PlantPage` 复制一棵：`TextureRect`（底图）+ 标题 `Label` +
   `CardGridContainer` + `AlmanacCharacterShowPanel` 实例 + `ReturnButton`（连 `_on_return_button_pressed`）；
3. `main_almanac.gd`：加 `@onready`、在 `_ready()` 里 `init_almanac_page()`、
   在 `_on_return_button_pressed()` 里 `visible = false`、再加一个 `_on_xxx_button_pressed()`；
4. 索引页 `StartPage` 上加一个按钮（照 `StartPage/Panel3/ExtraPlantButton`）。
