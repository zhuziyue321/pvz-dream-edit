## 0. 一句话

原版 PvZ1 的「我是僵尸」是**解谜模式的第二个分支**（`GAMEMODE_PUZZLE_I_ZOMBIE_1..9` + `_ENDLESS`）：
玩家扮演僵尸，用阳光买僵尸卡，把僵尸放到**红线右侧**，让僵尸一路向左啃掉纸板植物、啃掉每行尽头的**脑子**，
**吃光 5 个脑子即通关**（`I_ZOMBIE_WINNING_SCORE = 5`）；僵尸全死且阳光不够再放一只 = 失败。

> 原版代码位置（本机两套 C++ 参照项目，只读不搬素材）：
> `../PvZ-Portable-main/src/Lawn/Challenge.cpp:4001-4624`（全部 I'm Zombie 逻辑）、
> `../PvZ-Portable-main/src/Lawn/Board.cpp:1348-1489`（起始阳光 / 僵尸卡 / 红线限制）。
> **两仓库有差异时以 PvZ-Portable 为准**。

## 2. 摆纸板植物算法（原版 `Challenge::IZombieInitLevel`）

原版只有**两种**摆放，仓库逐条照抄：

### 2.1 固定格位 —— `IZombiePlacePlantInSquare(seedType, gridX, gridY)`

在**指定格**种一株；该格不能种就跳过（不换位置、不重试）。

### 2.2 范围内随机 —— `IZombiePlacePlants(seedType, count, gridY)`

1. 候选格 = 指定行（`gridY = -1` 表示不限行，全 5 行）× **红线左侧前 `aColumns` 列**。
2. 该格能种（`CanPlantAt == PLANTING_OK`）才进候选。
3. **坚果与火炬只进最右 3 列**（`aColumns - col <= 3`）。
4. 权重全是 1（等概率随机），放过的格权重置 0（不再重复使用）。
5. 实际放的数量 = `min(count, 候选格数)`。

### 2.3 摆放顺序

原版**总是先全部固定格位、再全部随机落位**（逐关 `switch` 里固定条目在前）。
仓库按布局表的书写顺序执行，效果等价。

### 2.4 无尽关（`_ENDLESS`）：每轮重掷阵型

原版无尽关不是固定表，而是**每轮换一套阵型**（`mSurvivalStage` 递增）：

- 小喷菇数量：`RandRangeInt(clamp(2 + stage/3, 2, 4), clamp(3 + stage/2, 2, 6))`；
  第 1 轮（stage 0）= 0、第 2 轮 = 1、第 10 轮起上限再放宽一档。
- 向日葵数量 = `8 - 小喷菇数量`。
- 阵型：先掷「是否走伤害阵」（`RandRangeInt(0,4) == 0` 且 stage ≥ 1），
  再掷一次挑具体阵型：伤害阵 4 种 / 普通阵 3 种（混合阵、控制阵、秒杀阵）。

## 5. 纸板质感与静止动画（已对齐原版）

### 5.1 原版怎么做

**`Challenge::IZombieSetupPlant`（`Challenge.cpp:4087`）**：把纸板植物的所有 reanim `animRate` 置 0
（**完全静止**）、`mBlinkCountdown` 置 0（**不眨眼**）。
**注意它没有碰攻击** —— 原版植物开火走 `Plant::mShootingCounter`（`Plant.cpp` 的 `UpdateShooting`），
跟 reanim 无关，所以原版纸板植物**不动但照吐豌豆**。

**`Challenge::IZombieDrawPlant`（`Challenge.cpp:4505`）**：用**同一个 reanim 画 4 遍**：

| 遍 | 滤镜 | 偏移 | 颜色 | 效果 |
|---|---|---|---|---|
| 1 | `FILTER_EFFECT_WHITE` | (+4, +4) | (122, 86, 58) 深棕 | 纯色剪影，最底 |
| 2 | `FILTER_EFFECT_WHITE` | (+2, +2) | (171, 135, 107) 中棕 | 纯色剪影 |
| 3 | `FILTER_EFFECT_WHITE` | (-2, -2) | (171, 135, 107) 中棕 | 纯色剪影 |
| 4 | 无 | 原位 | (255, 201, 160) 淡肤色 | 原图 × 淡肤色（本体） |

原版的 `SetColorizeImages(true)` + `SetColor(c)` = 「把这一遍画成 c 色」，
所以**描边层是纯色剪影**（不是白剪影），本体层是原图乘淡肤色。

### 5.2 仓库怎么做

| 原版 | 仓库 | 落点 |
|---|---|---|
| 画 4 遍 | 本体 1 层（淡色材质）+ 描边 3 层（**把 Body 的视觉子树复制 3 份**） | `PaperPlantLook.apply()` |
| 白滤镜 + `SetColor` | shader 的 `silhouette` 分支：`rgb = paper_tint.rgb`（丢原色，填剪影色） | `shaders/my_shader/paper_plant.gdshader` |
| 偏移 (+4,+4) 等 | 副本 `position = body.position + offset`，`z_index = body.z_index - 1`（画在本体下面） | `PaperPlantLook._make_outline_layer()` |
| animRate = 0 | `is_anim_frozen = true` + 动画树 `TimeScale = 0`；动画组件在冻结时**无视倍率**写 0 | `Plant000Base._setup_paper_plant()` / `AnimComponentNorm.owner_update_speed()` |
| mBlinkCountdown = 0 | 禁掉眨眼组件 | 同上 |
| 照吐豌豆 | 僵尸模式下攻击组件改走 `shoot_burst()`（直接发射），不依赖攻击动画的方法轨 | `AttackComponentBulletBase` |

**为什么描边层是「复制副本」而不是「同一个节点画 4 遍」**：仓库的植物是 AnimationTree 驱动的，
同一张 reanim 只驱动**一套**贴图节点，没有「同一张图画 4 遍」的现成机制；
而纸板植物**完全静止**，复制出来的副本不需要再跟动画同步 —— 复制一次就是最终形态。

**冻结锁为什么要单独一个 `is_anim_frozen`**：植物的速度倍率系统（关卡加速 / 冰冻减速 / 随机速度）
会调 `anim_component.owner_update_speed()`，把 `TimeScale` 写成 `原始速度 × 倍率`，
**把 0 覆盖回来看得见的速度**。所以要在动画组件里认这个锁：冻结时一律写 0。

### 5.3 两个坑（都实测踩过）

1. **Godot 的「用父节点材质」（`use_parent_material`）只往上找一层** ——
   只给 `%Body` 挂材质的话，贴图节点（中间夹着 `BodyCorrect`）拿不到材质，画面完全没变化。
   **材质要直接挂在每个贴图节点上**（贴图节点共用同一个 ShaderMaterial 实例）。
2. **Godot 的 `Color(255, 201, 160)` 不是 0~1 的值**（Color 构造不归一化）——
   直接塞进 shader uniform 会被 clamp 成纯白，画面上纸板全白。
   **传给 uniform 前一律除 255**；shader 里也**不要**加 `source_color` 提示（会多做一次 sRGB→线性转换）。

### 5.4 回归探针

`test/scenarios/probe_i_zombie_paper_plant.gd`：进僵尸关 → 逐株断言
「`TimeScale = 0`」「动画播放位置不再前进」「不眨眼」「本体材质 = 原版淡肤色」
「三层描边的偏移 / 颜色 / 层级都对」「贴图节点真的挂上了材质」
「静止的纸板豌豆射手照样开火（数 `signal_shoot_bullet` 的次数，不是数场上的子弹数）」。

## 6. 已知差异（仓库 ≠ 原版）

1. **脑子耐啃度**：原版 70 口（每口 -1，约 2.8 秒）；仓库 100 HP、每口 25（4 口）。
   仓库的「口」由动画方法轨驱动，与原版的 4 tick 一口不同频，故未按口数直译。
2. **向日葵掉阳光的节奏**：原版每降低一档血量（40 血）掉 1 颗、死时再掉 `血量/40 + 1` 颗；
   仓库是「每被啃一口掉 1 颗、死时把剩余全掉」。**总量都是 8 颗**，但掉落时机不同。
3. **蹦极可放红线左侧**：原版 `CanPlantAt` 对 `SEED_ZOMBIE_BUNGEE` 单独放行（`gridX < aLimit` 即可）；
   仓库一律禁止左侧（`left_can_zombie = false`）。
