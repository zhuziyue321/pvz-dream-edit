该部分解释说明本项目主体目录（二级目录未完全列出）

- **addons**：插件目录，主要使用 R2Ga_PVZ 和 anim_player_refactor 插件处理动画
- **animation**：动画目录，保存所有动画文件，大部分单独保存为 `.tres`，少部分保存在场景文件中；按 `character/plant|zombie/<角色名>/`、`item/`、`garden/`、`crazy_dave/` 分目录（目录名不带数字编号）
- **assets**：资产文件夹，包含图片、音乐音效、字体、reanim 原始素材等；考虑到版权问题，<span style="background-color:rgb(255, 238, 173)">github 中将该目录删除，加群或者从大版本更新视频简介获取完整项目内容</span>
- **data**：数据层，全部 `.tres` 资源与其资源脚本；`character/` 角色属性、`map/` 地图、`dave/` 对话、`levels/params/` 玩家自制关卡参数、`tutorial/` 教程、`save/` 存档、`ui/` 主题、`almanac/` 图鉴、`strings/` 文案
- **docs**：文档目录，保存项目说明文档（如 [子弹说明文档](子弹说明.md)）；`docs/images/` 放 README 展示用图片
- **images**：**已停用**的遗留素材目录（原来混放未并入 `assets/` 的根级图片）。  
  2026-10-05 起被引用的 3 张图（`Almanac.png` → `assets/image/main_game_item/`、`WateringCan.png`、`Store_FirstAidWallnutIcon.png`）全部迁走，  
  目录内已放 `.gdignore` + `.gitignore` 排除：**Godot 不再扫描导入，也不会再引用它**，可随时删除。
- **shaders**：着色器脚本（`.gdshader` / `.gdshaderinc`）；`shaders/materials/` 放材质 `.tres`（如僵尸出土材质）
- **src**：代码与场景的唯一根目录，**按功能就近放置**（同一功能的 `.gd` 与 `.tscn` 同目录）：
  - `core/` 框架层：`autoload/`（单例 + 类型注册表）、`consts/` 全局枚举与常量、`utils/` 工具
  - `entities/` 游戏实体：`character/`（base / components / plant / zombie）、`bullet/`
  - `levels/` 内置关卡（按 `mode_*` 分模式）+ `core/` 关卡基类与时间轴
  - `managers/` 管理器、`ui/` 界面、`world/` 世界与相机、`main/` 主战斗场景、`menus/` 主菜单与选关
  - `items/` `fx/` `garden/` `store/` `almanac/` `dave/` 按功能分目录
- **test**：自动回归与调试通道（`scenarios/` 探针、`run_autopilot.ps1`）
- **tools**：仓库维护脚本（不参与游戏运行）

# 动画制作约定（植物 / 僵尸）

> 本节由原「项目目录说明.md#动画制作约定植物--僵尸」并入；更细的角色 / 动画挂点见 [创建新角色.md](创建新角色.md)。

使用 [R2Ga_PVZ](https://github.com/hsk-dream/PVZ_reanim2godot_animation) 把《植物大战僵尸》的动画文件转换为 Godot 支持的动画格式。

僵尸动画：

- 用插件 [anim_player_refactor](https://github.com/poohcom1/godot-animation-player-refactor) 删掉一部分轨道，主要是僵尸胳膊与头相关的 `visible` 轨道 —— 掉手 / 掉头时由代码控制 `visible`。
- 或者把需要用代码隐藏的节点挂到一个新的 `Node2D` 父节点下，代码直接控制这个父节点的显示与隐藏，**不改动画文件（推荐）**。

植物动画：

- 植物「射击时眨眼」与「idle 时眨眼」用的不是同一个节点；射击眨眼依赖 `visible` 轨道，所以用插件删掉 idle 眨眼节点的 `visible` 轨道，改为代码控制植物眨眼。

# 第三方插件

> 本节由原「杂项存档.md」的插件部分并入，因为这些插件主要服务于上面的动画目录。

## [anim_player_refactor](https://github.com/poohcom1/godot-animation-player-refactor)

一个 Godot 插件，用于重构 AnimationPlayer 的动画。[插件使用教程](https://www.bilibili.com/video/BV1GxXWYZExH)

注意：目录下 **plugin.gd** 脚本中调用的函数 `EditorUtil.find_animation_menu_button(base_control)` 只支持英文，需要进入函数修改对应代码：`func(node): return node.text == "Animation"` 改为 `func(node): return node.text == "Animation" or node.text == "动画"`。

## [R2Ga_PVZ](https://github.com/hsk-dream/PVZ_reanim2godot_animation)

把《植物大战僵尸》的动画文件转换为 Godot 支持的动画格式。[使用教程](https://www.bilibili.com/video/BV1XBKwzdELA/)，forked from [PVZ_reanim2godot_animation](https://github.com/HYTommm/PVZ_reanim2godot_animation)。

# 测试

直接运行游戏场景文件会使用游戏场景文件export的参数文件，同时卡片无cd,可以通过修改MainGame节点测试相关的参数（阳光、速度、删除僵尸）测试游戏

### 快捷键

- **Ctrl+D + 0：直接通关本关**（总开关 Ctrl+D 对应输入映射 `ShortcutKeys_WinLevel`，定义在 `project.godot`）
  - Ctrl+D 只是「总开关」：按下后进入等下一个按键的状态，由**下一个按键**决定做什么 —— `0` 立刻通关本关，`1` 通关所有冒险关卡，`2` 打开存档文件夹，按其它键 = 取消。
  - 监听挂在常驻 autoload `Global._unhandled_key_input()`（**不是** MainGameManager）：
    这类快捷键要在选关界面 / 主菜单也能按，那里没有 MainGameManager。
  - 入口：`Global.debug_win_main_game()` → `MainGameManager.shortcut_win_main_game()` → `win_main_game()`，
    所以解锁植物、解锁道具、写通关存档、多轮关卡重置都走正常流程，不会漏。
  - 生效阶段：选卡 / 准备 / 游戏中；`NONE`、`GAME_OVER`（奖杯已出）阶段不响应，避免重复结算；不在关卡内按 0 只提示、不动作。
- **Ctrl+D + 1：通关所有冒险关卡**
  - 入口：`Global.debug_success_all_adventure_level()` → `GlobalGameState.success_all_adventure_level()`，
    把 1-1 ~ 5-10 的存档键（`101_<页码>_<4 位序号>`，由 `GlobalGameState.get_adventure_save_game_name()` 反推）逐个写 `IsSuccess = true` 并解锁沿途植物。
  - 只写全局关卡数据，**不结算当前这一局**（当前关该怎么打还是怎么打），钉耙消耗 / 多轮存档重置这类「真打完一局」的副作用不做。
  - 放在 `GlobalGameState` 而不是 `MgmSaveManager`，是因为它不依赖当前这一局，选关界面 / 主菜单按也生效。
- **Ctrl+D + 2：打开存档文件夹**
  - 入口：`Global.debug_open_save_dir()`，用 `OS.shell_open(ProjectSettings.globalize_path("user://<当前用户>/"))` 让系统文件管理器
    定位到当前用户的存档目录（全局存档 + 各关多轮存档都在这一层下面）；没登录时退回 `user://` 根目录，同时把绝对路径打进日志。
- **Ctrl+K：杀死场上所有僵尸**（只挂在 `MainGameManager`，因为它要有 `zombie_manager` 在场）
- 新增同类快捷键：总开关之后的数字键直接在 `Global._run_debug_follow_key()` 的 `match` 里加一支；  
  要新开组合键才走「InputMap 加一个 `ShortcutKeys_*` 动作 + 脚本里判 `Input.is_action_just_pressed()`」，不要在脚本里硬编码 `KEY_*`。
- **Ctrl+K：杀死场上所有僵尸**（输入映射 `ShortcutKeys_KillAllZombie`，定义在 `project.godot`）
  - 入口：`MainGameManager._unhandled_key_input()` → `shortcut_kill_all_zombie()` →  
    `ZombieManager.death_all_zombie()`（与 EventBus 事件 `test_death_all_zombie` 同一入口）。
  - 走的是正常死亡流程（血量归零 + `signal_character_death`），所以 `curr_zombie_num` 会正确递减，  
    最后一波清完一样触发奖杯结算，不会「僵尸没了关卡不结束」。
  - 生效阶段：仅 `MAIN_GAME`（选卡 / 准备阶段场上没僵尸，按了没意义）。
  - 只清 `all_zombies_2d`，**不含已被魅惑的僵尸**（魅惑时已从该列表移入 `all_zombies_be_hypno`）。
  - 自动回归：`powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_kill_all_zombie`  
    （无头可跑，输出 `[KILLALL] result=PASS`；1-1 是教程关、第一波由教程启动，探针直接调  
    `zombie_wave_create_manager.wave_create_zombie()` 摆僵尸，不干等波次）。
