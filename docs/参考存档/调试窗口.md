## 一、调试窗口是什么

一个**贴在屏幕右侧、半透明**的面板，Ctrl+Q 呼出 / 隐藏。它装的是**调试动作与实时状态**，
与控制台（`Console`）的分工是：

| | 控制台 | 调试窗口 |
|---|---|---|
| 入口 | 主菜单 / 暂停菜单 →「控制台」 | **Ctrl+Q** |
| 装什么 | 持久化**开关**（自动收集阳光 / 显示血量 / 调试模式…） | 一次性**动作** + 只读**状态** |
| 什么时候用 | 改一次，以后都生效 | 正在调试，随手按一下 |
| 是否进存档 | 是（`config.ini` 的 `[console]` 段） | 不进（除了「增量」滑条那个键） |

> 一句话判据：**加一个调试功能 = 在 `DebugWindowEntries` 里加一行**，窗口 / 分页 / 刷新都不用改。

**开它的前提**：控制台 → 调试 →「调试模式」勾上。关着的时候按 Ctrl+Q 只打一条提示、不弹出来
（免得玩家误触把界面顶出来）。

## 二、三件套

| 文件 | 类 | 作用 |
|---|---|---|
| `src/ui/debug/debug_window.gd` | `DebugWindow` | 面板：造界面 + 分页 + **认 Ctrl+Q** + 定时刷新状态行 |
| `src/ui/debug/debug_window_entries.gd` | `DebugWindowEntries` | 窗口里那批条目（一条一行）与它们要调的动作 |
| `src/core/autoload/global.gd` | `Global` | 只在 `_ready()` 里 new 出来并 `add_child`；顺带提供 `is_debug_mode_on()` |

> 条目形态直接复用控制台那套：`ConsoleEntry`（数据）+ `ConsoleEntryControl`（渲染器），
> 见 [控制台.md](控制台.md)。**但这些条目不登记进 `ConsoleRegistry`** ——
> 它们只在调试窗口里出现，控制台面板不会多出这些按钮，两边互不干扰。

窗口没有对应的 `.tscn`：它常驻在 autoload 下、内容全靠运行时造，用 `DebugWindow.new()`
就够了，省掉一份只有根节点的场景与 `.uid`。

数据流：

```
DebugWindowEntries ──create_control()──▶ ConsoleEntryControl ──▶ 那一页的 VBox
        │                                        ▲
        └── 按钮动作 / 滑条 setter ──▶ Global / GameContext / Engine
刷新：Timer(0.25s, ignore_time_scale) ──▶ ConsoleEntryControl.refresh()
```

## 三、加一项的两步

### 3.1 在 `DebugWindowEntries` 里加一行

照 `_register_common_entries()` 里现成的写法抄，五个形态都能用（Toggle / Button / Slider /
Text / Readout，见 [控制台.md §四](控制台.md#四五种形态consoleentrye_kind)）：

```gdscript
_add(builder, parent, ConsoleEntry.create_button(&"debug_my_action", "我的调试动作", _my_action)
	.set_tooltip("悬停时显示的说明")
	.set_category(CATEGORY_COMMON)
	.set_order(60))
```

只想加进新的一页 → 加一个 `CATEGORY_*` 常量，在 `get_categories()` 的返回数组里插一项，
再写一个 `_register_<名字>_entries()`；**窗口那边什么都不用改**，分页条会自己多一页。

⚠️ 与内置控制台条目一样：**不要在登记时读 `Global.config_service`** —— 一律写进 lambda，
等面板真取值时才去读（`bind_config()` 已经这么做了）。

### 3.2 动作写在 `#region 动作` 里

```gdscript
static func _my_action() -> void:
	if not GameContext.is_in_main_game():
		Log.warn("调试窗口：不在关卡里，「我的调试动作」没生效")
		return
	...
```

动作里要判「在不在关卡内」就用 `GameContext.is_in_main_game()`，再经 `GameContext.curr_main_game`
拿主管理器 —— 不要从别处绕。

## 四、三个容易改错的点

### 4.1 热键挂在窗口自己身上，不是 `Global`

`Global` 是普通 autoload，`process_mode` 继承到 `PROCESS_MODE_PAUSABLE`，菜单一开就把树暂停了，
那时它**收不到** `_unhandled_key_input`（`Ctrl+D` 那套快捷键同理）。

而调试窗口恰恰要在暂停时也能呼出来看状态。所以：

- `DebugWindow.process_mode = Node.PROCESS_MODE_ALWAYS`；
- `_unhandled_key_input()` 写在 `DebugWindow` 里，它自己 toggle；
- **根 CanvasLayer 一直 `visible = true`**，只切内部那一块 `Panel` 的 `visible` ——
  不可见的节点收不到按键，整层都藏起来就再也按不出来了。

### 4.2 只有「调试模式」开着才会弹出来

判定统一走 `DebugWindow.is_debug_mode_on()`：
`Global.config_service.get_console_value(ConsoleBuiltinEntries.DEBUG_MODE_KEY, false)`。

已开着时按 Ctrl+Q **无条件收起来**（哪怕这时调试模式被关了），否则会出现「窗口关不掉」。
配置一变（`ON_CONFIG_UPDATE`）也复查一次：调试模式被关掉就把窗口收起来。

### 4.3 面板矩形要 anchors + **四个 offset** 一起写死

根节点那块贴右侧的 `Panel` 是**运行时 `Panel.new()` 造出来的**（窗口没有 `.tscn`），
初始矩形是 **0×0** —— 这时候碰任何 anchors preset 都会出事：

| 写法 | 结果 |
|---|---|
| `set_anchors_preset(PRESET_RIGHT_WIDE)` | 按当前 0×0 矩形反算 offsets，把 `offset_bottom` 写成 `-视口高` → **高度算成 0** |
| `set_anchors_and_offsets_preset(PRESET_RIGHT_WIDE)` | 左边距取自 `get_minimum_size()`，而宽度写在 `custom_minimum_size` 里（不参与该计算）→ 宽度算成 0，再被最小尺寸按 `GROW_DIRECTION_END` **向右**撑开 → **整块面板跑到视口右边界之外** |

两种写法症状一模一样：`_window.visible` 是 `true`、`is_visible_in_tree()` 也是 `true`，
**但屏幕上什么都没有**（实测 `get_global_rect()` = `(800, 0, 420, 600)`，而视口只有 800 宽）。

正确写法 —— anchors 设好之后，**四个 offset 一个不落地覆盖**：

```gdscript
_window.set_anchors_preset(Control.PRESET_RIGHT_WIDE)
_window.offset_left = -WINDOW_WIDTH
_window.offset_top = 0.0
_window.offset_right = 0.0
_window.offset_bottom = 0.0
```

> **教训**：`visible == true` **不能**证明面板看得见。排查这类问题要打 `get_global_rect()`，
> 看它是否落在 `get_viewport().get_visible_rect()` 里（探针 `probe_debug_window_hotkey` 就是这么抓到的）。

## 五、验证

改动较小 → **免验证**（判定见 [验证流程.md](../验证流程.md) §1）。

要验证就打开游戏（带窗口）：

1. 主菜单 → 选项 → 控制台 → 调试，勾上「调试模式」，关掉控制台；
2. 按 Ctrl+Q → 右侧出现半透明调试窗口，能看见底下的游戏；再按一次 → 收起来；
3. 控制台里把「调试模式」关掉再按 Ctrl+Q → 只打一条提示、不弹窗；
4. 进任意关卡 → 暂停菜单打开（树被暂停）时按 Ctrl+Q → 窗口照样能呼出来 / 收回去；
5. 切到「状态」页 → FPS、当前场景、僵尸数量、阳光、金币在刷；
6. 点「加阳光」 → 卡槽数字当场变化，卡片的够不够钱也重判。
