> **[面向 AI Agent]** ｜ **触发条件**：要给调试窗口加 / 删一个调试功能；或要弄清楚「调试模式」的开关在哪、为什么热键挂在窗口自己身上

## 一、调试窗口是什么

一个**贴在屏幕右侧、半透明**的面板，Ctrl+Q 呼出 / 隐藏。它装的是**调试动作与实时状态**，
与控制台（`Console`）的分工是：

| | 控制台 | 调试窗口 |
|---|---|---|
| 入口 | 主菜单 / 暂停菜单 →「控制台」 | **Ctrl+Q** |
| 装什么 | 持久化**开关**（自动收集阳光 / 显示血量 / 开放所有关卡…） | 一次性**动作** + 只读**状态** + 开关的**集中入口** |
| 什么时候用 | 改一次，以后都生效 | 正在调试，随手按一下 |
| 是否进存档 | 是（`config.ini` 的 `[console]` 段） | 动作不进；开关页改的是同一批 `ConfigService` 字段（会落盘） |

> 一句话判据：**加一个调试功能 = 在 `debug_window_entries.gd` 里加一行**，窗口 / 分页 / 刷新 / 搜索都不用改。

**开它的前提**：模组页面（主菜单 → 选项 → 控制台 →「模组」）里打开**「调试模式」模组**
（`ModIds.DEBUG`）。关着的时候本体里根本没有这个窗口，Ctrl+Q 什么都不会发生。

### 1.1 七页分别装什么

| 页 | 内容 |
|---|---|
| **常用** | 通关本关 / 重开本关 / 跳到冒险第 N 关（1-1 = 1，5-10 = 50）/ 通关所有冒险 / 解锁所有商品 / 立即写存档 / 打开存档文件夹 / 触发血月 |
| **战斗** | 僵尸类型（id 文本）+ 行（滑条）/ 刷一只 / 每行各刷一只 / 下一波 / 清场（跳过僵王）/ **秒杀全屏（含僵王）** / **植物无敌** / **无限阳光** |
| **资源** | 增量滑条 / 加阳光 / 加金币 / 阳光拉满（999999） |
| **开关** | 与控制台同一批 `ConfigService` 字段：显示植物 / 僵尸血量、开放所有关卡、自动收阳光 / 金币、追踪子弹跟随鼠标、静态浓雾、隐藏空卡槽、焦点卡槽置顶、预铲除置顶、游戏全屏，另加 **事件追踪**（`EventBus.is_trace_pushed_events`）与 **记录事件历史**（`EventBus.enable_history`） |
| **运行** | 游戏倍速（`Engine.time_scale`）/ 暂停游戏 |
| **状态** | FPS / 当前账号 / 当前场景 / 关卡阶段 / 波次 / 僵尸数量 / 场上植物 / 阳光 / 金币 / 倍速 |
| **日志** | 最近 200 条 `Log.*` 输出（只读文本框 + 清空） |

### 1.2 面板本身的能力

| 能力 | 用法 | 实现要点 |
|---|---|---|
| 呼出 / 收起 | **Ctrl+Q** | `_unhandled_key_input`（暂停时也要能用 → `PROCESS_MODE_ALWAYS`） |
| 切页 | **Ctrl+1 ~ Ctrl+9**（窗口打开时） | 写在 **`_input`**，早于 `_unhandled_input` 吃掉事件，不会顺带触发卡槽的 1-9 选卡 |
| 搜索 | 标题栏下方的输入框 | 只切每一行的 `visible`，不重建控件（不丢焦点）；索引由 `_add()` 登记 |
| 拖动 | 拖**标题栏**上下移动 | 改 `offset_top` / `offset_bottom`（高度不变，至少留 80px 在屏幕里） |
| 调宽 | 拖**左边缘**竖条 | 只改 `offset_left`（anchors + 四个 offset 仍然显式写死） |
| 复位 | 标题栏「复位」按钮 | 回默认 460 宽 + 贴回顶部 |
| 动作反馈 | 底部一行状态条 | 条目里调 `DebugWindowEntries.notify(文字, 是否错误)`；4 秒后自动清空，错误为红色 |

## 二、三件套（都在调试模组里）+ 一处本体缓冲

**2026-10-23 起整块搬进模组 `mods_builtin/debug/`** —— 原版没有调试窗口，所以它归模组，
本体（`Global` / `src/ui/`）里一个节点、一句分支都不留。

| 文件 | 作用 |
|---|---|
| `mods_builtin/debug/debug_window.gd` | 面板：造界面 + 七页 + 搜索 / 拖动调宽 / 反馈条 + **认 Ctrl+Q 与 Ctrl+1-9** + 定时刷新 + 日志页 |
| `mods_builtin/debug/debug_window_entries.gd` | 窗口里那批条目（一条一行）与它们要调的动作；搜索索引、动作反馈、植物无敌 / 无限阳光的状态也在这里 |
| `mods_builtin/debug/debug_damage_modifier.gd` | 「植物无敌」用的伤害修饰器（`DamageModifier` 子类，全场植物免伤） |
| `mods_builtin/debug/debug_mod.gd` | 模组入口：`install()` 里 new 出窗口挂到 `Global` 下，`uninstall()` 里整个释放 |

> 条目形态直接复用控制台那套：`ConsoleEntry`（数据）+ `ConsoleEntryControl`（渲染器），
> 见 [控制台.md](控制台.md)。**但这些条目不登记进 `ConsoleRegistry`** ——
> 它们只在调试窗口里出现，控制台面板不会多出这些按钮，两边互不干扰。
>
> 三个脚本都**不写 `class_name`**（模组可能从 `user://mods/` 加载，那里的脚本不注册全局类）：
> 用 `const DebugWindowEntries := preload("debug_window_entries.gd")` 引用同目录那份。

窗口没有对应的 `.tscn`：它常驻在 `Global` 下、内容全靠运行时造，用 `DebugWindowScript.new()`
就够了，省掉一份只有根节点的场景与 `.uid`。

**日志页的数据源在本体**：`src/core/autoload/logger.gd` 里加了最近 200 行的内存环形缓冲
（`get_recent_lines()` / `get_recent_text()` / `clear_recent()` / `recent_version`），
引擎自己的日志文件仍在 `user://logs/`。这是本体唯一为调试窗口留的口子，通用、无开关。

数据流：

```
DebugWindowEntries ──create_control()──▶ ConsoleEntryControl ──▶ 那一页的 VBox
        │                                        ▲
        └── 按钮动作 / 滑条 setter ──▶ notify() ──┴── 底部反馈条
刷新：Timer(0.25s, ignore_time_scale) ──▶ ConsoleEntryControl.refresh()
                                     ├──▶ DebugWindowEntries.tick()（植物无敌补注册 / 无限阳光锁值）
                                     └──▶ 日志页（Log.recent_version 变了才重铺）
```

## 三、加一项的两步

### 3.1 在 `DebugWindowEntries` 里加一行

照 `_register_<分组>_entries()` 里现成的写法抄，五个形态都能用（Toggle / Button / Slider /
Text / Readout，见 [控制台.md §四](控制台.md#四五种形态consoleentrye_kind)）：

```gdscript
_add(builder, parent, ConsoleEntry.create_button(&"debug_my_action", "我的调试动作", _my_action)
	.set_tooltip("悬停时显示的说明")
	.set_category(CATEGORY_COMMON)
	.set_order(60))
```

只想加进新的一页 → 加一个 `CATEGORY_*` 常量，在 `get_categories()` 的返回数组里插一项，
再写一个 `_register_<名字>_entries()`；**窗口那边什么都不用改**，分页条会自己多一页。

⚠️ 与内置控制台条目一样：**不要在登记时读 `Global.config_service` / 各管理器** ——
一律写进 lambda，等面板真取值 / 真执行时才去读（`bind_config()` 已经这么做了）。

⚠️ 想用「无限阳光」那种**持续生效**的开关，状态放 `static var`，在 `tick()` 里每跳落实一次，
并在 `shutdown()` 里复位 —— 否则窗口关掉后副作用还在。

### 3.2 动作写在 `#region 动作` 里

```gdscript
static func _my_action() -> void:
	if not GameContext.is_in_main_game():
		notify("不在关卡里，「我的调试动作」没生效", true)
		return
	...
	notify("做完了")   ## 成功也写一句，底部状态条才有反馈
```

动作里要判「在不在关卡内」就用 `GameContext.is_in_main_game()`，再经 `GameContext.curr_main_game`
拿主管理器 —— 不要从别处绕。

### 3.3 日志页不是「条目」

`get_categories()` 里的 `CATEGORY_LOG` 只占一个页签，实际内容由 `debug_window.gd` 的
`_build_log_page()` 铺一个只读 `TextEdit`。要改日志展示形式就改那里，
**不要**去 `register_all()` 里加分支。

## 四、几个容易改错的点

### 4.1 热键挂在窗口自己身上，不是 `Global`

`Global` 是普通 autoload，`process_mode` 继承到 `PROCESS_MODE_PAUSABLE`，菜单一开就把树暂停了，
那时它**收不到** `_unhandled_key_input`（`Ctrl+D` 那套快捷键同理）。

而调试窗口恰恰要在暂停时也能呼出来看状态。所以：

- `DebugWindow.process_mode = Node.PROCESS_MODE_ALWAYS`；
- `_unhandled_key_input()` 写在 `DebugWindow` 里，它自己 toggle；
- **根 CanvasLayer 一直 `visible = true`**，只切内部那一块 `Panel` 的 `visible` ——
  不可见的节点收不到按键，整层都藏起来就再也按不出来了。

### 4.2 Ctrl+1-9 必须写在 `_input`，不能写在 `_unhandled_key_input`

卡槽的 `CardSlotRoot._unhandled_key_input()` 用 `Input.is_action_just_pressed("ShortcutKeys_Card1..")`
响应数字键，**而且不调用 `set_input_as_handled()`**。如果调试窗口也在 unhandled 阶段判数字键，
结果是「切页 + 选卡」同时发生。

`_input` 早于 `_unhandled_input`：在那里判 `ctrl_pressed` + `KEY_1..KEY_9`，命中就
`get_viewport().set_input_as_handled()`，事件根本到不了卡槽。

### 4.3 模组开着才有窗口；窗口开着就永远收得起来

「调试模式」是一个**模组开关**（`ModIds.DEBUG`，模组页面里点）。关掉模组时
`debug_mod.gd` 的 `uninstall()` 直接 `queue_free()` 整个窗口 —— 不存在「窗口还在、开关却关了」
的中间态，所以 `toggle_window()` 里不再判任何开关，只做「开 ↔ 收」。
窗口 `_exit_tree()` 会调 `DebugWindowEntries.shutdown()`，把植物无敌 / 无限阳光一并撤掉。

配置一变（`ON_CONFIG_UPDATE`）仍然刷一遍值：控制台里的开关要即时反映到「开关」页。

### 4.4 面板矩形要 anchors + **四个 offset** 一起写死

根节点那块贴右侧的 `Panel` 是**运行时 `Panel.new()` 造出来的**（窗口没有 `.tscn`），
初始矩形是 **0×0** —— 这时候碰任何 anchors preset 都会出事：

| 写法 | 结果 |
|---|---|
| `set_anchors_preset(PRESET_RIGHT_WIDE)` | 按当前 0×0 矩形反算 offsets，把 `offset_bottom` 写成 `-视口高` → **高度算成 0** |
| `set_anchors_and_offsets_preset(PRESET_RIGHT_WIDE)` | 左边距取自 `get_minimum_size()`，而宽度写在 `custom_minimum_size` 里（不参与该计算）→ 宽度算成 0，再被最小尺寸按 `GROW_DIRECTION_END` **向右**撑开 → **整块面板跑到视口右边界之外** |

两种写法症状一模一样：`_window.visible` 是 `true`、`is_visible_in_tree()` 也是 `true`，
**但屏幕上什么都没有**（实测 `get_global_rect()` = `(800, 0, 420, 600)`，而视口只有 800 宽）。

正确写法 —— anchors 设好之后，**四个 offset 一个不落地覆盖**：

```gdscript
_window.set_anchors_preset(Control.PRESET_RIGHT_WIDE)
_window.offset_left = -WINDOW_WIDTH
_window.offset_top = 0.0
_window.offset_right = 0.0
_window.offset_bottom = 0.0
```

拖宽只改 `offset_left`，拖标题只改 `offset_top` / `offset_bottom`，四个 offset 始终是显式的。

> **教训**：`visible == true` **不能**证明面板看得见。排查这类问题要打 `get_global_rect()`，
> 看它是否落在 `get_viewport().get_visible_rect()` 里（探针 `probe_debug_window_hotkey` 就是这么抓到的）。

### 4.5 `TextEdit` 没有 `scroll_following`

`scroll_following` 是 `RichTextLabel` 的属性；给 `TextEdit` 赋值会报
`Invalid assignment of property or key 'scroll_following'`（实测 4.6）。日志页要「跟着最新一行」用
`set_caret_line(get_line_count() - 1, true)`。

### 4.6 植物无敌是伤害修饰器，切关会被清掉

「植物无敌」不是逐个植物挂组件，而是往 `DamageSystem` 注册一个全局 `DamageModifier`
（`debug_damage_modifier.gd`）：`info.target is Plant000Base` 就 `return false`，
但放行 `E_DamageCause.Death`（铲子 / 死亡消失）与 `E_DamageCause.Script`（关卡脚本强杀）。

`DamageSystem` 切关会 `clear_modifiers()`，所以窗口定时器每次刷新都补一次
`register_modifier()`（自身幂等）。新增类似的「全局常驻」开关时照这个模式做，
**不要**指望寄存器会跨关保留。

## 五、验证

改动较小 → **免验证**（判定见 [验证流程.md](../验证流程.md) §1）。

要验证就打开游戏（带窗口）：

1. 主菜单 → 选项 → 控制台 →「模组」→ 打开**「调试模式」**，关掉模组页面；
2. 按 Ctrl+Q → 右侧出现半透明调试窗口，能看见底下的游戏；再按一次 → 收起来；
3. **Ctrl+1 ~ Ctrl+7** 逐页跳（不会顺带选卡）；搜索框输入「僵尸」→ 只剩相关行，清空 → 全部回来；
4. 拖标题栏上下移动、拖左边缘调宽、「复位」回默认；
5. 「开关」页勾「显示僵尸血量」→ 进关卡后僵尸头顶有血条（与内置控制台同一条链）；
6. 进任意关卡 → 暂停菜单打开（树被暂停）时按 Ctrl+Q → 窗口照样能呼出来 / 收回去；
7. 「战斗」页填 `cone` + 行 3 →「刷一只」→ 第 3 行右侧来一个路障僵尸；「下一波」→ 波次前进；
   「秒杀全屏（含僵王）」→ 场上僵尸全部走死亡流程；
8. 「植物无敌」勾上 → 僵尸啃植物不掉血；用铲子仍能铲掉；再关掉 → 恢复正常；
9. 「无限阳光」勾上 → 阳光锁在 999999，种植物不减；关掉 → 正常扣；
10. 「常用」页拖到 1-1 →「进入该冒险关卡」→ 直接进关；「重开本关」→ 回到本关开头；
11. 「日志」页能看到刚才的动作日志（`Log.info` 一类），「清空」后只剩后续日志。

无头回归（两种，都会走模组的真实安装路径）：

```
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_debug_window_hotkey
powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_debug_window_pages
```

- `probe_debug_window_hotkey`：模组开关 / 窗口在树 / 合成 Ctrl+Q 能开能关；无头跳过截图。
- `probe_debug_window_pages`：七页齐全、Ctrl+2 切页、搜索过滤、日志页读到 `Log.info`、
  「加金币」后底部有反馈、拖宽 / 复位、关掉模组后窗口被释放。
