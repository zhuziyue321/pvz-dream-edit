## 一、开关与组成

| 项 | 位置 | 说明 |
|---|---|---|
| 开关 | `ResourceLevelData.is_portal_combat`（`src/levels/core/level_data.gd`） | 未开启时 `PortalManager` 完全待机（关 `physics_process`、不摆门） |
| 换位间隔 | `ResourceLevelData.portal_reshuffle_interval` | 秒；`<= 0` 摆好后不再换 |
| 管理器 | `src/managers/portal_manager.gd`（`PortalManager`） | 挂在主场景 `Manager` 下（`main_game_base.tscn`），`_ready` 自驱，不需要外部 `init` |
| 门节点 | `src/items/mini_game/portal.gd`（`Portal`） | 纯代码组装贴图 + Tween 动画，无 `.tscn` |
| 音效 | `SoundManager.play_character_SFX(&"Portal")` | `assets/audio/sounds/portal.ogg`，注册在 `SFXCharacterMap` |

贴图直接用原版 reanim 拆出的 `assets/reanim/Portal_*.png`（`Portal_Circle_*` 三张、`Portal_Square_*` 两张）；`animation/` 里没有生成传送门的 reanim 动画资源，表现用 Tween 做（方门交替闪烁、圆门中心慢转 + 呼吸）。门贴图分辨率不一，按目标高度归一（`DOOR_HEIGHT = 120`），不用逐张调 scale。

## 二、摆门规则（`PortalManager._reshuffle_portals`）

- 四扇门：下标 0/1 一对**方形**、2/3 一对**圆形**，配对 = 下标 `^ 1`。
- 每扇门挑一个行 + 半区一列：一对里一扇在**左半区**（列 `0 .. 中列前`）、一扇在**右半区**（列 `中列后 .. 末列`），**中间一列不放门**；行洗牌后依次取（行数 < 4 时取模重复用）。
- 门位置：`map_data.get_cell_rect(lane, col)` 的格子中心 x，y = 该行 `zombie_create_global_pos.y - 45`（门中心悬在行地面上方，僵尸原点在脚部）。
- 门 `z_index = lane * 50 + 20`，插在植物格子行（`lane*50+10`）与僵尸行（`lane*50+30`）之间。
- 换位动画走 `Portal.relocate()`（淡出 → 挪位 → 淡入，重复调用先打断上一次 tween）。

## 三、传送判定与配套逻辑

**判定只看 x + 行号**（`Portal.contains_x` 半宽 36 + `door.lane == obj.lane`），不看 y —— 僵尸原点 y 就是行地面 y，子弹斜飞时 y 会飘，按行匹配最稳。

扫描频率：`_physics_process` 每帧扫 `zombie_manager.all_zombies_1d` 与 `main_game.bullets` 的子节点。

| 对象 | 传送时要做的事 | 漏做的后果 |
|---|---|---|
| 僵尸 | `lane = 出口行` → `curr_zombie_row_type` 更新 → `signal_lane_update.emit()`（让僵尸管理器挪 `all_zombies_2d`）→ `reparent(新行节点)` → 落点 = 出口门 x 顺行进方向偏 20px、y = 新行地面 y | 不发 `signal_lane_update` 会留下悬空引用；y 不对齐会悬空/入土 |
| 子弹 | `lane = 出口行` → `z_index = lane*50+45`（与 `Bullet000NormBase.init_bullet` 同式）→ `global_position = 出口门中心` → `start_pos = position`（重置最大射程基准） | 不重置 `start_pos` 会被当「超过最大射程」立刻销毁 |

- **方向不变**：僵尸的 `direction_x_root`、子弹的 `direction` 都不动，走出出口门后继续原方向走 / 飞。
- **防来回横跳**：不用时间冷却（僵尸走得慢，固定冷却要么不够要么太久），改「出口记忆」—— 传送后记下出口门（`instance_id → instance_id`），该对象**离开出口门判定范围之前**不再触发传送，离开后自动清除。门整关常驻只换位置，所以不用考虑记忆里的门被释放。
- **被魅惑的僵尸不传**：`signal_lane_update` 会把魅惑僵尸挪回 `all_zombies_2d`，而魅惑僵尸死亡时只清 `all_zombies_be_hypno`，会留下悬空引用（`ice_all_zombie` 等遍历虽有 `is_instance_valid` 兜底，别赌）。
- **子弹只处理 `Bullet000NormBase` 系**：`lane` / `start_pos` 都定义在它上面；玉米炮弹直接继承 `Bullet000Base` 没有行属性，且一发清屏不该被门转送。

## 四、与原版的差异（口径说明）

- 原版传送门在草坪上随机位置刷新，本实现固定「左右半区各一扇、行不重复」，保证每对门传送有实际意义；换位间隔 15 秒取的是接近原版的节奏，未逐帧核对原版数值（来源分级见 [AI查wiki避坑.md](AI查wiki避坑.md)）。
- 抛物线 / 追踪子弹传送后继续追原来的目标（可能横穿草坪飞回去），原版行为未核实，玩法上可接受。
