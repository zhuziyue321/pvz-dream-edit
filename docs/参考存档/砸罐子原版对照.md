## 0. 一句话

原版 PvZ1 的「砸罐子」叫 **Scary Potter**（解谜模式里叫 Vasebreaker），
全部内容 = **9 个关卡 + 1 个无尽关 + 冒险模式 4-5**（Level 35）三批罐子，
机制核心是「用锤子砸开一个**矩形区域**里摆满的罐子，罐子里是植物 / 僵尸 / 阳光」。

> 原版代码位置（本机两套 C++ 参照项目，只读不搬素材）：
> `../PvZ-Portable-main/src/Lawn/Challenge.cpp:3456-3940`（全部逻辑）、`../re-plants-vs-zombies-main/Lawn/Challenge.cpp:4040-4300`（交叉验证）。
> **两仓库有差异时以 PvZ-Portable 为准**（re-plants 的 SP_6 僵尸数会越界，见 §5 注）。

## 2. 摆罐算法（原版 `Challenge::ScaryPotterPopulate`）

1. 候选格 = 前院 **9 列 × 5 行**（`MAX_GRID_SIZE_Y - 1`）共 45 格。
2. 按关卡表 `ScaryPotterDontPlaceInCol(col)` **排除若干列** → 剩下的列就是罐子区。
3. 每类罐子按数量 `ScaryPotterPlacePot(type, zombie, plant, count)` **加权随机**丢进候选格，
   **一格一个罐子**，所以「罐子总数 = 列数 × 5」，**每关都摆满，没有空格**。
4. 绿罐：`ScaryPotterChangePotType(GRIDITEM_STATE_SCARY_POT_LEAF, 2)` ——
   **每关固定 2 个**，从「内容是植物」的罐子里随机挑 2 个**只换外观**（内容不变）。
5. 太阳罐：仅 ENDLESS 有 1 个，`mSunCount = Rand(3) + 1`（1~3 颗阳光）。

| 机制 | 原版行为 | 原版代码 |

## 5. 本项目实现对照

| 原版概念 | 本项目落点 |
|---|---|
| `ScaryPotType`（内容） | `ScaryPot.E_PotType{Random, Plant, Zombie, Sun}`（`src/items/scary_pot.gd`） |
| 外观（棕 / 绿 / 僵尸脸） | `ScaryPot.get_pot_look_index()`：**由内容派生**（Plant→绿、Zombie→僵尸脸、其余→棕） |
| `SCARYPOT_SUN` | `E_PotType.Sun`；`open_sun()` 用 `SunSpawner.pop_up` 掉 1~3 颗阳光 |
| 关卡摆罐数据 | `ResourceLevelData`（`src/levels/core/level_data.gd`）的 `@export_group("罐子参数")` |
| 罐子占列 | `pot_col_range`（连续区间，左闭右开）**或** `pot_cols`（任意列集合，原版 SP_2 用） |
| 绿罐（戴夫提示） | `pot_hint_num`：从「内容已固定的植物罐」里随机挑 N 个换绿外观 |
| 太阳罐个数 | `sun_pot_num` |
| 无尽关巨人递增 | `pot_extra_gargantuar_per_round`（原版 10）+ `pot_extra_gargantuar_max`（8） |
| 关卡脚本 | `src/levels/mode_puzzle/puzzle_pot_01..10.gd`（10 = 无尽）、`src/levels/mode_adventure/adventure_04_05.gd` |
| 生成逻辑 | `src/managers/plant_cell_manager/pcm_pot_util.gd`（全 static） |

### 已知差异（本项目有意为之 / 未做）

| # | 差异 | 说明 |
|---|---|---|
| 1 | 罐子外观只有 3 种，**没有材质分类** | 原版 PvZ1 也没有；PvZ2 的陶/瓷/玻璃罐不在移植范围 |
| 2 | 僵尸内容罐用「僵尸脸外观」 | 原版僵尸罐是**棕罐**（内容只在透视时可见）；本项目用贴图第 3 列显式区分，属加强 |
| 3 | 罐内透视是**角色虚影**（原版是半透明内层） | 本项目用虚影表现灯笼草照亮的效果，信息量比原版多 |
| 4 | 无尽关**没有**「每 10 批奖励币」与「连胜旗数记录」 | 未做；原版规则见 §3.2 |
| 5 | 无尽关**没有**原版「成就：第 15 批」 | 未做 |
| 6 | 玩偶匣爆炸范围 | 原版 3×3；本项目用 250×200 的爆炸检测框 + 行 ±1 判据，视觉上与 3×3 接近 |

> re-plants 与 Portable 的差异（**以 Portable 为准**）：SP_6 僵尸数 re-plants 写成 6+6=44 > 35 格会越界；SP_8 植物 Portable 是高坚果、re-plants 是坚果墙。
