# 未使用代码与资源清单

本文件记录一次全项目静态扫描的结果，供后续清理时参考。
**扫描方式**：把所有文本文件（`scripts/`、`scenes/`、`resources/`、`animation/`、`data/`、`shaders/`、`test/`、`level_game_para/`）拼成一个语料，
再对每个资源的 **`res://` 路径** 和 **`uid://`** 分别计数 —— 只有两者都没被别处引用才算候选。

> 注意：**不要直接按本清单删除**。下面每一类都标注了判断依据，标为「保留」的多半是刻意保留的内容。
> 第 2.3 与第 3.2 节的遗留候选已在最近一轮处理完毕，详见第四节；保留节标题只为记录判断过程。

## 一、已确认为误报的类别（不要删）

早期只用「路径字符串」判断会得到 165 条候选，其中绝大多数是误报。以下类别已核实：

| 类别 | 为什么是误报 |
|------|--------------|
| `shaders/*.gdshaderinc` | 用**相对路径**引用：`#include "public.gdshaderinc"`（无 `res://` 前缀） |
| `addons/**` 的 `plugin.gd`、`main.tscn` 等 | 由 `plugin.cfg` / 编辑器按约定加载，不走 uid |
| `default_bus_layout.tres` | 是 Godot 音频总线的**隐式默认**路径 |
| `level_game_para/*.tres` | 自定义关卡，运行时**按目录扫描**加载（`06_custom_choose_level.gd`），不靠引用 |
| `animation/**` 中被 AnimationPlayer 引用的 | 走 `[ext_resource type="Animation"]` 的 uid，不是路径 |
| 由**动画方法轨道**调用的函数 | 方法名存在 `.tres`/`.tscn` 的轨道里，只搜 `.gd` 会误判（本项目大量使用该机制） |

## 二、真正的孤儿资源（无路径引用 + uid 也只在自己文件里出现一次）

### 2.1 动画资源（136 个）—— 判断：**保留**

主要分布在 `animation/character/plant/**` 与 `animation/character/zombie/**`，
文件特征为 `*_blink.tres`、`*_face.tres`、`*_head1/2.tres`、`*_hair.tres` 等。

**保留理由**：项目文档写明「植物射击/待机眨眼使用代码控制」，因此这些眨眼、表情、头部动画没有挂进 AnimationPlayer；
但它们是从原版动画转换出来的素材，后续做代码驱动眨眼时还会用到，删除收益（几 KB）远小于丢失素材的代价。

## 三、从未被引用的函数（28 个）

扫描口径：排除引擎回调（`_ready`/`_process`/`_on_*` 等）后，函数名在整个语料中**只出现一次**（即只有定义处）。

### 3.1 公共 API，**保留**（提供给外部/未来使用的工具方法）

```
scripts/autoload/event_bus.gd            subscribe_once / unsubscribe_all / clear_subscriptions /
                                         get_subscriber_count / get_event_history / clear_event_history /
                                         get_subscription_counts
scripts/autoload/global/save_service.gd  stop_autosave
scripts/autoload/util/random_picker.gd   remove_items / update_items_weights / get_items_weights /
                                         get_remaining_count / get_all_items
```

这些是 EventBus / RandomPicker / SaveService 的公开接口，属于刻意保留的能力，不建议删。
