# AGENTS.md —— `docs/` 目录指针

> **[面向 AI Agent]** ｜ **触发条件**：进入 `docs/` 找文档时（或在仓库任意子目录里读到「去 docs/ 查规则」时）
> **读完你能**：知道本目录是**规则层**，项目相关的参考文档在下一层 [参考存档/](参考存档/AGENTS.md)，并能立刻定位到文档总目录 [README.md](./README.md)
> **强制级别**：**参考**（纯指针） ｜ **不读的风险**：在错误的文件里找规则，或直接凭猜测改代码
> **关联**：仓库唯一入口 [../AGENTS.md](../AGENTS.md)

本文件**只做指针**，正文一律在下面的文档里（同一件事只在一处写）。

## 这一层放什么

- **规则 / 方法论 / 管理类**（本层）：`README.md`（总目录）、`项目规范.md`、`验证流程.md`、`AI调试通道.md`、`Agent协作协议.md`、`参考意见存档.md`、本文。
- **下一层还有两个目录**：
  - [参考存档/](参考存档/README.md) —— **项目相关**的机制 / 内容参考（地图 / 子弹 / 关卡 / 波次 / 手持物…），参考级别，不读不打回。
  - [工作记录/](工作记录/README.md) —— 逐次任务的流程记录（一次任务一个文件）。
