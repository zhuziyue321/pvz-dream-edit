## 步骤

1. **写 RTON 解码器** `tools/rton2json.py`（解包资源里全是 RTON：植物数值、图集矩形）。
   字节码表在文件头；两条实测口径：① 根对象**不带 `0x85`**，键值对直排、`0xff` 结束、尾部 `DONE`；
   ② `0x83` 是 RTID（子类型 3 最常见，先给「字符数 + 字节数」两个 varint 再给字符串）；
   ③ `0x84` 是「备注 + 真值」（读完备注塞回去的那个字符串再取值）。
2. **补 PAM → json 工具**：从 `..\b\tools\pam2json.py` 复制一份（纯 Python，可批量，替代 PopStudio 手工点）。
3. **新增一键重烘** `tools/bake_pvz2_assets.py`：五株清单（PAM 源 / 1536 图集 / `--atlas-id`）→
   PAM→json、RTON→JSON、`bake_pam_bin.py` 出 bin + 图集落位。
   ⚠️ `bake_pam_bin.py` 加了 `--atlas-id` 参数：同名 image 在 `*_768` / `*_1536` 两组里各有一份矩形（数值差一倍），

4. **拆出模组 `mods_builtin/pam/`**：`pam_mod.gd` + `runtime/`（播放器 / 定格渲染器 / 数据类 / 读取器），

## 弯路 / 踩坑（三段式）

1. **`pivot_offset` 的方向反了** —— 第一版按「脚悬空 35 px ⇒ pivot.y 减 35」改，结果整株**往上飘**了 35。
   `_root_xform()` 是纯位移，**pivot.y 越小画面越靠上**；正确写法 `pivot.y = 原值 - rect.end.y`（`rect.end.y` 是负数）。
   症状：种下去那株浮在半空 / 陷进土里，其它一切正常。口径已写进 `模组机制.md §6.7.1.1`。
2. **`.tscn` 里写死跨模组脚本路径** —— 模组有两个加载根（`user://mods/` 优先），
   场景里 `res://mods_builtin/pam/...` 在玩家把 pvz2 拷进 `user://mods/` 之后会指到「另一份」。
   改成「空 Node2D + 运行时 `set_script`」，并顺手踩到两个附带坑：
   ⓐ 空节点上 `set("binary_path", ...)` **不报错也不生效**（必须先 `set_script`）；
   ⓑ 脚本是进树之后挂的，`_ready()` 不会自动跑 ⇒ 要手动 `set_process(true)` + `load_bin()`，
   少了前者就是「画出第一帧然后一动不动」。
3. **静态类型调不到播放器方法** —— `@onready var _anim: Node2D = $Body/XxxAnim` 直接编译不过
   （「Node2D 没有 set_state()」）；播放器不是全局类，没有可写的类型名 ⇒ 声明成**无类型**
   `@onready var _anim = $Body/XxxAnim`，走动态派发。
4. **RTON 的数组与字符串** —— 数组是 `0x86 0xfd <varint 元素数> … 0xfe`，字符串长度也是 **varint**
   （不是 u8）；`0x91` 回引的下标指向「本次解析出现过的缓存字符串顺序」，所以解析必须从头一次到底，不能跳段。

2. 选卡页第 2 页看五张卡：卡面应是**定格站立**的植株（不是空白），「毒液豌豆」也在；
