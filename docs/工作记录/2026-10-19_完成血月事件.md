## 目标

把 DLC 版第 6 章月夜屋顶的**血月事件**补上：旗与旗之间 / 大波期间触发，全场僵尸大幅加速 + 画面变红。

## 步骤

1. **先查维基口径**：Moon 页（api.php 取 wikitext，页面直连 403）只给了定性描述
   ——「between or during each flag … significant boost in speed」，**没有数值**。
   想查 `Blood_Moon` 专页 → `missingtitle`，不存在。→ 数值自定并写进文档（§3 可调常量）。
2. **摸三条链路**（一轮探查拿到）：波次口子 `ZombieWaveManager.wave_started`、
   僵尸移速 `update_speed_factor(值, E_Influence_Speed_Factor.BloodMoon)`（**那一档已经存在**，
   是 DLC 模组血橙在用）、全屏染色 `CanvasLayerEffect`（现有只有「闪一下」的 once，没有常驻型）。
3. **开关放场景**：`SceneSettingBase.is_blood_moon` → `ResourceLevelData.is_blood_moon`
   （`apply_scene_setting()` 同步一行）—— 月夜屋顶场景给 true，其它场景零开销。
4. **新子管理器** `src/managers/blood_moon_manager.gd`：照 `MgmRewardManager` 的
   「runtime new + add_child + init_manager()」挂进主游戏；订阅旗帜波 → 起血月 → 计时结束自动落。
5. **红屏**：`canvas_layer_effect.gd` 加常驻型 `canvas_layer_effect_fade`（只 tween alpha，
   传 0 即淡出）+ 新事件 `CANVAS_LAYER_EFFECT_FADE`（顺手把 payload 签名补进
   `EVENT_PAYLOAD_SIGNATURES`），`main_game_base.tscn` 加 `Panel_BloodMoon`。
6. **新僵尸也要吃到**：`ZombieManager` 加 `zombie_created` 信号（`create_norm_zombie` 统一出口发），
   血月管理器连它 —— 否则只有血月前就在场的僵尸变快。
7. **音源**：四个 `bloodmoon*.ogg` 进 `pak/sounds/` 并登记 `SFXOtherMap`；
   用 ogg granule 位算出时长（10.7s / 6.75s / 2.72s / 1.41s）再定用途（见 [血月.md](../参考存档/血月.md) §4）。
8. **调试入口 + 探针**：调试窗口常用页「触发血月」按钮（再按一次提前结束）；
   探针 `probe_blood_moon` 覆盖开关 / 音源 / 实机加速与新僵尸 / 红屏进出。

## 踩坑

1. **新素材先过一次导入再跑门禁**：`.ogg` 和上次 `.png` 一个毛病 ——
   `preload` 报 `has no resource loaders (unrecognized file extension)`，9 条错；
   跑一遍 `check_scripts.ps1`（第一道就是 `--import`）生成 `.import` 后重跑即绿。
2. **探针里 `mg` 没类型 → `get_node_or_null` 推断不出类型**：
   `var layer := mg.get_node_or_null(...)` 直接 Parse Error，探针整个加载失败、
   游戏干等 300 秒被看门狗杀掉。写成 `var layer: Node = ...` 即可。
3. **合成关卡的僵尸要自己造**：血月合成关没有波次在跑，`create_norm_zombie` 要自己调
   （照 `probe_zombie_nimble.gd` 的 init_para 三件套）。
4. **别复用 `E_Influence_Speed_Factor.BloodMoon` 还想当然**：这一档血橙也在写，
   两边共用会互相清（血橙的计时结束把档设回 1.0 会顺带清掉血月的加速）。
   **次日本轮已修**：给血橙新开 `BloodOrange` 档（`character_base.gd` 追加枚举末尾，
   `bloodorange_plant.gd` 两处换档名），血月 / 血橙的计时从此互不可见。
5. **血月图 ≠ 月夜图（移植时踩的最大的一个）**：DLC 的 `background6.png` 在
   `properties/resources.xml` 里的 id 就叫 **`BACKGROUND_BLOODMOON`**（紫红血月），
   而月夜那幅是 `background6boss.jpg`（`BACKGROUND6BOSS`，深蓝，僵王战里那张）。
   我把血月那幅直接登记成了 `GameBg.MoonRoof` 的**常驻**底图 → 玩家一进关满屏紫红，
   **视觉上像是血月已经开了**，其实血月要等旗帜波才起（僵尸速度也是正常的）。
   已改：常驻换成月夜那幅，血月起落时由新事件 `BLOOD_MOON_VISUAL` 通知
   `main_game_bg_moonroof.gd` 把底图 + 房门遮罩换成血月那一套，结束换回来
   —— 血月这才真的「有来有去」。**查素材要先扫 `properties/`，只扫 `compiled/` 会漏。**

## 验证方式

- `test/check_scripts.ps1` → `real compile errors = 0`。
- `test/run_autopilot.ps1 -Scenario probe_blood_moon` → `[BLOODMOON] result=PASS failed=0`
  （在场僵尸 1.0→2.0、血月期间新生成的僵尸也是 2.0、红屏 alpha 抬起再淡回 0、结束后还原 1.0）。
- 回归：`probe_moonroof_map` / `probe_boss_map` 都 `PASS failed=0`。
- **人工肉眼验收**（可选）：调试窗口（Ctrl+Q，需先开控制台「调试 → 调试模式」）常用页
  「触发血月」→ 全场僵尸明显变快、画面泛红、换成血月环境曲，15 秒后自动还原。
