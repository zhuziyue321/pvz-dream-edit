# 2026-10-24_僵尸卡模组

> **本次任务**：从本机 `../PVZ_DLC` 取「脑光 / 僵尸卡牌 / 僵尸卡槽」等贴图，做成「僵尸卡」模组，在「我是僵尸」关卡里用上
> **耗时 / 轮次**：约 10 轮；没开游戏（编译门禁 + 无头探针各跑一遍，探针 failed=0）
> **推荐度**：推荐

## 目标

「我是僵尸」关卡要靠僵尸卡开局，但本体那条僵尸卡通道是关着的（`ConstFeatureSwitch.ZOMBIE_CARD_ENABLED = false`）——
那关发不出牌、也判不了负。这次用 PVZ2 的贴图做一个模组：既让那关有僵尸卡，又把外观换成 PVZ2 的僵尸卡槽 / 卡面 / 脑光。

## 最简路径（步骤）

1. 找素材：PVZ2 的「我是僵尸」那套 UI 在 `../PVZ_DLC/_unpacked/images/` ——
   `ZombieSeedBank.png`（446×87 僵尸卡槽）/ `ZombieSeed.png`（50×70 僵尸卡牌）/
   `SeedChooser_Background_I_Zombie.png`（465×513 选卡背景）/ `BrainGlowBig|Small.png`（120×120 脑光）/
   `BrainSun.png`（37×37 脑子阳光）。尺寸与本体那张一一对得上，可直接换。
   找法：`cmd /c dir /b <images> | findstr /i "card slot brain seed"`。
2. 建模组骨架：`ModIds` 加 `ZOMBIE_CARD`，`ModManager.MOD_SCRIPT_PATHS` 加一行，
   `mods_builtin/zombie_card/` 写入口 + 接线脚本 + 素材。
3. **发僵尸卡别去动总开关**：`is_zombie_card_enabled()` 是**全局**的，一打开普通关卡的选卡界面也冒出僵尸页，
   玩家能在正常关里放僵尸。改成在「我是僵尸」关卡里直接 `CardSlotBattle.set_cards()` 发牌。
4. 换外观：卡槽底图走 `add_theme_stylebox_override("panel", style)`；僵尸卡卡面直接改 `card.card_bg.texture`；
   待选区是 `TextureRect`，直接换 `.texture`。
5. 脑光：脑子被吃掉时会 `queue_free()`，所以脑光要挂在**脑子的同级**上；挂在脑子底下的话，
   「爆一下」会跟着脑子一起没了。
6. 脑子阳光：订阅 `ConstEventName.SUN_SPAWNED`（payload 就是阳光节点本身），把原版贴图藏掉再画脑子。
7. 收尾：编译门禁 + 探针；文档（模组机制 §6.12 / 卡片与选卡流程 / `mods_builtin/README.md` / 工作记录）。

## 弯路 / 踩坑（三段式）

- **试过**：在 GDScript 里写 `battle.theme_override_styles/panel = style` 换卡槽底图。
- **因为**：GDScript 不支持这种带斜杠的属性赋值（`.tscn` 里能用，代码里不行），解析直接报错，
  而且报错只报在**下游**（preload 失败 → 「无法推断常量类型」），看不出是哪一行。
- **结论**：换样式一律走 `add_theme_stylebox_override("panel", style)`；模组脚本要进编译门禁的视野，
  探针里对它 `preload`（门禁第二道会连着编译它们），别只在运行期 `load()`。

- **试过**：打开本体那个「僵尸卡总开关」来让「我是僵尸」有牌。
- **因为**：它是全局的 —— 普通关卡的选卡界面会多出僵尸页，玩家能在正常关里放僵尸。
- **结论**：模组只在该关卡里**直接发牌**，不去碰那个全局开关（`CardSlotBattle.set_cards()` 就是本体给的公共口子）。

## 推荐度与理由

推荐。模组本体（5 个脚本 + 6 张贴图）约 400 行，最难的不是写代码，而是**想清楚「哪条路只给「我是僵尸」、
哪条路会影响别的关卡」**：总开关是全局的不能动；发牌口子是现成的，直接用。
贴图尺寸与本体那张一一对齐，换外观不用调坐标。

坑有三个（都记在上面）：`theme_override_styles/panel =` 不能写、模组脚本要 `preload` 进探针才进门禁、
脑光要挂脑子的同级。
