## 一句话

甜菜守卫（DLC 的 ChardGuard）= 高血量防御植物 + 近战**击退**：僵尸从右侧凑过来就抡胳膊把它往后崩飞一截，共 3 次，不造成伤害；用完变 `idle_broken` 残血墙。落了 `mods_builtin/dlc/chardguard/`，配方 / 图鉴 / 描述登记进 `dlc_mod.gd`，探针 `test/scenarios/probe_dlc_chardguard.gd`。

## 关键决策与踩坑

1. **击退 = 改 `zombie.position.x += 距离`，不走 `DamageSystem`**。
   仓库**没有**僵尸击退 / 硬直 / 位移的引擎能力（搜遍 `component_move.gd` / `character_base.gd` 只有 `be_hit_light()`）。但僵尸每帧的位移是 `MoveComponent._process()` 按 ground / 速度的**增量**改 `position.x`，不会把一次性加的一截抹掉 —— 所以直接 `position.x += knockback_distance`（往右，即后退方向）就是净击退，僵尸得自己走回来。要改成带伤害，在 `_on_punch_timer_timeout()` 补 `DamageInfo.create(...) + apply_damage()`（口径见菜问 / 地刺）。
2. **检测框只铺右侧、且比击退距离短**：僵尸从右往左来，框铺 x∈[-40,190]（`CollisionShape2D position.x=75`、size 230×90），只罩「正在啃它」的那只；击退 +160 会把僵尸崩到 x≈+220、落出框外 → `signal_not_can_attack` 停表，僵尸走回来再崩，直到 3 次用完。**框右沿必须短于「啃食位 + 击退距离」**，否则崩完还在框里会连着崩不停。
3. **3 次额度管在 `_punches_left`**：崩够 3 次把冷却表掐掉，让当前这拳播完再由 `_on_animation_finished` 切 `ChardGuard_idle_broken`（不强行打断出拳动画，过渡更顺）；残血后 `_on_can_attack` / `_on_attack_cd_timer_timeout` 都按 `_punches_left > 0` 放行。
4. **血量靠覆盖 `HpComponent.max_hp`**：在植物场景里 redeclare `HpComponent` 节点设 `max_hp = 1600`（本体默认 300）—— 防御植物的命门。
5. **动画三段合成进 `AnimLib`**：转换工具每段一个独立 `AnimationPlayer`，`AnimLib` 里只有 `ALL_ANIMS`；照旧在自己场景里覆盖 `AnimLib.libraries`（idle / attack / idle_broken）。`AnimLib` 在 `ChardGuard.tscn` 里索引 = **18**。attack 0.9167s、idle 1.5s；`attack_cd`（1.2s）必须长于 attack，`punch_delay`（0.5s）取抡胳膊峰值。
6. **摆放**：初始 `ChardGuardAnim position = (-40,-85)` 是预估，最终以探针 `get_content_rect()` 量到的「底边对齐本体坚果墙」为准（STEP5 打 INFO，跑完按差值回填）。
