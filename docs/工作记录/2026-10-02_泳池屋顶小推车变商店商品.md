# 2026-10-02 · 其它（商店商品） · 把泳池/屋顶小推车改成商店商品

> **任务类型**：其它（商店商品）
> **推荐度**：**推荐**
> **耗时与成本**：约 1 轮，未开游戏（Godot 未在 PATH 中）
> **验证方式**：免验证 + 已给出人工验证方法
> **补充自**：无

## 目标

让水路小推车（Pool Cleaner）和屋顶小推车（Roof Cleaner）像原版一样在戴夫商店出售，买一次后所有对应地形关卡永久配发；普通草坪小推车仍免费配发。

## 步骤

1. **常量与存档**（参考 `docs/参考存档/选关界面与解锁.md` 商品表写法）：
   - `src/core/consts/const_shop.gd` 增加 `POOL_CLEANER_PRICE`、`ROOF_CLEANER_PRICE` 与 `CLEANER_PRICE` 字典。
   - `src/core/autoload/global_game_state.gd` 增加 `is_pool_cleaner_bought` / `is_roof_cleaner_bought` 及 `is_lawn_mover_bought()` / `buy_lawn_mover()`。
   - `src/core/autoload/save_service.gd` 把两个 bool 写入/读出全局存档。
2. **关卡生成侧过滤**：
   - `src/managers/game_item_manager/gim_lawn_mover.gd` 在 `create_all_lawn_mowers()` 与 `replenish_lawn_mover()` 里增加 `is_lane_can_have_mover()`，水路/屋顶类型未购买时当成「没有小推车」。
3. **商店商品**（参考 `goods_garden_tree.gd` 一次性商品模板）：
   - 新建 `src/store/goods_lawn_mover.gd`，`extends Goods`。
   - 新建 `src/store/goods_pool_cleaner.tscn` / `goods_roof_cleaner.tscn`，复用 `src/store/goods.tscn` 并挂 `StoreIcon`（复用现有 `assets/reanim/*_body1.png` 贴图）。
   - 新建 `data/dave/dialog_detail/store/pool_cleaner.tres` / `roof_cleaner.tres`。
4. **上架**：
   - `src/store/store.tscn` 把两个商品实例插到 `PlantCardGoodsContainer` 的 `GoodsCardSlot` 之后，并更新 `StoreManager.all_goods`。
   - `src/store/store_manager.gd` 注释同步。
5. **文档同步**：
   - 更新 `docs/参考存档/选关界面与解锁.md` 货架分页说明与一次性商品表。

## 关键决策与理由

- **状态存在 GlobalGameState 而不是 garden_data 里** —— 小推车解锁是全局战斗道具进度，与花园无关；单独字段语义更清晰，也便于 GIM_LawnMover 直接读取。
- **复用现有 reanim 贴图当商店图标** —— `assets/image/store/` 没有清洁车图标，手动生成新 PNG 会缺少 `.import`；复用已导入的游戏内贴图可立即生效，只是图标不够精致。
- **不改动地图资源** —— 地图仍描述「这行该配什么类型的小推车」；是否真正生成由购买状态过滤，与原版一致（购买后所有泳池/屋顶关自动生效）。
- **保持 `all_lane_have_lawn_mover` 原语义** —— 新加 `all_lane_mover_bought` 数组，避免把「地图没铺草皮」和「还没买清洁车」混在一起，方便后续 debug。

## 踩坑

1. **GIM_LawnMover 的大段替换失败** → 拆分成分步骤的小替换才成功；大段文本里中英文混排容易因不可见字符/缩进差异导致不匹配。
2. **差点把图标放进 `store.tscn` 里维护** → 后来决定放进 `goods_pool_cleaner.tscn` 等商品场景里，复用性更好，且 `store.tscn` 编辑范围更小。

## 给后来者的最简路径

1. 价格/存档字段 → `ConstShop` + `GlobalGameState` + `SaveService`。
2. 生成过滤 → `GIM_LawnMover.is_lane_can_have_mover()`（地图 + 购买状态）。
3. 商品脚本 → 照抄 `GoodsGardenTree` 的一次性 Sold Out 模板，改为按小推车类型判定。
4. 上架 → `store.tscn` 的 `PlantCardGoodsContainer` 添加实例，`all_goods` 补 NodePath。
5. 图标 → 复用 `assets/reanim/*Cleaner_body1.png`，避免生成新的 `.import`。

## 人工验证方法

1. 开启新游戏或旧档，通过任意方式让金币 >= 1000 且商店已解锁（冒险 3-4）。
2. 进入商店，确认第一页网格在「卡槽扩充」之后出现两个新商品，分别显示 $1000 / $3000。
3. 鼠标悬停，确认戴夫出现对应对话。
4. 进入泳池/屋顶关卡（或任意使用 `map_pool.tres` / `map_roof.tres` 的关卡），确认左侧没有 Pool Cleaner / Roof Cleaner。
5. 购买对应商品，存档后再次进入同类型关卡，确认左侧出现小推车；触发后能被消耗并在后续波次/秒级刷新中补回。
6. 重新进入商店，已购买商品应显示「已拥有」且按钮禁用。
