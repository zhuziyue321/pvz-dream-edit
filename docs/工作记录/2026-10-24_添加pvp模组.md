## 弯路 / 踩坑（三段式）

- **试过**：把 `TextureRect3` 原样改成 `TextureButton`，照抄编辑器里存的偏移 `offset_right = 98 / offset_bottom = 240`（= 92x40），再加 `ignore_texture_size = true`。
- **因为**：以为「编辑器里存的就是运行时尺寸」。实际上 **`TextureRect` 的最小尺寸 = 贴图尺寸**（本工程 Godot 版本实测 `combined_minimum_size = (279, 83)`），
  所以旧牌运行时是被**最小尺寸撑成 279x83** 画出来的（编辑器里那 92x40 是存量的死值）；
  换成 `TextureButton` 后 `ignore_texture_size = true` 把最小尺寸抹掉 → 牌被压成 92x40，贴图糊成一团。
- **结论**：换节点类型前先量「进树后的实际尺寸」——
  临时探针里 `TextureRect.new()` + `texture = 同一张图` + `size = 92x40` + `add_child()` + 等一帧，打 `size`。
  本次据此把按钮矩形写成 279x83（`offset_right = 285 / offset_bottom = 283`）并**不设** `ignore_texture_size`，视觉与旧牌完全一致。
