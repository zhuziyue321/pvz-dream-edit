# 2026-10-18_水盆模组并入 DLC

> **本次任务**：把 `mods_builtin/water_bowl/` 整包并入 `mods_builtin/dlc/`（模组 id `water_bowl` 撤销，水盆变成 DLC 模组里的一株）
> **耗时 / 轮次**：1 轮；**没跑探针**（编译门禁 `real compile errors = 0` PASS；当时有 godot 进程占着输出文件，按约定不杀）
> **推荐度**：推荐（同类「一株植物一个模组」的小模组，攒够后并进内容模组，少一个模组页条目、少一份开关）

## 目标

水盆本来是为了「草地上也能种海蘑菇」这一条原版没有的组合才独立成模组的，实际只有 3 个文件
（入口脚本 + 植物脚本 + 场景）。DLC 模组已经在做同一件事（运行期登记植物 + 一页选卡），
两个模组各占一个模组页条目、各登记一页选卡，维护与开关都是双份。合并后：
**模组页少一项、选卡少一页、水盆与 DLC 16 株共用 `[dlc]` 开关**。

## 最简路径（步骤）

1. **搬文件**：`git mv` 水盆的 `plant_water_bowl.tscn` / `water_bowl_plant.gd`（含 `.uid`）
   → `mods_builtin/dlc/waterbowl/`；入口脚本 `water_bowl_mod.gd` 不搬（逻辑并进 `dlc_mod.gd` 后删除）。
2. **`dlc_mod.gd` 加 4 处**（照其它株的槽位写）：
   - 场景常量 `WATER_BOWL_SCENE := preload("waterbowl/plant_water_bowl.tscn")` +
     id / 数值常量块（`PlantIds.WATER_BOWL` / 7.5 秒 / 25 阳光 / 卡面动画 `Pot_waterplants` / 兜底脸花盆）；
   - `install()` 配方数组末尾 `_build_water_bowl_recipe()`、图鉴调用段末尾 `_register_water_bowl_almanac_entry()`；
   - `uninstall()` 末尾 `clear_extra_almanac_entry(WATER_BOWL)`；
   - 配方函数追加到 `#region 配方` 末尾；图鉴条目追加到 `#region 图鉴条目` 末尾。
3. **水盆独有的两段代码单独开一个 region**：`#region 水盆：水生植物可以种进去`
   （`_open_water_plants_to_bowl()` / `_restore_water_plants()` + 成员 `_patched_water_plants`）。
   `install()` 里在登记选卡页之后调 `_open_water_plants_to_bowl()`；`uninstall()` **第一行**调
   `_restore_water_plants()`（和原模组同一顺序：先还原地形位，再撤页 / 卸植物）。
4. **撤销 water_bowl 模组**：`mod_ids.gd` 删 `WATER_BOWL` 常量、`ModManager.MOD_SCRIPT_PATHS` 删一行、
   删掉 `mods_builtin/water_bowl/` 目录。`user://<用户名>/mod_config.ini` 里旧的 `[water_bowl]` 段
   不会被读（`_load_save()` 只遍历登记在册的 id），下次保存自然消失。
5. **探针**：`probe_water_bowl.gd` 的开关从 `ModIds.WATER_BOWL` 改成 `ModIds.DLC`；
   「排在可选植物列表最后」的断言放宽成「在可选列表里（能挑到）」—— 水盆现在是 DLC 页的最后一格，
   但那条断言的语义是「模组追加项能进选卡」，不该被别的模组追加项左右。
6. **文档**：`mods_builtin/README.md`（`water_bowl/` 行换成 `dlc/` 行）、`dlc/README.md`、
   [模组机制.md §6.4](../参考存档/模组机制.md)、[DLC植物导入.md §1.2](../参考存档/DLC植物导入.md)
   （注明 `#region 水盆` 不属于 5 个并行槽位）、[图鉴.md](../参考存档/图鉴.md)、
   [运行期植物.md](../参考存档/运行期植物.md) 的样例路径。

## 踩坑 / 注意

- **水盆不是 DLC 素材**：它套的是本体花盆场景的 `Pot_waterplants` 那一支，别把它的 tag / 说明写成
  「DLC 动画导入」；配方里 `card_face_fallback_plant = PlantIds.FLOWER_POT`、动画名 `Pot_waterplants`。
- **id 沿用 `PlantIds.WATER_BOWL`**：探针、老存档与 `PlantIds.ALL` / 编号表第 50 位都在用；
  并入时不要顺手改成 `dlc_waterbowl`（会与 `PlantIds` 的空槽位对不上，存档里那株变成不存在的 id）。
- **场景内部引用用相对路径**（`water_bowl_plant.gd`）：模组可能整体从 `user://mods/` 加载，
  相对路径在同一个加载根内解析，比 `res://mods_builtin/...` 稳。
- **卸载顺序**：`_restore_water_plants()` 必须在 `kit.uninstall()` 之前 —— 它换回的是水生植物的条件资源，
  与水盆这张卡本身无关，但顺序和原模组保持一致，读代码时不用重新推一遍。
- **别把 `#region 水盆` 当成并行槽位**：DLC 导入手册的 5 个槽位是「一株一株追加」的位置，
  水盆这段是整块逻辑，并行接新株时不要动它。

## 验证

- `test/check_scripts.ps1` → `real compile errors = 0`，`result=PASS`。
- 人工验证：开游戏 → 模组页打开「DLC植物」→ 选卡界面 DLC 那一页最后一格是水盆 →
  草地上种下水盆 → 上面能种海蘑菇 / 缠绕海草、影子消失 → 铲掉水盆后影子回来 →
