# 2026-10-14 · 其它 · 选卡层把僵王当普通僵尸：候选卡页合并

> **任务类型**：其它（已有机制的层内收敛）
> **推荐度**：**推荐**（「同一层里一个数两套编号空间」照这个走：先统一编号，再合并消费侧）
> **耗时与成本**：约 1 轮对话，未开游戏（要不要开窗口见文末）
> **验证方式**：免验证 + 已给出人工验证方法（编译门禁 PASS 0 error）
> **补充自**：[2026-10-06_移植v1.3.0僵王博士与卡牌类型资源.md](2026-10-06_移植v1.3.0僵王博士与卡牌类型资源.md)（僵王卡是那轮加进去的，单开一页也是那轮定的）

## 目标

选卡 / 卡牌层不再把僵王当「另一类东西」：它排在最后一个僵尸卡位后面，
共用同一批候选页、同一份容器字典 —— 不再出现「整页只有一张僵王卡」。

## 步骤

1. 先统一编号空间：`all_cards.gd` 的 `rebuild()` 里改成 `var boss_i = zombie_i`，
   僵王的 `card_id` 接在最后一张僵尸卡之后（原来是 `boss_i = -1` 重新数）；
   顺手加 `get_enemy_cards_in_choose_order()`，把僵尸卡 + 僵王卡拼成一条连续列表。
2. 消费侧合并：`card_slot_candidate.gd` 删掉 `all_card_candidate_containers_boss` 与
   `_init_card_slot_candidate_boss()`，`_init_card_slot_candidate_zombie()` 改成走现成的
   `_create_card_pages()`（与植物同一套），按那条列表连续排页，容器一律登记进
   `all_card_candidate_containers_zombie`。
3. `card_slot_norm.gd`：删掉僵王的信号连接与两处按 `card_type` 分派的分支，换成两个小工具
   `_resolve_enemy_card_id()` / `_get_enemy_candidate_container()` —— 只有「查哪张 id 表」
   按 `card_type` 二选一，之后跟普通僵尸走同一条路。
4. `card_random_pool.gd` 去掉 `card_type == ZombieBoss` 的非法判定：僵王现在可以按权重
   进传送带 / 种子雨（写进 `.tres` 就能出）。
5. 同步文档：`docs/参考存档/卡片与选卡流程.md` 改页序描述 + 新增「僵王候选卡并入僵尸页」一节。

## 关键决策与理由

- **保留 `curr_zombie_boss` 解锁名单，不并进 `curr_zombie`** —— 两者 id 空间不同
  （`ZombieBossIds.DOCTOR = "doctor"` 不是有效 `ZombieIds`），合并会让「遍历 `curr_zombie`
  按僵尸类型查表」的地方拿到错误 key；两份名单只影响「点亮哪几个卡位」，成本低。
- **保留 `CardType.ZombieBoss` 不改成 `Zombie`** —— 召唤侧必须按它区分：
  `hand_component_character.gd` 走「不查格子占用、虚影落在格子的普通植物位置」，
  落地调 `try_create_boss_from_card()`；改掉等于把战斗层的差异抹了。本次只动**选卡层**。
- **`all_boss_card_prefabs` / `boss_card_ids` 保留** —— 它们仍是「僵王源卡」的登记表，
  候选容器要靠它们把 boss 类型换成 card_id；删了还要连带改 `debug_channel` 的计数报表。

## 踩坑

1. **Godot 要求同一文件里缩进方式一致** —— 手写时混进了「空格 + Tab」的一行，
   门禁报 `Used space character for indentation instead of tab as used before in the file`；
   这条错误会让**依赖它的十几个脚本**全部 `Failed to compile depended scripts`，
   一眼看去像到处都炸 → **正解**：在 `PROBLEMS` 里先看带**具体文件名**的那条 Parse Error，
   只有它指向真凶。
2. **`var x := 某函数()` 报「Cannot infer the type」** —— 被调用的函数明明写了
   `-> Array[Card]`，autoload 侧却推断不出来 → **正解**：消费侧显式写类型
   `var x: Array[Card] = ...`（这条与 10-07 那条「`Dictionary.get()` 恒返回 Variant」同源）。

## 给后来者的最简路径

1. 先问一句「这两套东西当初为什么分成两套」：找它们各自的**编号空间**能不能合并。
2. 编号统一 → 消费侧换成同一个列表 + 同一套分页 → 删掉多余的那份容器字典与其调用分支。
3. 收尾：`powershell -ExecutionPolicy Bypass -File test/check_scripts.ps1`
   + 全仓搜被删成员名（这里是 `all_card_candidate_containers_boss` / `_init_card_slot_candidate_boss`）。

## 人工验证方法（本次未开游戏）

- 控制台勾上「调试模式」→ 进任意有卡槽的关卡 → 选卡界面翻到最后一页（应为第 3 页）：
  僵尸卡之后紧跟一张僵王卡，**不再有第 4 页**。
- 选僵王卡 + 几张僵尸卡开局 → 点草坪任意格子仍照旧召唤出博士（说明只改了选卡层）。
- 退出重进 → 「重选上次卡片」能恢复上次那几张卡（含僵王卡）。
- 回归：解谜「我是僵尸」关卡的预选僵尸卡仍正常入槽。
