# 玩家对战僵尸卡花费平衡（2026-10-26）

- 推荐度：高（已落地，编译门禁 PASS）
- 关联：`mods_builtin/zombie_card/zombie_card_settings.gd` 的 `PLAYER_BATTLE_ZOMBIE_COSTS` / `PLAYER_BATTLE_ZOMBIE_COOLDOWNS`；文档 `mods_builtin/zombie_card/README.md` 与 `docs/参考存档/模组机制.md` §6.12

## 做了什么

按本仓库对战实现的**实测数值**与**胜利条件**重标 22 张僵尸卡的脑子花费（基准 = 普僵 25 脑子 = 270 EHP / 速度 20 / 无能力）。
核心改动：旗帜 300→25（PvP 没波次，等同普僵，冷却 30→7.5）、路障 75→50、撑杆 100→50、铁桶 100→125、铁网门 100→125、舞王 150→100、冰车 150→175、小丑 100→75、气球 225→150、矿工 150→175、蹦极 125→100、扶梯 150→125、投石车 175→150、巨人 250→300、小鬼 50→25；伴舞显式登记为 50（原回退注册表）。

## 分析口径（为什么这么标）

1. **僵尸方收入没做**：开局只有 `PLAYER_BATTLE_START_BRAINS = 150`（`player_battle_settings.gd`），无持续脑子收入。昂贵的「中后期卡」实战买不起，整体往下压让 150 开局 + 墓碑能滚起来。
2. **胜利条件是「漏一只进门」**：植物方 5 台割草机兜底，但**矿工 / 气球 / 蹦蹦**这三类「绕过全部植物」的越线单位是 PvP 真正制胜点，比「纯肉」单位（路障/铁桶/橄榄球/铁网门）更值钱 —— 越线类标到 150~175，纯肉类按 EHP 标（铁桶/铁网门 ≈ 5.1× 普僵 → 125，橄榄球 ≈ 6.2× → 150）。
3. **本仓库数值与原版不同**：铁桶/铁网门 EHP ≈ 1370、橄榄球 EHP ≈ 1670 但**本实现没加速**（与普僵同速）、旗帜僵尸无任何波次功能 —— 都按实测 `HpComponent.max_hp` + 防具算，不照搬 wiki。

## 踩坑 / 已知限制（本次未改，留给后续）

- **潜水 / 海豚骑士是 `ZombieRowType.Pool`**：白天前院（全 Land）选了也放不出来，白占卡槽 1 格；等泳池对战关卡或放开水域再调。
- **雪橇车需要冰道**（`ZombieCondition`）：白天前院不先放冰车就选不出来，是联动卡。
- **气球 / 矿工是「二进制」克制**：植物卡组没带仙人掌/灰烬类（樱桃/ Jalapeno/ 玉米加农）就无解，纯花费调不平；已在注释标注，靠卡组克制而非数值。
- **脑子收入**：真正决定僵尸方薄厚的还是 `player_battle_settings.gd` 那条「收入」逻辑（目前 TODO），花费是次要杠杆，收入做好后这套花费可能还要再校。
