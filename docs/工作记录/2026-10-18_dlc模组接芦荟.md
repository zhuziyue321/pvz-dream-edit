## 做法（最简路径）

1. **数值先取**：DLC Edition wiki 的 `Aloe Vera` 页（`api.php?action=parse&page=Aloe_Vera&prop=wikitext&format=json`）
   给到 50 阳光 / 7.5 秒冷却 / 生命 300 / 3×3 群体治疗 / 每 3 秒一次 / 治疗量不叠加；
   单次治疗量页面没给，取模组值 30。
2. **范围判定用自写 `Area2D`，不挂 `DetectComponent`**：本体检测组件是「索敌」用的，层按阵营写死成
   僵尸受击框（4），还会连 `CanAttackStatusComponent`。治疗要的是**植物受击框检测层（2）**：
   `aloe_heal_area_component.gd`（`extends Node2D`）里一个 `Area2D`（`collision_layer = 0` /
   `collision_mask = 2`），形状 `228×285`（3 格宽 × 3 行高，单元格 76×95）写在
   `plant_aloe.tscn` 里，脚本每帧比对「有目标 / 没目标」发两个信号给宿主。
3. **回血走新增的 `HpComponent.hp_heal(amount)`**：与 `hp_loss()` 对称的语义入口，夹到 `max_hp`、
   发 `signal_hp_loss(curr_hp, false)`（坚果 / 南瓜头的 `HpStageChangeComponent` 靠它，且回血不会触发掉落）。
   **不要**用负伤害走 `DamageSystem` —— 加血没有修饰器 / 免疫那些事。
4. **多株不叠加**：目标植物上记 meta `_dlc_aloe_last_heal_ms`，2.25 秒（= 3 秒 × 0.75）内被别的芦荟治过就跳过。
5. **动画**：照 DLC 老流程合成 `AnimLib` 库（idle / heal / blink / face），脚本只切 `AloeVera_idle` ↔
   `AloeVera_heal`；`heal_interval` 必须**长于** heal 动画 1.167 秒。
6. **登记**：`dlc_mod.gd` 加常量 / 场景预加载 / `_build_aloe_recipe()` / `install()` 数组 /
   图鉴条目 / 卸模清理 / 描述与 detail label。普通卡（`PlantConditionBits.DEFAULT_NORM`）。

## 踩坑

① **卡面落点要用运行期整株包围盒中心，不能用动画画布坐标**。取帧拿到的是挂好
   `<角色>Anim.position` 的**整株**，画布中心会差一个动画节点位移。芦荟按画布算得 `(-20.6,-16.0)`，
   实测卡面偏到左上；改用 `get_content_rect()` 量的整株中心 `(0,-37.4)` 反推 → `(0, 18.7)`（0.5 缩放）才落正。
   本体向日葵卡面手摆值 `(1,14)` + 0.5 缩放，用同一公式能反推出吻合值，可作基准。
   已在探针里加一条「卡面内容中心落在挂点 ±4 px」防止复发。
   > 注：`dlc_mod.gd` 里投掷蘑菇的 `(-15.3,-21.2)` 就是按画布算的，疑似同类偏移；本次**没动**（他人文件）。
② **`dlc_mod.gd` 是并发热点**：编辑期间它被别的 agent 改过，我第一次插入的常量块被覆盖丢了
   （编译门禁报 `Identifier "ALOE_COOL_TIME" not declared`）。改完**必须再搜一遍常量是否还在**。
③ **`@onready` 别给模组组件写自定义类型**：`aloe_heal_area_component.gd` 在 `user://` 下没有全局类名，
   `var x: HealAreaComponent` 会解析失败；写成不标注类型的 Variant，调用靠鸭子类型。
   同理 `var targets := _untyped.get_...()` 推不出类型 → 显式写 `Array` / `HpComponent`。
④ `Area2D.get_overlapping_areas()` 要等物理帧；探针里 `await a.frames(4)` 再断言回血。
