# 2026-10-17 自定义关卡模组：加载所有模组的 levels/ 目录

> **触发**：用户要求「修改自定义关卡模组，识别模组自带的关卡」→ 澄清为「**加载所有模组的特定目录**」。
> **结论先行**：扫描器从「只扫 `user://custom_level`」扩成「玩家目录 + 每个模组自己目录下的 `levels/`」，
> 同 id 玩家优先；探针 15 条断言全 PASS，`check_scripts.ps1` PASS。

## 一、改了什么

| 文件 | 改动 |
|---|---|
| `mods_builtin/custom_level/custom_choose_level.gd` | 新增 `MOD_LEVEL_DIR := "levels"` 约定；新增 `get_mod_level_dir(mod_id)` / `get_mod_level_dirs()`；`scan_custom_levels()` 重构为「玩家目录 + 所有模组 levels/」两类合并，抽出 `_scan_root()` / `_add_level()` |
| `mods_builtin/custom_level/custom_level_mod.gd` | 模组页面详情与 `_count_level_entries()` 改为统计两类目录 |
| `test/scenarios/probe_custom_level_mod.gd` | 新增断言：别的模组 levels/ 的关卡进列表、未登记模组 levels/ 也认、同 id 玩家优先（阳光 111 盖 222）、UI 层也出现 |

## 二、关键口径

- **目录来源**：`ModManager.MOD_SCRIPT_PATHS` 里登记的全部模组（**不论启用与否**）+
  `user://mods/` 下未登记模组目录兜底；每个模组的目录 = `ModManager.get_mod_root(id)` + 入口脚本的目录段 + `levels/`
  （`user://mods/<id>/levels` 优先、`res://mods_builtin/<id>/levels` 兜底，与 §2.2 素材同口径，整目录拷到 `user://mods/` 时关卡跟着走）。
- **同 id 优先级**：玩家目录 > 模组目录（模组之间按 id 排序先到先得，顺序确定）。
- 目录不存在自然跳过；只有玩家目录不存在时会自动创建（让玩家知道往哪放）。

## 三、踩坑

1. **`replace_in_file` 的 `\n`**：old_str/new_str 里含 GDScript 字符串字面量 `"\n"` 时，JSON 参数必须写成 `\\n`，否则匹配失败（报 "string to replace was not found"）。
2. **顺带修了 `probe_mod_page.gd` 的缩进损坏**（并行 WIP）：第 196–273 行整体少一级缩进（顶层语句顶格），
   先报 `Unexpected identifier "_click" in class body`，修好后才暴露下一个问题。三引号字符串（临时依赖脚本的 source_code）**不能**跟着加缩进，分三段绕开。
3. **门禁临时文件被占用**：`check_scripts.ps1` 清理 `%TEMP%\pvz_check_scripts\out.txt` 时被残留进程占用会中断；确认无 godot 进程后重跑即可。

## 四、验证

- `test/check_scripts.ps1` → PASS（real compile errors = 0，scenarios scripts=121）
- `run_autopilot.ps1 -Scenario probe_custom_level_mod`（无头）→ `result=PASS failed=0`：
  扫到 4 个关卡（玩家包 / 玩家冲突包 111 / glove levels 包 / 未登记模组包），冲突 id 只有一个且阳光=111
- 人工验证：模组页面打开「自制关卡」→ 主菜单入口 → 选关界面；把关卡包放进任意模组目录的 `levels/` 下即出现在列表

## 五、推荐度

想做「模组自带关卡」直接复用这条路：关卡包丢进自己模组目录的 `levels/` 即可，无需改任何注册表或本体代码。
