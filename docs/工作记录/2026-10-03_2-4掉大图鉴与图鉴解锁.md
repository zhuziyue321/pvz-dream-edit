# 2026-10-03 · 其它 · 冒险 2-4 通关掉大图鉴，并把图鉴入口挂到 2-4 解锁

> **任务类型**：其它（对齐原版：掉落 + 解锁门槛）
> **推荐度**：**推荐**（下次给某关加"戴夫掉落物"照这个走）
> **耗时与成本**：约 2 轮对话，未开游戏（用户选择免验证）
> **验证方式**：免验证 + 已给出人工验证方法（探针 `probe_adventure_reward` 已备好，跑一遍即可）
> **补充自**：无（同类最近的记录是 [2026-10-02_冒险4-6掉礼盒解锁解谜模式.md](2026-10-02_冒险4-6掉礼盒解锁解谜模式.md)，但那次是"中途某波携带"，本次是"通关掉落 + 入口解锁"）

## 目标

原版通关冒险模式 2-4 后戴夫掉下大图鉴（`Suburban Almanac`），在此之前图鉴入口进不去。
本仓库当时两处都没做：2-4 通关什么都不掉（该关既不在植物解锁表、也不在道具奖励表），
主菜单 / 暂停菜单的图鉴按钮则一直开放。

## 步骤

1. 掉落侧：`ConstAdventureReward.LEVEL_ITEM_REWARD` 加第 14 关（2-4）—— 提示文本取原版
   `data/strings/lawn_strings.txt` 的 `[FOUND_SUBURBAN_ALMANAC]` + `[SUBURBAN_ALMANAC_DESCRIPTION]`，
   贴图 `res://images/Almanac.png`（80×80，主菜单图鉴按钮那张）。
2. 选关界面：`adventure_choose_level.tscn` 第 2 页 **2-5** 按钮的
   `Panel/TextureRect` 下挂 `Sprite2D`（`position = Vector2(97, 69)`）—— 规则是
   「第 N 关的奖励 = 第 N+1 关按钮上的本关看点图标」，2-5 之前是空面板。
3. 解锁侧：`ConstUnlockLevel.ALMANAC_UNLOCK_ADVENTURE_LEVEL = 14` + `is_almanac_unlocked()`，
   `GlobalGameState.is_almanac_unlocked()` 包一层（与铲子 / 手套同口径，**不落库存档**）。
4. 两个入口拦截：主菜单 `BG_Right/Item/TextureButton2` 置灰 + 点击弹提示不切场景；
   暂停菜单 `Option/Button1`（`encyclopedia()`）置灰 + 点击用 `ReminderInformation` 弹提示。
5. 探针：`test/scenarios/probe_adventure_reward.gd` 加 STEP5（首次通关 2-4 掉图鉴贴图 / 提示含「大图鉴」）。
6. 文档：`docs/参考存档/选关界面与解锁.md` 补「图鉴解锁」小节 + 图标清单 + `LEVEL_ITEM_REWARD` 现状。

## 关键决策与理由

- **走 `LEVEL_ITEM_REWARD` 而不是给 `adventure_02_04.gd` 配 `drop_unlock_on_level_complete`** ——
  该关没有"解锁由通关触发"的额外语义，且文档明确"同一件事只在一处写"：
  关卡资源配过的是 3-4 车钥匙 / 4-4 玉米卷，普通奖励一律查奖励表。
- **图鉴解锁不落库存档** —— 与铲子 / 手套一致，由"已通关最大冒险关卡序号"推导，改门槛只改常量。
- **暂停菜单提示用 `ReminderInformation`** —— 那里的 `Dialog` 是基类 `dialog.gd`，没有
  `update_text()`（带文本的是子类 `DialogError`），只能换一套提示控件。
- **置灰统一用 `modulate`** —— 主菜单按钮是 `TextureButton`、游戏内是自定义 `BaseButton`，
  都继承自 `CanvasItem`，不必按类型分两套写法。

## 踩坑

1. **探针没跑成**：`test/run_autopilot.ps1` 清临时目录时报
   `godot.log 正由另一进程使用` → 原因是机器上还留着 3 个 Godot 进程 → 用户选择跳过验证，
   本次改用"免验证 + 人工验证方法"（改动已落探针，随时可跑）。
   **下次**：跑批前先 `Get-Process | ? {$_.ProcessName -like '*godot*'}` 看有没有残留实例。
2. **图鉴入口一开始没纳入解锁**：原版主菜单图鉴按钮在拿到图鉴之前不可用，
   第一版只补了掉落、没锁入口 —— 是用户补刀才加的，属于"原版表现要查全，不只是掉落物本身"。
3. **`_mark_cleared()` 在探针里只写 `101_0_xxxx` 也能跨页**：解锁判定
   `get_adventure_level_on_save_game_name()` 只看存档键第 3 段（`level_id`），
   所以标记 0013 就够让 2-4 算"首次通关"，不必按页拼 key。

## 给后来者的最简路径

1. 奖励表 `src/core/consts/const_adventure_reward.gd` 的 `LEVEL_ITEM_REWARD` 加一行（关卡序号 → 提示 + 贴图）。
2. 选关界面对应"下一关"按钮挂 `Sprite2D`（抄 1-5 铲子 / 2-5 图鉴的节点写法）。
3. 若这个掉落物还"解锁某个入口"：`ConstUnlockLevel` 加常量 + `is_xxx_unlocked()` →
   `GlobalGameState` 包一层 → 入口置灰 + 点击提示。
4. 文档同步 `docs/参考存档/选关界面与解锁.md`（图标清单 + 本关看点说明）。
