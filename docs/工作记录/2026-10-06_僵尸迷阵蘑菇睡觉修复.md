# 2026-10-06 · 排查调试 · 僵尸迷阵（宝石迷阵）蘑菇全程睡觉：关卡脚本漏写 `is_day = false`

> **任务类型**：排查调试
> **推荐度**：**推荐**（下次同类任务照这个走）
> **耗时与成本**：约 1 轮对话，带窗口跑了一次 `probe_beghouled`（约 20 秒）
> **验证方式**：打开游戏实测（带窗口探针 PASS，failed=0）
> **补充自**：无

## 目标

宝石迷阵（迷你游戏 05 僵尸迷阵）盘面上的小喷菇 / 磁力菇从头睡到尾（冒 zzz 且攻击组件被禁），改成醒着。

## 步骤

1. 定位睡眠判定：`ComponentSleep.judge_is_sleeping()`（`src/entities/character/components/component_sleep.gd`），
   判据是 `MainGameManager.game_para.is_day` —— **true = 白天 = 睡觉**，全局只有这一个消费点。
2. 查关卡脚本 `src/levels/mode_minigame/minigame_05_beghouled.gd`：`_init()` 里只写了
   `game_BG = FrontNight`，**没写 `is_day`**，取 `ResourceLevelData` 的默认值 `true` → 全场蘑菇睡觉。
3. 补 `is_day = false` + 订正注释（原注释把语义写反：「蘑菇是醒着的，所以 `is_day` 保持 true」）。
4. 同类隐患一并订正：`minigame_09_beghouled_twist.gd`（夜晚前院、注释同样写反；该关未实现，按钮已摘）。
5. 探针加断言：`test/scenarios/probe_beghouled.gd` STEP1 加「`is_day = false`」、STEP2 加「蘑菇不睡觉」
   （蘑菇数只进 detail，避免依赖随机铺场结果）。
6. 带窗口跑 `powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_beghouled -Windowed` → `[BEGHOULED] result=PASS failed=0`。
7. 踩坑沉淀：`docs/参考存档/场景设置.md` §5 新增第 3 条「`is_day` 语义极易写反」。

## 关键决策与理由

- **改关卡脚本字段，不动睡眠组件** —— 组件口径与 `scene_front_night.gd` / `minigame_06_invisi_ghoul.gd`
  一致（后者白天泳池底图也显式写 `is_day = false` 好让寒冰菇能用），错的是关卡漏写字段。
- **顺手修 minigame_09** —— 同样的注释误解，留着等实现三消时会再踩一次。
- **把断言加进已有探针而不是新写探针** —— 已有 `probe_beghouled` 覆盖本关，一行断言即可，成本最低。

## 踩坑

1. **现象**：夜晚前院的关卡里蘑菇睡觉 → **原因**：把 `is_day` 当成「蘑菇醒着」写（实际 true = 白天 = 睡觉），
   且底图写 `FrontNight` 时没人提醒要同步写 `is_day = false` → **正解**：夜晚底图（`FrontNight` / `Fog` / `Boss`）
   一并写 `is_day = false`；白天底图要用蘑菇也要显式写（参考 minigame 06）。
2. **现象**：睡觉不只是冒 zzz → **原因**：`sleep_influence_components` 里的攻击 / 磁力组件会被
   `Sleep` 因子禁用 → **正解**：按玩法失效排查，不要当成纯表现问题。
3. **探针断言别依赖随机结果**：盘面是随机铺的，某一局可能一株蘑菇都没有 →
   **正解**：蘑菇数只进 detail，断言只写确定性的「睡觉数 = 0」。

## 给后来者的最简路径

1. 蘑菇睡觉类问题先查 `MainGameManager.game_para.is_day`（唯一判据在 `component_sleep.gd`）。
2. 夜晚关补 `is_day = false`；改完跑 `-Scenario probe_beghouled -Windowed`（本关已有「蘑菇不睡觉」断言）。
3. 别的关要加同类断言照 STEP1 / STEP2 那两条抄：`not mg.game_para.is_day` + 遍历植物查 `is_sleeping`。
