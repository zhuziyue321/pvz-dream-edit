## 最简路径（步骤）
1. **实机取证**：写一次性探针（参考 `probe_debug_window_hotkey.gd` 的截图段）进拉霸关，悬停探测 + 三张截图（待机 / 滚动中 / 停稳）。证据：悬停菜单中心命中的是拉霸根节点 `@Control@80`（mf=0 STOP）；滚动截图里种子包溢出窗口上下；拉杆是一根横杆、红球脱离。
2. **菜单**：根 Control 只是全屏坐标系 → `mouse_filter = MOUSE_FILTER_IGNORE`（子节点各自保留命中）。
3. **裁剪**：原版 `SeedPacket::Draw` 是 `ClipRect(0,0,mWidth,mHeight)` = 包自身 50x70 矩形 → 转轮容器 `clip_contents = true`；转轮改成「当前 / 下一个」两个槽位，槽内预放 6 种卡面、按需翻可见性（同一符号会同时出现在两个槽位）。
4. **卡面**：`pak/images/seeds.png` 实为原版 `IMAGE_SEEDS` **包底图集**（格号 = `DrawSeedPacket` 的 `aPacketBackground`，普通卡底 `norm.tres` 裁的就是 x=100 那格），里面没有植物立绘 → 植物符号改用 `AllCards.create_card(引用, Catalog)` 的卡面工厂（费用隐藏、全链 IGNORE）；太阳 / 钻石用包底格 5 / 6。
5. **拉杆**：读 `Reanimator.cpp::MatrixFromTransform`——轨道 `kx/ky` 是 skew 角，shaft 各帧 `kx==ky` 即纯旋转，Godot 侧 `rotation_degrees = kx` 口径一致；把 9 帧关键帧（中心 / kx / 缩放）搬成常量表，`_apply_lever_pose()` 插值驱动，`anim_pull` = 帧 0..5（5/36 s）、`anim_return` = 帧 4..0 环绕（5/24 s），pivot = 贴图中心。
6. **验证**：`check_scripts.ps1`（real compile errors = 0，中途抓到一个 `Rect2(int,int,Vector2)` 构造错）→ 复跑取证探针（菜单悬停命中 `MainGameMenuButton`、三张截图全正常）→ `probe_slot_machine` 全绿。

## 弯路 / 踩坑（三段式）
- **试过**：把 `seeds.png` 的格 0..8 当「转轮符号图」配 `SYMBOL_FRAMES = [1,2,4,3,5,6]`。
- **因为**：那张图是包底图集（0 模仿者 / 1 升级 / 2 普通 / 3 弹坑 / 4 刷新箭头 / 5 太阳 / 6 钻石 / 7 潜水 / 8 奖杯），格 1..3 只是底图没立绘，寒冰豆根本没有对应格（配到 4 = 刷新箭头）。
- **结论**：识别一张 pak 图集先找**仓库内的既有消费者**——`norm.tres` 裁的就是它 x=100，顺着这条线立刻定性；植物卡面一律走 `AllCards` 工厂，别手拼。

- **试过**：拉杆 shaft 只做「拉下时 x 向压缩」（pivot 右端）。
- **因为**：reanim 轨的 `kx/ky` 是 skew/旋转口径，shaft 静止 kx=296°、拉下 422°——它是**摆臂**（老虎机手臂摆 126°），压缩模型天然画不出。
- **结论**：reanim 数值搬运会丢「旋转」这种信息；对照 `MatrixFromTransform` 确认 `kx==ky` 时 Godot `rotation_degrees = kx`，再把整条轨搬成关键帧表，别只搬首末两帧。

- **试过**：探针里 `var menu_btn := mg.canvas_layer_ui.get_node_or_null(...)`。
- **因为**：`mg` 是无类型参数，`:=` 推断不出 → Parse Error，整个场景脚本没加载，白跑一轮 180 秒看门狗。
- **结论**：探针里凡从无类型对象取值的一律显式标类型（AI调试通道踩坑表同款）。

## 推荐度与理由
推荐。**价值在两条通用口径**：① `pak/images/seeds.png` 是包底图集（普通卡底 `norm.tres` 也裁它），以后任何要画「种子包」的地方都应该用 `AllCards` 卡面工厂而不是手拼图集格；② reanim `kx` ↔ Godot `rotation_degrees` 的换算口径（`kx==ky` 时纯旋转），本仓还有大量 reanim 贴图手摆的场景（先例 `portal.gd`）。**给后来者**：排查「画面不对」类问题，第一轮就上带截图的取证探针，三个症状一轮全拍下来，比逐个猜省一半轮次。
