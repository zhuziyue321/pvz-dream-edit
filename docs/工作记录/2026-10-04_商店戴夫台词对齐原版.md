# 2026-10-04 · 其它 · 商店里戴夫的台词全部换成原版文本

> **任务类型**：其它
> **推荐度**：**推荐**（下次同类任务照这个走）
> **耗时与成本**：约 1 轮对话，未开游戏（纯文本改动 + 一处运行期生成）
> **验证方式**：免验证 + 已给出人工验证方法（见文末）
> **补充自**：[2026-10-04_商店货架改成一页两行8格.md](2026-10-04_商店货架改成一页两行8格.md)

## 目标

商店里戴夫说的三处话全部对齐原版一代 PC：

1. 开场白（进商店时念的两句）；
2. 挂机时随机念的闲话；
3. 鼠标移到商品上时念的商品描述。

判定标准：文本取自 `data/strings/lawn_strings.txt`（原版中文字符串表），逐句对得上 key。

## 步骤

1. **先定位原版文本在哪** —— `data/strings/lawn_strings.txt` 里搜 `CRAZY_DAVE_20xx`：
   2000~2008 是紫卡 / 模仿者、2010 金盏花幼苗、2011~2014 卡槽扩充、2015~2018 挂机闲话、
   2019~2023 花园工具、2026~2033 清洁车 / 钉耙 / 蘑菇园等。
   这些条目自带 `{NO_SOUND}{NO_CLICK}` 标记 —— 正是「鼠标悬停、不用点击、没有语音」的商品描述口径。
2. **挂机闲话对口径**：`web_fetch https://plantsvszombies.wiki.gg/wiki/Crazy_Dave%27s_Twiddydinkies?action=raw`
   的 Trivia 段明写「玩家在商店发呆时戴夫会随机说这四句」，与 2015~2018 一一对应。
3. **开场白**：原版 `CRAZY_DAVE_303 / 304`（拿到车钥匙 → 杂货店开张）；
   `CRAZY_DAVE_301 / 302`（「你找到了我的车钥匙」）是**捡到钥匙那一刻**的话，
   商店会被反复进入，不能每次都念，所以只取 303 / 304。
4. 改数据层：8 个 `data/dave/dialog_detail/store/*.tres` 的 `text` 逐条换成原版文本
   （坚果包扎术那句原版没有 `{SCREAM}`，顺手把 `is_crazy` 改回 `false`）。
5. 改脚本兜底话术：`goods_garden_tool.gd`（2019~2023）、`goods_plant_card.gd`（2000~2008）、
   `goods_rake.gd`（2028）、`goods_lawn_mover.gd`（2026 / 2027）、`goods_wall_nut_first_aid.gd`（2033）。
6. 卡槽扩充改成运行期生成：原版 7 / 8 / 9 / 10 槽各一句（2011~2014），静态 `.tres` 表达不了，
   于是 `goods_card_slot.gd` 每次都用模板生成，买完再生成一次切到下一档；
   删掉 `card_slot_upgrade.tres` 与 `store.tscn` 里对它的引用（避免两处各写一份）。
7. `store.tscn` 的 `CrazyDave.dialog_resource`：开场白两句 + 挂机四句，全换成原版文本
   （`is_crazy` 只给带 `{SCREAM}` 的 2016「一起来吧！我疯掉啦！！」）。
8. 来源注释写进 `store_manager.gd`（`.tscn` 里不好写注释，指针放脚本里），注明 key 与 wiki 口径。

## 关键决策与理由

- **台词一律以 `lawn_strings.txt` 为准，不凭记忆写** —— 依据
  [AI查wiki避坑.md](../参考存档/AI查wiki避坑.md)：仓库里就有原版字符串表，比 wiki 二手翻译更准。
- **开场白只取 303 / 304，不取 301 / 302** —— 前两句是「捡到车钥匙」当下的话，
  商店解锁后可从主菜单反复进入，每次都念「你找到了我的车钥匙」是错的时间点。
- **卡槽扩充走运行期生成而不是 4 个 `.tres`** —— 档位由存档决定（`get_card_slot_num()`），
  静态资源表达不了；删掉旧的静态 `.tres` 是为了不留「看上去能改、改了不生效」的坑。

## 踩坑

1. **现象**：`Get-Content` 读 `.tres` 出来是乱码（`鑺遍挶鎵╁厖绉嶅瓙鍖?`）。
   → **原因**：PowerShell 默认按 GBK 解 UTF-8。
   → **正解**：用 `read_file` 工具读，或 `Get-Content -Encoding UTF8`。
2. **现象**：`replace_in_file` 报「string not found」。
   → **原因**：我按几轮前的记忆写 `old_str`，中间读到的文件内容已经不是那样
   （`goods_card_slot.gd` 的 `price` 是在 `_refresh_goods_state()` 里赋的，不在 `_ready()`）。
   → **正解**：改同一个文件超过两三次就重新 `read_file` 再改。
3. **现象**：`ext_resource` 的 `uid=` 里还有一段 `uid://`，我第一次写 `old_str` 漏了。
   → **正解**：`.tscn` 的引用行整行复制，别手打。

## 给后来者的最简路径

1. 在 `data/strings/lawn_strings.txt` 里搜 `CRAZY_DAVE_`，按商品对上 key。
2. 商品描述 → 改 `data/dave/dialog_detail/store/*.tres`；脚本兜底话术 → 改对应 `goods_*.gd`。
3. 商店戴夫本人的话（开场白 / 挂机）→ 改 `src/store/store.tscn` 里 `Resource_2rser` 那两个数组。
4. 跑 `probe_store_rules` 确认商店还能正常开；台词本身只能靠进商店肉眼确认。

## 人工验证方法（本次未开游戏）

1. 通关 3-4 拿车钥匙 → 自动进商店：戴夫念「疯子戴夫的闪闪亮杂货店正式营业了！」
   →「来瞧一瞧！你是否找到了一些你喜欢的东西！」，点两句后开始挂机。
2. 在商店里不动鼠标等约 10 秒：戴夫随机念「杂货店的商品都已经上架了！」/
   「一起来吧！我疯掉啦！！」（发疯动画）/「我的价格很不可思议吧！！！」/「我吃掉在地上的东西。」。
3. 鼠标逐个划过商品：卡槽扩充念「增加的卡片槽，将让你在每关可选7种植物！」（买一次后变 8）；
   紫卡念「把这些种在你的…上，把它变成…！」；蘑菇园 / 水族馆 / 智慧树 / 金盏花幼苗 /
   泳池清洁车 / 屋顶清洁车 / 钉耙 / 坚果包扎术 / 花园工具各自念对应的原版那一句。
