# 2026-10-20_DLC素材误用清理

> **本次任务**：扫 `mods_builtin/dlc/` 找误用素材，修掉「单帧烟被当三帧播」+ 1504 处大小写不一致，清掉零引用的死素材
> **耗时 / 轮次**：1 轮静态扫描（Python 脚本）+ 1 轮批量改写 + 3 条探针，未开编辑器窗口
> **推荐度**：推荐（扫描脚本是一次性的，结论已固化进 `dlc/README.md` §7.1）

## 目标

排查 DLC 模组里「素材被用错 / 白占地方」的情况，尤其是 `particles/`（56 个 PopCap XML），
修掉能修的、清掉没用的。

## 最简路径（步骤）

1. **静态扫描代替肉眼**：Python 遍历 `mods_builtin/dlc/`，建「小写相对路径 → 磁盘实际名」映射，
   再从 `.tscn/.tres/.gd` 里抽所有 `res://…` 与相对 `preload()`，一次产出四类问题清单：
   悬空引用 / 大小写不一致 / 孤儿素材 / 跨角色借图。比 `rg` 一处处看快得多（`rg` 输出会被截断）。
2. **粒子参数**：`pultshroom/bullet_pultshroom_spore.tscn` 与 `mortarshroom/bullet_mortarshroom_shell.tscn`
   的 `CanvasItemMaterial` 删掉 `particles_animation / h_frames / v_frames / loop` 四项
   （贴图 `pak/particles/PuffShroom_puff2.png` 是 21×21 **单帧**，3 帧切帧会切成 3 条 7×21 细条）。
3. **批量修大小写**：脚本把 191 个文件里的 1504 处路径改写成磁盘实际名（只改引用，不改文件名，
   所以 `.import` 不受影响）。跳过 2 处（`.gd` 注释里的 `<角色>` 占位符）。
4. **清死素材**：`particles/`（56 个 XML，Godot 不解析、0 引用）+ `reanim/VineNutLegacy/` 下 5 张 PNG
   （场景引的是 `reanim/Vinenut/` 同名图）。**先备份到仓库外再删**（整个 `mods_builtin/dlc/` 未入库，删了 git 救不回来）。
5. **验证**：`test/check_scripts.ps1` → `real compile errors = 0`；
   手跑 `probe_dlc_pultshroom` / `probe_dlc_voltshroom` / `probe_dlc_mortarshroom` 三条，均 `result=PASS failed=0`。

## 弯路 / 踩坑（三段式）

- **试过**：直接用 `run_autopilot.ps1 -Scenario …` 跑探针。
- **因为**：仓库里有一个昨天启动的 Godot 进程（pid 18548），跑批直接 `result=STALE_PROCESS` 退出，
  而脚本明确写了「别 kill，可能是用户未保存的编辑器」。
- **结论**：照 [DLC植物导入](../../docs/参考存档/DLC植物导入.md) §7.2 的手跑姿势，自己建临时
  `APPDATA` 与临时目录再起 Godot（不与共享输出文件打架），就能拿到 `[DLC] result=PASS`。
- **试过**：把「未被引用」的 PNG 一律当垃圾。
- **因为**：`reanim/` 下大量 PNG 是**还没转换的动画段 / 变体**（如 `ChillyPepper` 7/23、`PickledPepper` 25/40），
  删了将来转段就没图了。
- **结论**：只删「同内容副本且场景引的是别处同名图」的（`VineNutLegacy/`），其余只报不动。
- **试过**：想当然认为 `reanim/<角色>/` 里有别的角色的部件图（`Peashooter_*`、`Queencactus_*`、`Tallnut_*`）是放错目录。
- **因为**：DLC 原包的 reanim 就是复用原版部件，目录里带这些图是正常的。
- **结论**：这类只统计不处理（`Peashooter_*` 在 4 个角色目录各存一份 = 冗余，不是误用）。

## 推荐度与理由

推荐。静态扫描这一套（建路径映射 → 比对 → 分类）能一次性把「悬空 / 大小写 / 孤儿 / 跨目录借图」
四类问题全捞出来，之后任何一次素材整理都能照抄。

要点：

- **大小写不一致是导出才炸的雷**：Windows 开发时一切正常，导出 pck 后 `res://` 查找区分大小写，
  16 株里 11 株会大面积白图（bonkchoy 167/182、voltshroom 117/144 最严重）。现在已归零。
- **特效素材别互相照抄参数**：96×32 的三帧命中图（蜜蜂 / 尖刺 / 箭）与 21×21 的单帧烟
  参数不通用，已在 `dlc/README.md` §7.1 写了警示。
- 特效 PNG 的实际尺寸 / 帧数与 README §7.1 声明**全部一致**，`*_FRAMES` 常量也对得上，这块没问题。
