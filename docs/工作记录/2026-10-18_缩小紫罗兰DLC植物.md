# 2026-10-18 缩小紫罗兰（DLC 植物）

- 面向 AI Agent：这是**流程记录**，不是规则。要新增同类「一次性控制植物」时看本文件即可；
  规则与硬约束仍以 `docs/项目规范.md §1` 与 `docs/参考存档/README.md` 为准。
- 结论：已实现并**跑通探针**（`test/scenarios/probe_dlc_shrinkingviolet.gd`，`result=PASS failed=0`）。
  编译门禁 `test/check_scripts.ps1` 通过（前提：见下方「踩坑②」，共享热点文件不被并发改坏）。

## 做法（最简路径）

1. **效果落在僵尸身上，不落在植物身上**：照寒冰菇 `ZombieManager.ice_all_zombie()` 的写法，
   在 `zombie_manager.gd` 加 `shrink_all_zombie(duration, scale, damage)`，遍历 `all_zombies_2d`
   对每只僵尸调 `character_base.gd` 新增的 `be_shrink(...)`。
   - `be_shrink` 用 `create_tween()` 把 `body.scale` 补间到 `origin * scale_factor`；
   - 通过新增的 `E_AttackValueFactor.Shrink` 因子把啃食伤害压到 `damage_factor`（普通/梯子僵尸都走 `update_attack_value`）；
   - 用现成的 `all_timer[E_TimerType.Shrink]` 计时，到点恢复缩放与伤害因子。
2. **植物做成「一次性」**：DLC 植物照 `pultshroom` 的骨架（`AnimComponent` 换 `component_anim_empty` +
   `AnimLib` 合成 idle/bloom 两段），`ready_norm()` 里播 `bloom` 并同步调 `shrink_all_zombie`，
   `animation_finished(bloom)` 后调 `character_death_disappear()` 让自身消失（与寒冰菇/樱桃同类）。
3. **登记**：`dlc_mod.gd` 加常量（0 阳光 / 7.5 秒冷却 / 卡面）、场景预加载、`install()` 配方数组、
   图鉴条目 + 卸模清理。普通卡，不是紫卡。

## 踩坑

① **探针基线必须在「种下之前」采集**。一次性植物在 `ready_norm()` 里**同步**施放缩小，
   种下后再读 `body.scale` / `curr_attack_value_per_sec`（当时叫 `..._per_min`，2026-10-23 改名）拿到的已经是「缩小后」的值，
   会误判成「没生效」。正确做法：摆好僵尸、种紫罗兰**之前**先记基线。
   另外直接校验攻击组件里的 `attack_value_factor[Shrink]` 比只看换算出的攻击值更稳
   （速度因子变动也会改攻击值，容易假阳/假阴）。

② **`dlc_mod.gd` 是并发热点**。同时有别的 agent 在往里疯狂加植物（glowshroom / lemonade / aloe …），
   会短暂处于半成品状态：`install()` 调了 `_build_xxx_recipe()` 但函数还没定义 → 整包 mod 加载失败
   → 所有 `probe_dlc_*` 一起挂。**这不是自己的锅**，等一下它补完即可；不要顺手去改别人的新植物。

③ **`ampliflower_plant.gd` 的 `_exit_tree()` 裸 `super()`** 是 parse error：
   父类脚本链（`Plant000Base → … → Node`）没有脚本级 `_exit_tree()`，GDScript 对
   「父类脚本未定义的 virtual」调 `super()` 会直接报错，拖垮整包 mod。修法是**去掉 `super()`**
   （Node 的离场通知仍会照常派发）。本次为解阻塞临时修了这一处，属他人文件，知会一下。

④ 动画节点**不能再叠一层缩放**：每部件原版缩放已在动画 `scale` 轨道里。
   摆放位置用运行期 `AnimationFrameUtil.get_content_rect()` 实测（本株初估 `(-35, -75)` 恰好可用，
   内容 68.8×71.2、底边 +3.7，贴地）。

## 推荐度

高：一次性控制植物的通用骨架（寒冰菇式全场效果 + 自写 `be_xxx` + 挂状态到僵尸 + 播一段即消耗）
可直接复用到其它「全屏控制」DLC 植物。探针「种下前采基线」这条尤其值得记，否则很容易误判。
