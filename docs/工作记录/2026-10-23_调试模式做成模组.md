# 2026-10-23_调试模式做成模组

> **本次任务**：把「调试模式」（控制台那个 `debug_mode` 勾选框所管的一整套）从左本体搬进内置模组 `ModIds.DEBUG`
> **耗时 / 轮次**：1 轮；**没开游戏**（编译门禁 + 6 支无头探针）
> **推荐度**：推荐（改动面集中在 6 个本体文件 + 1 个新模组；探针已锁住「关掉 = 窗口/解锁/追踪一起撤」）
> **补充自**：无

## 目标

`ConsoleBuiltinEntries` 里有一条「调试模式」，打开后：僵尸卡片（含僵王）可用、四株原版流程拿不到的植物解锁、
`EventBus` 开始记录被 push 过的事件名、Ctrl+Q 调试窗口可呼出。它长在本体里，关掉只能在每个读它的地方各判一次
（`GlobalGameState.is_debug_mode` / `ConsoleBuiltinEntries.DEBUG_MODE_KEY` / `is_appended_plant` 的名单）。

按仓库判据「原版没有 → 做成模组」，把它整块搬进 `mods_builtin/debug/`：**关掉 = 不装载**，本体零节点、零分支。

## 步骤

1. **框架加一个钩子**：`ModBase.on_session_reloaded()` + `ModManager.notify_session_reloaded()`，
   由 `Global.reload_session_for_current_user()` 在读档之后调用 —— 存档会覆盖 `curr_plant` / `selected_cards`，
   而模组并没有被卸载（开关没变），只靠 `install()` 补不回来（调试模组、以后任何写存档态的模组都要用）。
2. **本体留通用口子、删掉调试概念**：
   - `GlobalGameState`：删 `is_debug_mode` / `apply_debug_mode()` / `_sync_debug_mode_plants()`；
     加 `set_runtime_zombie_card_enabled()`（`is_zombie_card_enabled()` = 总开关 or 运行期开关），
     `_sync_debug_mode_zombie_cards()` 改名 `_sync_runtime_zombie_cards()`；
   - `Global`：删 `debug_window` 字段 / `_spawn_debug_window()` / `is_debug_mode_on()`；
   - `ConsoleBuiltinEntries`：删 `DEBUG_MODE_KEY` 与 `debug_mode` 条目（内置条目 12 → 11）；
   - `EventBus.is_trace_pushed_events`：从「getter 读 `is_debug_mode`」改成普通 bool，由模组置位；
   - `ConstPlantUnlock.DEBUG_MODE_PLANT_TYPES` 改名 `APPENDED_PLANT_TYPES`（原版流程拿不到的植物清单，
     只剩「别当常规植物排」这一个用途），`AllCards` / `图鉴` 同步。
3. **新模组** `mods_builtin/debug/`：入口 `debug_mod.gd` 一处 `_set_debug_mode()` 管全部副作用
   （僵尸卡开关 / 四株 unlock+lock / 事件追踪 / 造+释放窗口）；`on_session_reloaded()` 与
   `install_to_main_game()` 各补一次解锁。
4. **调试窗口整份搬**：`src/ui/debug/` → `mods_builtin/debug/`，去掉 `class_name` 与「调试模式没开就只打提示」
   的分支（模组关着时窗口根本不存在），窗口里 `toggle_window()` 只做开 / 收。
5. **探针同步**（全部改走 `ModManager.set_mod_enabled(ModIds.DEBUG, ...)`）：
   `probe_bowling_debug_mode` / `probe_event_trace` / `probe_selectable_plant` / `probe_almanac_extra_page` /
   `probe_debug_window_hotkey`（顺带加无头跳过截图 + 关掉模组后窗口被释放）；`probe_console_registry` 的
   内置条目数 12 → 11。

## 弯路 / 踩坑（三段式）

1. **`ModBase` 在模组脚本里没有名字** —— 第一次写 `ModBase.create_detail_label(...)` 直接解析失败
   （`Parse Error: Identifier "ModBase" not declared`）。模组入口的 `extends "res://src/mods/mod_base.gd"`
   只是继承，基类没有 `class_name`；要静态调用它的方法必须 `const ModBase := preload("res://src/mods/mod_base.gd")`
   （现役模组都这么写）。
2. **`Global._ready()` 里 `ModManager` 可能还是 null** —— autoload 顺序是 Global(2) → … → ModManager(10)，
   启动时那次 `reload_session_for_current_user()` 跑在 ModManager 的 `_ready` 之前，直接调
   `ModManager.notify_session_reloaded()` 会空引用；加 `if ModManager != null` 保护（启动时模组还没装，
   本来也不需要补）。
3. **无头跑 `probe_debug_window_hotkey` 会卡到看门狗超时** —— 它原来无条件
   `await RenderingServer.frame_post_draw` 再截图，无头没有渲染帧，这个信号永远不发（不是本次引入，顺手修了）：
   加 `DisplayServer.get_name() == "headless"` 分支跳过截图。

## 边界（本次没搬的）

`Ctrl+D`（通关本关 / 通关所有冒险 / 打开存档文件夹 / 解锁所有商品）与 `Ctrl+K`（清场）**不在本模组**：
它们是「调试快捷键」，与「调试模式」这个判据无关，仍在 `Global` / `MainGameManager` 里。

- 无头探针（全部 `result=PASS failed=0`）：`probe_bowling_debug_mode` / `probe_event_trace` /

  关掉模组 → 窗口与僵尸页一起消失。

## 最简路径

要再搬一个「本体开关」成模组：先确认它读的是哪个状态 → 给那个状态留一个**通用 setter**（别叫原功能名）→
模组 `install()` / `uninstall()` 各调一次 → 存档态（`curr_plant` / `selected_cards` 这类）再在
`on_session_reloaded()` + `install_to_main_game()` 各补一次 → 最后把探针改成 `ModManager.set_mod_enabled()`。
