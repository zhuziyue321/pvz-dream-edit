# 2026-10-15 · 新增内容 · 招笑版模组第三只植物：樱桃炸弹 → 「烟熏樱桃」（不炸血、上 30 秒烟熏）

> **任务类型**：新增内容（模组 + 本体两个通用口子）
> **推荐度**：**推荐**（「让一只角色临时被同类索敌」照这个走：本体那句 `is_enemy` 上一次早退就够，别走 `is_hypno`；探针那四条坑也都能直接抄）
> **耗时与成本**：约 6 轮（含 3 轮口径确认 + 4 次探针排错），未开窗口（无头探针 + 门禁）
> **验证方式**：免验证 + 已给人工验证方法（无头验得到逻辑，观感需人工看一眼）
> **补充自**：[2026-10-15\_招笑版傻豆射手.md](2026-10-15_招笑版傻豆射手.md)（同一只模组的上一只植物，接管手法与探针写法都照它）

## 目标

樱桃炸弹改成「烟熏樱桃」，四条：

1. 改名；
2. **不造成伤害**（爆炸表现照旧，一滴血不炸掉）；
3. 给爆炸范围内的僵尸上 **30 秒烟熏**；
4. 烟熏效果 = **遇到植物时站着不动、不啃**（且要播**待机站姿**，不是定格在啃咬那一帧）+ **可以被同类索敌**。

用户中途补了两条口径：索敌要「只有僵尸能锁定它、**玩家植物照旧打它**」（于是排除了 `is_hypno` 那条换边路线）；
站立时「不是一动不动，而是播**选卡界面那种待机动画**」。

## 步骤

1. 先摸清现有能力（读 `component_bomb_base/norm.gd`、`component_detect.gd`、`bullet_camp_config.gd`、
   `component_move.gd`、僵尸动画状态机）。**结论一：本体早已不用碰撞层区分敌我**，
   敌我只有一句 `BulletCampConfig.is_enemy(camp, 目标) = get_owner_camp(目标) == 敌对阵营` ——
   所以「加一个临时植物碰撞箱就能被僵尸啃」**在今天的代码上不成立**（物理上本来就重叠，是阵营把它否了）。
   而阵营只有**一个值**：想被僵尸索敌 ⇒ 必须算植物方；想被玩家植物打 ⇒ 必须算僵尸方 —— 互斥。
2. 确认「不造成伤害」最省的做法：`bomb_value = 0`（伤害管线对 `amount <= 0` 直接取消，
   爆炸表现 / 音效 / 范围判定一概不动）。
3. 确认「站立播待机」的路：僵尸动画状态机**没有 `Walk→Idle` 转移**（Idle 只能从 `Start` 进），
   所以不能只置 `is_idle`；正解是**置 `is_idle = true` + `playback.start(&"Idle")` 硬跳**，
   跳过去之后 `Idle→Walk` 的条件被压住 ⇒ 站得住；放开 `is_idle` 本体自己就走回 Walk。
4. **第一版实现（诱饵路线，用户先定的方案）**：
   - 本体加一株**工具植物「隐形植物」**（`PlantIds.INVISIBLE` + `plant_invisible.tscn/gd`）：
     看不见、不攻击、只留一副能被僵尸索敌的受击框，`damage_link` 可把伤害转给绑定角色；
   - 模组给每只被烟熏的僵尸脚下挂一株诱饵（`init_plant` + **没入树的假 `PlantCell`** 当 lane 载体
     + 把诱饵登记进那个假格子的 Norm 槽，否则本体索敌问「这一格该打哪一株」会拿到空值、僵尸不会停）。
   - 探针跑通：诱饵被索敌 ✓、诱饵不掉血 ✓、宿主掉血 ✓。
5. **改成口子路线（用户要求的最终形态）**：
   - 本体加 `Character000Base.is_enemy_to_all_camps` + `BulletCampConfig.is_enemy()` 里一句早退
     —— 「临时谁都能打它」：**只改「能不能被打」**，归属阵营 / 朝向 / 表现 / 死亡计数全不动；
   - 模组把诱饵那一段删掉（`_spawn_decoy` / `_decoy_scene` / `_remove_decoy` + 诱饵常量与设置项），
     改成 `_ready` 里置位、`stop_smoke()` 里还原各一行；
   - 隐形植物**留在本体当调试 / 工具植物**（它自己的能力照旧，只是本模组不再用它）。
6. 探针 `test/scenarios/probe_zhaoxiao_cherry.gd`（31 条断言）跑通 `failed=0`；门禁 PASS 0 error。
7. 文档：机制口径写进 [模组机制.md §6.8.3](../参考存档/模组机制.md)（模组侧实现 + 两个本体口子 + 弯路）。

## 关键决策与理由

- **「被同类索敌」走 `is_enemy` 早退，不走 `is_hypno`** —— 阵营只有一个值，
  `is_hypno`（换边）会让**玩家植物也不再打它**（还有转身 / 染色 / 死亡按魅惑登记等连带）。
  在 `is_enemy()` 上加一句早退，能同时满足「僵尸打得中」与「玩家植物照旧打得中」，且不动其它任何判定。
- **状态挂在僵尸身上，不挂在植物上** —— 樱桃炸弹爆完当场就死（动画方法轨道 `bomb_once()` → `character_death()`），
  挂在它身上会跟着消失。
- **「不啃」用「伤害压 0 + 动画换待机」而不是禁用攻击组件** ——
  禁用攻击组件会走 `attack_end()`，僵尸**恢复走路**（不是站住）；而要「站住」靠的正是攻击组件那条
  `IsAttack` 移动因素。所以保留攻击状态、只把它算出来的伤害摁成 0。
- **本体只留通用口子、不留模组专属分支** —— 两个口子（隐形植物 / `is_enemy_to_all_camps`）
  本体自己一行都不用，默认行为零变化；这与仓库既有的 `set_runtime_plant_stat` 等同一套做法。

## 踩坑

1. **`AnimationNodeStateMachinePlayback.play()` 在 Godot 4 已改名为 `start()`**
   现象：运行期 `Nonexistent function 'play' in base 'AnimationNodeStateMachinePlayback'`（编译门禁抓不到）。
   **正解**：`playback.start(&"Idle")`。
2. **刚 `add_child()` 出来的 `Area2D`，`get_overlapping_areas()` 是空的**
   现象：爆炸框里明明有两只僵尸，量出来 0 只 ⇒ 烟熏一个都没派出去。
   原因：Area2D 的重叠表要过**一个物理帧**才更新。
   **正解**：种下之后 `await` 一帧再调 `bomb_once()`。
3. **探针踩「僵尸进家」→ 关卡收摊 → 之后全是「previously freed」且 `await` 再也不回来**
   （症状是在看门狗 300 秒超时里结束，极难查）。
   三个原因叠在一起：① 用了**教程关 1-1**（探针一「种下第一株植物」就推进教程流程、
   放出站在房子边上的教程僵尸）；② 没关房子；③ 僵尸**一出生就超出「僵尸可存在范围」（x 上限 1000）**，
   波次一刷新就被清掉，探针还拿着旧引用。
   **正解**：换无教程关（用 1-10）+ `MainGameHome.disable_home()`（⚠️ 房子在**背景子场景**里，
   要从场景根按类型找，不是 `MainGameManager` 的子节点）+ 僵尸**出生后立刻**挪进场内 +
   每步等完先做一次「引用还在吗」的快速失败。
4. **两只僵尸同速同行 ⇒ 距离永远不变**
   现象：把攻击者摆在受害者右边 90 像素、等 6 秒，它一直没索敌到人。
   原因：两只都在以同样速度往左走，越走越追不上（索敌框只有身前十几像素）。
   **正解**：要验索敌就把攻击者**摆进索敌范围内**，别指望它自己走过来。
5. **别的 agent 在同机跑探针 ⇒ 共享临时目录打架**
   现象：`run_autopilot.ps1` 报 `The process cannot access the file because it is being used by another process`，
   或重定向出来的文件里是**别人那次**（`probe_plant`）的输出。
   原因：跑批脚本的中间文件固定在 `%TEMP%\pvz_autopilot\`，两个实例共用。
   **正解**：并发时别用 `run_autopilot.ps1`，改成自己起 Godot 并**换一个 APPDATA**：
   `$env:APPDATA=<自己的临时目录>; godot --headless --path <项目> -- --scenario=res://test/scenarios/xxx.gd`
   （与 `check_scripts.ps1` 第二关同一套做法）。

## 给后来者的最简路径

1. 要「**同类能索敌它、玩家植物照旧打它**」：在 `Character000Base` 加个 bool（如 `is_enemy_to_all_camps`），
   在 `BulletCampConfig.is_enemy()` 里目标非空且该字段为真时 `return true`；谁置位谁还原。
   **别**用 `is_hypno`（那是换边）。
2. 要「**僵尸站着不啃**」：**别**禁用攻击组件（会恢复走路）。保留攻击状态（它自带 `IsAttack` 停住），
   把 `curr_attack_value_per_sec`（当时叫 `..._per_min`，2026-10-23 改名）**每帧**摁成 0；动画要换姿势就 `is_idle = true` + `playback.start(&"Idle")`。
3. 要「**往空气里扔一个可被索敌的东西**」：用本体工具植物 `PlantIds.INVISIBLE`（隐形植物），
   它是 `IsNorm` 才有受击框；给它一个**没入树的 `PlantCell.new()`** 当 lane 载体，
   并把植物登记进那个假格子的 Norm 槽。
4. 探针侧：别用 1-1、先关房子、僵尸出生即挪进场、每步做存活检查、收尾报 `checks=N`；
   并发时段换 `APPDATA` 自己起 Godot。

## 人工验证方法

打开游戏（模组页面开「招笑版」）→ 随便进一个白天关 → 种一株樱桃炸弹：

- 名字应显示「烟熏樱桃」（图鉴 / 商店卡说明也一起变）；
- 它炸的时候**僵尸一滴血都不掉**，但爆炸动画 / 音效照旧；范围内的僵尸会被"烟熏"（30 秒）；
- 被烟熏的僵尸走到植物前面会**站着不动**（摆出待机姿势，不是啃咬姿势），
  盯着它看一会儿那颗植物**一点血都不掉**；把植物铲掉 / 让它被吃掉之后，它自己继续往前走；
- 被烟熏的僵尸附近再放一只僵尸（或等后面波次的僵尸走过来）：**同类会停下来啃它**，
  它自己**掉血**（被同类吃掉），而你种的植物**照旧能打中它**；
- 30 秒后（或重开一局）一切恢复原样：僵尸照常啃植物、同类不再互相啃。
