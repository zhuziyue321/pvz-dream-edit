# 2026-10-01 · 文档规范 · 每个显眼目录放 README / AGENTS 指针，让任何 Agent 都能注意到 `docs/`

> **任务类型**：文档规范
> **推荐度**：**推荐**（下次同类任务照这个走）
> **耗时与成本**：约 2 轮对话，未开游戏（纯文档改动）
> **验证方式**：免验证（只新增 / 修改 md，不触达玩法行为）
> **人工验证方法**：打开任意一份指针文件，点其中的链接能跳到 `docs/` 对正文；`grep -l "AGENT-DOC" -r .` 能列出全部指针文件
> **补充自**：无

## 目标

1. 让 Agent **在仓库任何目录**里都能一眼看到「规则在 `docs/`，去那儿取」。
2. `docs/README.md` 成为**全仓库文档总目录**（顶层管理类 + `docs/工作记录/` 机制与流程记录 + 各目录指针清单）。

## 步骤

1. 确认目录归属：机制 / 内容类文档（`*.md`）**留在 `docs/工作记录/`**，不迁到 `docs/` 顶层（避免与并行 Agent 抢文件，也避免一次改几十处路径引用）。
2. 新建指针文档：`docs/AGENTS.md`、`src/`、`src/`、`data/`、`animation/`、`test/`、`addons/`、`shaders/` 各一份 `AGENTS.md`（面向 Agent）+ `README.md`（面向人）。
3. 每份指针只写三件事：本目录装什么（含子目录速查表）、动手前必读哪几份 `docs/` 文档、回链仓库入口 —— **不复制规范正文**。
4. 建索引：`docs/README.md` 新增 §1.2「各目录内的 README / AGENTS 指针」表；根 `AGENTS.md` 新增 §6 同样的表 + 路由表加一行；根 `README.md` 补一行。
5. 维护约定落文档：`docs/README.md` §4 与根 `AGENTS.md` §5 各加一条「新增一级目录要补指针并登记」。

## 关键决策与理由

- **指针不复制规则** —— 两处写必然漂移；规则只在 `docs/` 正文里改，指针永远不用同步。
- **不迁 `*.md` 到 `docs/` 顶层** —— 收益（位置显眼）已被 §1.2 总目录覆盖，成本（几十处路径替换 + 与并行 Agent 冲突）不划算。
- **每个目录放两份（`AGENTS.md` + `README.md`）** —— 一份面向 Agent（带 `<!-- AGENT-DOC: pointer -->`，可被 `grep` 发现），一份面向人，互不干扰。

## 踩坑

1. **中途把 `*.md` 移到了 `docs/` 顶层** → 用户澄清「机制类都留在工作记录里，只用把目录提出来」 → **正解**：只提「目录（索引）」，机制文档原地不动；已用 `Move-Item` 移回，未做任何路径替换，无残留引用错误。
2. **改 `docs/README.md` 时按旧内容做字符串替换失败** → 文件被其它 Agent 排版过（表格对齐变了） → **正解**：替换前先 `read_file` 取当前内容，别凭记忆拼 `old_str`。

## 给后来者的最简路径

1. 新建 / 改目录 → 在该目录放 `AGENTS.md`（`<!-- AGENT-DOC: pointer -->` + 元信息头 + 子目录表 + 必读链接）+ `README.md`（3 行，回链 `AGENTS.md` 与 `docs/`）。
2. 在 `docs/README.md` §1.2 与根 `AGENTS.md` §6 各登记一行。
3. 完事 —— 不要动规范正文，不要迁文件。
