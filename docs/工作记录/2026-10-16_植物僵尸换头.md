# 2026-10-16_植物僵尸换头

> **本次任务**：植物僵尸不再「在僵尸头顶另插一棵完整植物」，改成**用植物的头取代僵尸自己的头**，并让它跟着僵尸的摇头 / 点头一起动。
> **耗时 / 轮次**：约 20 轮工具调用；开游戏 2 次（`-Windowed` 截图核对，含一次路径写错的返工）
> **推荐度**：推荐（改 2 个文件 → 14 只全部生效；坑集中在「动画 track 会覆盖 visible」与「组件比宿主先 ready」）

## 目标

`docs/参考存档/植物僵尸.md` 记的旧实现是「僵尸头顶（`Body/BodyCorrect` 下）叠一棵静态植物」——
视觉上是**头上方多了一棵小植物**，而不是原版那种「僵尸的头就是植物」。
本次要把它换成真正的换头，且尽量少动场景（14 个植物僵尸场景共用 `zombie_norm.tscn`，不该逐个改）。

## 最简路径（步骤）

1. 先弄清僵尸的头长什么样：**不是 reanim、是普通节点**——
   `Body/BodyCorrect/Anim_head`（容器）→ `Anim_head1`（Sprite2D，贴图 `Zombie_head.png`，`centered = false`）。
   头的位置 / 旋转 / 缩放全部由 `.tres` 动画里 `Body/BodyCorrect/Anim_head/Anim_head1:position|rotation|scale` 驱动。
2. **藏僵尸自己的头**：`Anim_head1.self_modulate.a = 0`；
   下巴 / 舌头 / 胡子 / 头发四个**外层容器** `visible = false`
   （`Anim_head2`、`Anim_tongue`、`Zombie_mustache`、`Anim_hair`——与 `ResourceBodyChange` 那套「掉头」用同一组路径）。
3. **植物挂到 `Anim_head/Anim_head1` 下面**（跟随头部动画），节点参数：
   `position = 头贴图中心（texture.get_size() / 2）+ head_offset`、
   `rotation = -头节点.rotation`、`scale = head_scale / |头节点.scale.x|`（抵消头节点自己的 0.798 与 12° 倾斜）。
4. **挂载时机**：`owner.ready.connect(_replace_zombie_head, CONNECT_ONE_SHOT)`（`owner.is_node_ready()` 时直接调）。
5. 配置表 `zom_botany_config.gd`：`sprites` **只留植物的头、去掉茎**；`head_offset` / `head_scale` 语义改成
   「相对僵尸头贴图中心的微调 / 植物最终大小」。
6. 核对（临时探针，跑完即删）：`Global.game_para = minigame_01_zom_botany.new()` → 切 `MainSceneRegistry.MainScenes.MainGameFront`
   → `main_game_start()` → 按行 `zombie_manager.create_norm_zombie(...)` 摆出全部 14 只 → 禁 `move_component` 钉在原地
   → `root.get_texture().get_image()` 截图，并**按每只植物头的 `get_global_transform_with_canvas()` 坐标裁 150×150、
   拼成 7×2 九宫格放大 2 倍**——一张图看完全部换头效果。
7. 门禁：`test/check_scripts.ps1`（`real compile errors = 0`）+ 无头跑 `probe_zom_botany`（新增一条「场景里有可被替换的僵尸头节点」断言）。

## 弯路 / 踩坑（三段式）

- **试过**：把 `Anim_head1` 当作 `Body/BodyCorrect` 的直接子节点（`^"Anim_head1"`）。
- **因为**：以为它跟 `Anim_tongue` / `Anim_hair` 一样是直接挂 `BodyCorrect` 的——实际它在 `Anim_head` 容器里，路径少了一层。14 只全部打 `植物僵尸找不到僵尸头节点`。
- **结论**：路径写 `^"Anim_head/Anim_head1"`；顺便把这条路径写进 `probe_zom_botany` 的静态断言，改场景结构时能提前发现。

- **试过**：在 `component_ready()` 里直接隐藏僵尸头。
- **因为**：宿主 `Zombie001Norm.ready_norm()` 里还有一步 `_random_sprit_appear()`，会把 `Anim_tongue` / `Anim_hair` **随机**设成 visible；而 Godot 先跑子节点 `_ready()`（组件）再跑父节点（宿主），刚藏好的又被打开。
- **结论**：改挂 `owner.ready`（宿主整个 `_ready()` 走完才执行）。

- **试过**：用 `Anim_head1.visible = false` 藏头、或直接隐藏外层 `Anim_head`。
- **因为**：动画里有 `Anim_head/Anim_head1:visible` 这条 track（死亡动画把它设成 false），下一帧就被还原；而隐藏外层 `Anim_head` 会把**挂在它下面的植物一起**隐藏（`visible` 是继承的）。
- **结论**：只有 `self_modulate.a = 0` 两全——不牵连子节点、也没有动画 track 覆盖它。

- **试过**：核对时直接看整屏截图。
- **因为**：僵尸在 800×600 里太小，看不清「植物接在脖子上的位置对不对」。
- **结论**：在探针里按每只植物头的屏幕坐标裁小块拼九宫格（`Image.get_region` + `resize(INTERPOLATE_NEAREST)` + `blit_rect`），比让人对着整屏图猜快得多。

## 推荐度与理由

**推荐**。这套换头把「头顶植物」那一步的取舍（贴图位置靠估、`head_offset` 不好调）一次解决掉了：

- 改动面小：`component_zombie_plant.gd` + `zom_botany_config.gd` 两个文件，14 只僵尸 / 两关全生效，场景一个没动。
- 挂点选头节点之后，植物**自动跟随**走路摇头与啃咬点头，不用同步 transform。
- 位置默认「贴图中心对僵尸头中心」，`head_offset` 只在个别看起来不齐时微调。

后来者要注意两点：① 任何「隐藏某个被动画驱动的节点」的需求，先看动画里有没有那条 `visible` track；
② 组件里做**外观类**初始化时，记住组件比宿主先 ready，宿主 `ready_norm()` 里的随机外观会覆盖你。

已知边界（没做）：僵尸死亡掉出来的**仍然是僵尸头**（`Body/NodeDrop/Node2D_Head_Drop` 那套精灵是普僵的），要掉植物头得另做一套掉落节点。
