# 2026-10-17_平衡模组改名生态版

> **本次任务**：把「原版平衡」模组改名为「生态版」（显示名 / id / 目录 / 文件名 / 探针 / 文档全链路）
> **耗时 / 轮次**：约 2 轮对话，没开游戏（纯改名，编译门禁兜底）
> **推荐度**：推荐（先全仓 grep 旧名、git mv 保历史、历史流水只追加不改写）

## 目标

模组页面上的名字从「原版平衡」改成「生态版」；为免「名叫生态版、目录还叫 balance」的漂移，
连同内部标识一次改全：id `&"balance"` → `&"eco"`、目录 `mods_builtin/balance/` → `mods_builtin/eco/`、
四个脚本 `balance_*.gd` → `eco_*.gd`、探针 `probe_balance_mod.gd` → `probe_eco_mod.gd`。

## 最简路径（步骤）

1. 全仓 grep `balance|原版平衡`（大小写都搜）拿到全部引用点，按「代码 / 文档 / 历史流水」分三类；
2. `git mv` 目录与文件（`.uid` 跟着 `.gd` 一起改，Godot 按文件名认 uid），保留重命名历史；
3. 改代码：`mod_ids.gd` 常量 `BALANCE` → `ECO`、`mod_manager.gd` 的 `MOD_SCRIPT_PATHS` 一行、
   入口脚本 `get_mod_name()` / `get_mod_id()` / preload 路径、探针的 `ModIds.ECO` 与 `[ECO]` 标签；
4. 改文档：`mods_builtin/README.md` 目录表一行、`docs/参考存档/模组机制.md` §6.6
   （标题 / 目录路径 / 文件表 / `[eco]` 存档段 / 探针路径）；
5. 本体两处口子注释（`src/items/plant_cell.gd` / `src/core/autoload/character_registry.gd`）里的模组名同步；
6. `docs/工作记录/` 旧流水**不改写**，按 §5 在文末追加「补充 / 评价」区块 + 双向链接；
7. 跑 `tools/gen_worklog_index.ps1` 刷新索引，跑 `test/check_scripts.ps1` 过编译门禁。

## 弯路 / 踩坑（三段式）

- **试过**：只改 `get_mod_name()` 的返回值（最小改动）；
- **因为**：目录 / id / 文件名 / 文档还叫 balance，后来者会踩「名叫生态版、路径叫 balance」的漂移；
- **结论**：显示名 + id + 目录 + 文件名 + 探针 + 文档一次改全；历史流水只追加。

- **试过**：把 `docs/工作记录/` 旧记录里的「原版平衡 / balance_wiring.gd」一并替换；
- **因为**：工作记录是**当日事实的流水**，改写等于抹掉历史（README §1 明令禁止）；
- **结论**：旧记录末尾按 §5 追加改名说明 + 双向链接，索引行数不动。

## 推荐度与理由

推荐。改名类任务的坑全在「漏」：漏一处文档就漂移。先全仓 grep 再动手、`git mv` 保历史、
历史流水只追加，三条照做不会漏。
**注意**：模组 id 从 `balance` 改成 `eco` 后，`user://<用户名>/mod_config.ini` 里旧的 `[balance]` 段
不再被读到（该模组默认关闭，影响仅限「曾经手动开过它」的存档，重新开一次即可）。
