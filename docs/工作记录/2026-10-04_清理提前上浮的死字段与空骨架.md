### 为什么不删 `is_can_look_random_res_pot`

- 它**有真实生产端**：`data/levels/params/vase_zombie.tres` 是随仓库发布的自定义关卡（`custom_choose_level.gd` 按目录扫描加载），删字段 = 这一关当场少一个玩法。
- 它在本体里**不产生专属分支**，只是把开关值转发给 `ScaryPot` 已有的通用属性 `IsAlwaysLookPot`；
  顺着删下去还得动 `scary_pot.gd` 的枚举与读取处，收益远小于风险。
- 结论：**留**，并在字段上写明「目前只有自定义关卡在用」，免得下一个 agent 又来审一遍。

### 空骨架怎么收尾

`minigame_09` 的 `run_flow()` 是一段「普通打僵尸」流程，**不是**原版的「旋转 2x2 凑三消」，但它在选关界面上有按钮、点进去能打完 —— 这就是「看起来能进的关卡」。

本次没补玩法（那是另一个完整功能，不是清理任务该夹带的），改成两头都堵上：

1. 文件头写死「⚠️ **未实现**」+ 四个 TODO（复用 `src/levels/script/mini_game/beghouled/` 的 `BeghouledManager`、在 `init_level_items()` 里自己 new、通关条件改配对次数、做完把按钮加回来）；
2. 选关场景 `mini_game_choose_level.tscn` 的 `ChooseLevelButton10` **摘掉 `level_script` / `preview_icon` 两行**，只留空槽位保持原版 20 关的顺序。
   `ChooseLevelButton._ready()` 在没有 `level_script` 时会把按钮 / 通关标记 / 预览图全部隐藏 —— 玩家看到的是一个空框，点不进去。

存档键不受影响：20 个迷你游戏的 `save_key` 全部写死（V2），按钮少一个不会让 `level_id` 影响存档名。

## 踩坑

1. **删枚举成员会顺移后面成员的值** —— `E_PotMode` 删掉第 1 位的 `Weight` 后，`Fixd` 从 `2` 变成 `1`，
   而 `data/levels/params/vase_zombie.tres` 里写的是**数字** `pot_mode = 2`。
   → **正解**：删完枚举必须回头搜一遍 `.tres` 里写死的数字（脚本关写 `ConstLevelData.E_PotMode.Fixd` 会自动跟上，只有 `.tres` 会漏），本次把 `vase_zombie.tres` 改成 `pot_mode = 1`。
   （`E_CardMode` 删的是最后一位 `Coin`，`Norm=1` / `ConveyorBelt=2` 不变，`not_zombie.tres` 的 `card_mode = 2` 无需动。）
2. **`.tscn` 里注释用 `;` 不是 `#`** —— 顺手写了 `#` 才发现仓库里只有 `;` 注释（`src/entities/character/zombie/zombie_bungi_drop.tscn`）。`#` 会让场景解析失败，代价是整个选关界面打不开。
3. **删除前要确认「生产端」而不是「消费端」** —— `E_PotMode.Weight` 的权重模式其实**早就跑不起来**：它要给 `PlantCellManager` 赋 `pot_plant_random_pool` / `pot_zombie_random_pool`，而这两个字段在管理器上**根本没声明**。
   只有「没人赋值」+「一跑就崩」两条凑齐，才能放心整段删。
4. **多 agent 并行时别抢 Godot** —— 本次改动期间另一个 agent 正开着两个 `Godot_v4.6.2` 进程（还在批量删 `animation/**`），
   再起一个 `--headless --import` 会抢 `.godot/` 的类缓存，所以本次按 V-01 免验证，把人工验证方法写清楚（见文末）。

## 给后来者的最简路径

1. 判断「该不该删」只问一句：**有没有关卡 / 资源真的把它置成非默认值**。没有 → 删；有 → 留（并把「谁在用」写进字段注释）。
2. 删枚举成员 → **先搜 `.tres` 里的裸数字**（`pot_mode = 2` 这种），再删 match 分支，最后删只服务它的字段与函数，别留下不可达分支。
3. 删完跑三条全仓搜索收尾：枚举成员名、字段名、以及随之成为孤儿的场景 / 脚本（`class_name` + 文件名各搜一次）。
4. 空骨架别只写 TODO：要么补完，要么**把入口摘掉**（选关按钮去掉 `level_script`），别留一个「能进、但不是原版玩法」的关卡。

## 人工验证方法（本次免验证，交给下一个开游戏的人顺手过一遍）

1. 选关 → 迷你游戏页：**第 10 格是空框**（原「僵尸迷阵旋风」位置），点不进去；其余 19 关按钮正常、通关标记正常。
2. 冒险 4-5 砸罐子：三批罐子照常摆出来（3 / 4 / 5 列），切批次时上一批植物被清空，戴夫提示罐个数不变。
3. 解谜模式砸罐子 01~10 与自定义关卡 `vase_zombie`：`vase_zombie` 的罐子**砸之前能一直看到里面**（`is_can_look_random_res_pot` 那条没被误删）。
4. 传送带关（冒险 1-10 / 2-10 / 5-5）：出战卡槽照常发牌。
5. 读档：多轮关卡（4-5 与解谜砸罐子）读档后仍从第 N+1 批开始，植物不恢复。
