## 目标

调试窗口此前只有 4 页（常用 / 资源 / 运行 / 状态）：能通关、加阳光金币、调倍速、看几个状态，
但**不能刷僵尸、不能跳波、不能秒杀、不能跳关**，也没有搜索 / 日志 / 动作反馈；
「显示血条」「开放所有关卡」这类调试常改的开关仍要去控制台翻。

## 弯路 / 踩坑（三段式）

1. **`accept_event()` 是 Control 的方法，CanvasLayer 里没有** —— 窗口脚本 `extends CanvasLayer`，
   在 `gui_input` 回调里直接写 `accept_event()` 编译报 `Function "accept_event()" not found in base self`。
   改成 `get_viewport().set_input_as_handled()`。
2. **`TextEdit` 没有 `scroll_following`** —— 那是 `RichTextLabel` 的属性；赋值报
   `Invalid assignment of property or key 'scroll_following'`，而且错误发生在 `_build_pages()` 里，
   会让后面的 `_show_page(0)` 整段不执行（页面全部不可见，但探针只判 `_window.visible` 仍然 PASS）。
   要「跟着最新一行」用 `set_caret_line(get_line_count() - 1, true)`。
   **教训**：探针只看「窗口开没开」是不够的，得同时断言页数与页内控件。
3. **数字键不能写在 `_unhandled_key_input`** —— 卡槽的 1-9 选卡在 unhandled 阶段响应且不标记 handled，
   调试窗口若也在这里判数字键，会「切页 + 选卡」同时发生。`_input` 早于 unhandled，吃掉就传不下去。
4. **无头跑探针时共享输出文件会被别的 Godot 实例占住** —— `run_autopilot.ps1` 会直接
   `result=STALE_PROCESS` 拒绝启动（这是有意的保护，不要 `-KillStale`）。
   并行调试时用独立 `APPDATA` 临时目录 + 自己的输出文件直接调 `godot --headless` 即可。
