# 2026-10-08 · 其它 · 原版之外的功能做成模组（本轮只做手套模组）

> **任务类型**：其它
> **推荐度**：**推荐**（下次新增任何"原版没有的玩法"，照这个走）
> **耗时与成本**：约 2 轮对话，未开窗口（两条无头探针全 PASS + 编译门禁 PASS）
> **验证方式**：无头探针 `probe_glove_unlock`（模组开启态）/ `probe_hand`（模组关闭态 + 临时开启态）全 PASS
> **补充自**：[2026-10-04_隐藏关卡内手套功能](2026-10-04_隐藏关卡内手套功能.md)（那次的"单点开关"方案被本记录取代）

## 目标

把**非原版玩法**做成模组：本体（`main_game_base.tscn` / 管理器 / 卡槽）不认识任何模组，
关掉 = 不装载（场景里不留一个节点），而不是"装了再在本体各处堵分支"。
本轮只把手套（关卡内拎起植物换格子）改造成**第一个模组**，并建立模组框架。

背景：2026-10-04 为了隐藏手套，在 5 个本体文件 + 2 个探针里各加了一层
`ConstFeatureSwitch.GLOVE_ENABLED`；那套做法作废，改成模组后开关只剩 `data/mods/mod_config.tres` 一处。

## 步骤

1. **建框架**（`mods_builtin/`）：
   - `mod_ids.gd`（`ModIds`：id 常量）/ `mod_base.gd`（`ModBase`：`install()` + `install_to_main_game()`）
   - `mod_manager.gd`（`ModManagerClass`，**注册为 autoload `ModManager`**）：`MOD_SCRIPT_PATHS` 是
     id → 入口脚本的唯一映射表；`_ready()` 读开关并 `install()`；`install_mods_to_main_game(mg)` 每局装载
   - `mod_config.gd` + `data/mods/mod_config.tres`（`enabled_mods`，**默认空 = 本体即原版**）
2. **手套整包搬进 `mods_builtin/glove/`**（连 `.uid` 一起移动）：
   `hand_component_glove.gd`、`glove_in_ui.gd`、`real_glove.gd`，并新增
   `glove_mod.gd`（入口）、`glove_slot.tscn`（卡槽按钮，从主场景里抠出来原样重建）。
3. **`GloveMod.install_to_main_game()` 现场造三件套**：`RealGlove` → `%CanvasLayerTemp`；
   `UIGlove` → `%UIShovel` 的父节点（ShovelContainer）；`HM_Glove` → `HandManager`。
   卡槽按钮的 `glove_clicked` 信号连到组件的 `on_click_glove`（**不走 EventBus**）。
4. **本体摘干净手套**：
   - `main_game_base.tscn` 删 `HM_Glove` / `UIGlove` / `RealGlove` 三个节点（含 ext_resource 与 connection，`load_steps` 93→89）
   - `card_slot_root.gd` 删 G 键分支（改由模组自己的卡槽按钮收）
   - `ConstFeatureSwitch` 删 `GLOVE_ENABLED`；`ConstUnlockLevel` / `GlobalGameState` 删手套解锁
     （口径迁进 `GloveMod.UNLOCK_ADVENTURE_LEVEL`）；`ConstEventName` 删 `MAIN_GAME_CLICK_GLOVE`
   - `PlantCell` 的 `glove_*` API 改名 `move_*`（它是通用搬运能力，手套模组与三消共用）
   - `MainGameManager.init_manager()` 在 `hand_manager.init_manager()` **之前**调
     `ModManager.install_mods_to_main_game(self)`
5. **4-6 赠礼对话**：留在关卡内容里（`data/dave/dialog/adventure_04_06_glove.tres`），
   由 `adventure_04_06.gd` 按 `ModManager.is_mod_enabled(ModIds.GLOVE)` 决定播不播。
6. **探针 + 文档**：`probe_glove_unlock` 自己打开模组再跑；`probe_hand` 关闭态跳过第 7 节、
   组件数按开关断言 4 / 5；新增 [模组机制.md](../参考存档/模组机制.md) 并登记索引，
   同步 `手持物实现.md` §五、`架构总览.md`、`选关界面与解锁.md`。

## 关键决策与理由

- **模组 = 运行时装载，不是"装了再隐藏"** —— 只有"不装载"才能让本体零分支；
  留着节点靠开关隐藏，就会重演 2026-10-04 那次"5 个文件各堵一层、探针也得跟着跳过"。
- **本体只留"槽位"，不留"认识"** —— `E_HandComponentType.Glove` 这个枚举值保留（没有它模组注册不了手持物），
  但解锁口径、组件、界面、快捷键全部归模组；`PlantCell` 的 API 改叫 `move_*`，
  "本体 API 名字里出现模组名"本身就是耦合。
- **本体不 import 模组** —— 4-6 没有去 `preload` 模组目录里的对话资源（那会造出本体→模组硬依赖，
  删掉模组就编译不过）；对话属于关卡演出内容，只按开关决定播不播。
- **模组内部连线用信号不用 EventBus 事件名** —— `ConstEventName` 是本体的表，
  往里加 `main_game_click_glove` 等于把模组写进本体。
- **默认全关** —— 与改造前的现状（`GLOVE_ENABLED=false`）一致，不偷偷改变玩家看到的东西。

## 踩坑

1. **autoload 脚本的 `class_name` 不能与单例同名**：写 `class_name ModManager` + autoload `ModManager`
   → 编译门禁报 `Class "ModManager" hides an autoload singleton`，并且本体里
   `ModManager.install_mods_to_main_game(self)` 被解析成
   `Cannot call non-static function ... on the class "ModManager" directly`。
   **正解**：要么不写 `class_name`（如 `EventBus`），要么写成 `ModManagerClass`
   （与 `GlobalUtilsClass` / `AllCardsClass` 同款）。
2. **运行时 `add_child` 的节点拿不到场景唯一名节点**：`HandComponentGlove` 原来的
   `@onready var ui_glove: UIGlove = %UIGlove` 在模组场景里会拿到 null（`%` 只对场景里本就有的节点生效）。
   **正解**：由模组在 `add_child` 之前注入引用（`set_visual_nodes()`），组件里改成普通成员。
3. **装载时机**：`install_to_main_game()` 必须排在 `hand_manager.init_manager()` 之前 ——
   `HandManager` 是在 `init_manager()` 里遍历 `get_children()` 登记组件的，晚加的组件登记不进去
   （表现为 `get_hand_component(Glove)` 恒为 null，且没有任何报错）。
4. **探针最容易漏的一步**：模组默认关 → 手套探针不自己 `set_mod_enabled(true)` 就整支必挂；
   反过来 `probe_hand` 里写死的"HandManager 下 5 个组件"在关闭态会变成 4 个，断言要跟着开关走。

## 给后来者的最简路径

1. 判据：**原版有 → 本体；原版没有 → 模组**。
2. `ModIds` 加常量 → `ModManager.MOD_SCRIPT_PATHS` 加一行 → `mods_builtin/<id>/` 写入口脚本（继承 `ModBase`）。
3. 要挂节点就在 `install_to_main_game()` 里现场造，挂载点用本体场景的 `%同名` 节点；
   造出来的节点不要用 `@onready %`，由模组注入引用。
4. 本体要判断模组开没开，只写 `ModManager.is_mod_enabled(ModIds.XXX)`，**不要 import 模组的类 / 资源**。
5. 开关：`data/mods/mod_config.tres`（正式）/ `ModManager.set_mod_enabled()`（探针调试）。
6. 交付前：改到手套就跑 `probe_glove_unlock` + `probe_hand`；改动较小则免验证（见[验证流程.md](../验证流程.md)）。
