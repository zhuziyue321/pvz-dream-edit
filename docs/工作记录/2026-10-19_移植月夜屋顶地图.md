# 2026-10-19 · 关卡与地图 · 从 PVZ_DLC 移植月夜屋顶地图

> **任务类型**：关卡与地图
> **推荐度**：**推荐**（下次从 DLC 版搬一张新地图 / 新背景照这个走）
> **耗时与成本**：约 1 轮对话；编译门禁 + 新探针 `probe_moonroof_map` + 回归 `probe_boss_map` 全绿，未开窗口人工验收
> **验证方式**：免验证（无头探针全绿），人工方法见文末
> **来源素材**：`..\PVZ_DLC\_unpacked\`（《Plants vs. Zombies: DLC Edition》v2.7.2 解包）

## 目标

把 DLC 版第 6 章「月夜屋顶（Moon）」的**地图**搬进本仓库：底图 + 房门遮罩 + 地图资源 +
背景子场景 + 场景设置，让后续 DLC 章节 / 自制关卡可以直接用。

## 步骤（最简路径）

1. **先认素材**：月夜屋顶底图 = `_unpacked/images/background6.png`（1400×600，与其余底图同画幅；
   `background6boss.jpg` 是它的僵王关配色变体）。用 System.Drawing 预览确认过再动手。
2. **查机制口径**：DLC 官方维基 `pvz-dlc-edition.fandom.com/wiki/Moon`（页面直连 403，
   走 `api.php?action=parse&prop=wikitext` 能拿到全文）—— Moon = Night + Roof 混合：
   **无天降阳光**、屋顶斜面、必须花盆、蹦极、旗间血月加速；BGM 是 **Harvest Moon**（MisterKaze）。
3. **搬素材**：`background6.png` → `pak/images/background6moon.png`、
   `background6moon_gameover_mask.png` → 同名、`sounds/music/HarvestMoon.ogg` →
   `assets_custom/audio/BGM/harvest_moon.ogg`。
4. **照 map_boss 三件套抄**：`GameBg.MoonRoof`（**追加在枚举末尾**，不动现有下标——
   `.tres` 里存的是整数）+ `GameBGM.Moon`；`main_game_bg_moonroof.tscn`（抄 boss，换底图 +
   多挂 `Background6MoonGameoverMask`）；`map_moonroof.tres`（几何逐格抄 `map_boss`）；
   `main_game_home.gd` 两个数组补到 7（`get_node_or_null` 套路）；场景 `SCENE_MOON_ROOF`。
5. **写探针** `test/scenarios/probe_moonroof_map.gd`：静态（与 `map_boss` 逐行几何一致 +
   背景子场景契约 + 常量 / 场景设置值）+ 实机（**合成关卡**：`ResourceLevelData.new()` 直接给
   `map_data` 和 `scene_name` 进主游戏，核对底图 / 遮罩数组 / 斜面 / 格子）。

## 踩坑

1. **新 png 先导入再过门禁**：`preload("res://pak/images/background6moon.png")` 在资源没进
   Godot 导入管线时报 `has no resource loaders (unrecognized file extension)`，门禁 19 条错；
   跑一次 `--import`（check_scripts 第一道就是它）生成 `.import` 后重跑即绿。新增底图都这样。
2. **合成关卡不要断言小推车**：小推车入场已搬进**关卡流程**，`ResourceLevelData.new()` 出来的
   合成关卡不是 `LevelScriptBase`，流程不跑 → 场上 0 台。别学 `probe_boss_map` 断言 5 台
   （5-10 有真流程才断得了）；类型 / 行数由静态逐行比对覆盖。
3. **reanim/particles 一张都不缺**：456 个 `.compiled` 全量二进制扫过
   （`MOON / Background6 / CRATER / HALLOW` 零命中）——月夜屋顶是纯静态底图，
   **本次不需要 PopStudio 反编译**。血月红光没有独立底图（应是运行期调色），接血月玩法时再查。

- `test/run_autopilot.ps1 -Scenario probe_boss_map` → `[BOSSMAP] result=PASS failed=0`（未漂移）。

  `map_data = preload("res://data/map/map_moonroof.tres")` 的关卡进游戏，确认：
  ① 底图是月牙 + 暗红瓦的月夜屋顶；② 左侧每行有屋顶清洁车；③ 夜晚、不掉阳光；
  ④ BGM 是 Harvest Moon；⑤ 输掉时房门遮罩是月夜那张。
