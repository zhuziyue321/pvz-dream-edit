## 目标

加一个「锤子」模组，结构与其余部分类似手套模组：点卡槽（或按 H）拿到手上 → 点草坪 →
对以点击点为中心的小范围内僵尸造成伤害；伤害**可设置** —— 固定数值，或一键秒杀。

## 步骤

1. 用 code-explorer 把手套模组整条链路摸清（入口 / 组件 / 卡槽 / 真手套 / 设置读写 / 命中判定 / 伤害 API / AOE 参考）。
2. 注册三处：`ModIds.HAMMER` → `ModManager.MOD_SCRIPT_PATHS` 加一行 → `E_HandComponentType` 枚举**末尾**加 `HammerMod`（现役 `Hammer` 已被迷你游戏锤僵尸占用，重复会报「类型重复」跳过登记）。
3. `project.godot` 加 `ShortcutKeys_Hammer`（H，physical_keycode 72）。
4. `mods_builtin/hammer/` 五件：`hammer_mod.gd`（`HeadHammerMod`，入口 + 五项设置 + `install_to_main_game()` 现场造三件套）、`hand_component_hammer_mod.gd`（组件：冷却照手套抄，`click_cell` 一律挥锤并返回 true）、`hammer_in_ui.gd` + `hammer_slot.tscn`（卡槽按钮，锤头 + 锤柄两块贴图拼图标，位置 140~210）、`real_hammer_mod.gd` + `real_hammer_mod.tscn`（真锤子，复用迷你游戏锤子的贴图 / `.tres` 动画 / Area2D 套路）。
5. 文档同步：`mods_builtin/README.md` 加一行；[模组机制.md](../参考存档/模组机制.md) §二文件表 + §六新增 6.3 小节。
6. 跑 `test/check_scripts.ps1`：PASS（real compile errors = 0，scenarios 109）。

## 关键决策与理由

- **命中判定走 Area2D 而不是遍历 `zombie_manager.all_zombies_1d` 算距离** —— 与现役锤子同一套路
  （mask=4 僵尸受击框层、`get_overlapping_areas()`、`area.owner is Zombie000Base`），
  半径可调只要改 `CircleShape2D.radius`，且天然吃到受击框的真实形状；
  仓库没有「按距离查敌人」的通用工具，遍历法还得自己定义「僵尸的中心点」。
- **伤害结算放在组件里、真锤子只返回名单** —— 组件才知道设置（秒杀 / 数值）；
  秒杀用 `be_attack_to_death()`，数值用 `DamageInfo.create(…, Norm, Hammer)` + `apply_damage()`
  （不用 `be_attacked_hammer(1800)`：Hammer 模式的语义是「一类防具 900、本体清空」，数值塞进去行为不对）。
- **不设通关解锁** —— 手套的解锁是「剧情里戴夫赠送」才有的事；模组是玩家显式开关的，装上即可用。
- **冷却默认关、与手套同一套实现**（`_process` 倒计时 + 卡槽遮罩），挥一锤就算用掉一次。
- **美术复用迷你游戏锤子**：三块贴图 + `hammer_whack_zombie.tres` 动画原样进新场景，
  不复制 `.gd`（那边 `_unhandled_input` 会自己挥锤打 1800，逻辑不能带过来）。

## 踩坑

1. 手持物类型枚举里 `Hammer` 已被「锤僵尸」玩法占用（`HandComponentHammer`）→ 直接复用会在
   `HandManager._register_all_hand_components()` 报类型重复并**静默跳过** → **正解**：新类型加在枚举**末尾**（`HammerMod`），别插中间。
2. 手写 `.tscn` 里引用新脚本没有 `uid` → 不写 `uid=` 属性即可（仓库已有先例，见 2026-10-12 防具那条记录）。

## 给后来者的最简路径

1. 照 `mods_builtin/glove/` 五件套抄出 `mods_builtin/hammer/`，改类名与信号名。
2. 注册三处：`ModIds` / `MOD_SCRIPT_PATHS` / `E_HandComponentType`（新类型放**末尾**）。
3. 快捷键在 `project.godot` 加一条 `ShortcutKeys_Xxx`（physical_keycode = 字母序号）。
4. 设置五件套照 `HeadHammerMod._build_panel_entries()`：`ConsoleEntry.create_toggle/slider(...).bind(get, set)`，
   值走 `ModManager.get/set_mod_value(ModIds.XXX, key, default)`，开关一动 `request_refresh()` 让滑条置灰跟着变。
5. 交互类道具的效果写在组件的 `click_cell()` 里，返回 true = 这一下用完了（回空手）。

## 人工验证方法（未开游戏，验证时按此走）

1. 主菜单 → 选项 → 控制台 →「模组」→ 开「锤子」（右侧详情应出现解锁 / 用法说明与五项设置）。
2. 进任意可操作草坪的关卡（如 1-1）：卡槽手套右侧应出现锤子按钮（带 H 角标）。
3. 按 H 或点按钮 → 锤子跟鼠标 → 点草坪：挥锤动画 + swing 音效；范围内有僵尸时加 bonk 音效与 Pow 星星，僵尸掉血。
4. 模组页面把「一键秒杀」打开 → 再挥一次，范围内僵尸（含路障 / 铁桶）直接死；把伤害数值调低（如 200）→ 普僵不死只掉血。
5. 范围半径调大 / 调小各试一次，确认命中圈跟着变；开「挥完之后有冷却」→ 挥完卡槽图标盖遮罩、倒计时结束才可再拿。
6. 右键 / 点空白收回锤子；关掉模组后进关，卡槽与场景里不应有任何锤子节点。
