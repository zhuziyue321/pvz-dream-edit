## 弯路 / 踩坑

### 1. 这只僵尸「没有原版行为」

`Zombie_target.reanim` 与三条文案都在，但两个 C++ 参照项目里 `ZOMBIE_TARGET` 都是**整块注释掉**的
（`re-plants-vs-zombies-main` 里明写 console 时代残留）。所以没有「原版怎么打」可对齐 ——
玩法直接按需求定（对战靶子、原地不动），别去翻原版找速度 / 血量。

### 2. DLC 动画进不了本体的 AnimationTree

本仓库普通僵尸一律「骨架 + AnimationTree 状态机」；DLC 转换产物是**逐帧烘焙的 Sprite 组**
（每段动画写一遍所有部件的 texture / position / visible），两者不是一回事：

- 换 `AnimComponent = AnimComponentEmpty`，脚本直接播 `AnimLib`；
- 代价：`signal_animation_finished` 不再由组件发（`move_component._on_animation_finished` 不会跑）——
  靶子不走，正好不需要；
- 素材只有 idle / hit / death，**没有 walk / eat**（原版未启用，没这些段）。

### 3. 死亡动画没有收尾方法轨 → 尸体永远留在场上

本体僵尸的 `zombie_death.tres` 方法轨里调 `_fade_and_remove()`；DLC 转出来的死亡动画没有方法轨。
自己在 `animation_finished` 里按动画名补一次 `_fade_and_remove()`（`target_zombie.gd`）。

### 4. `CharredComponent` 要换回基类

`component_charred_zombie_norm.gd` 的 `@onready` 去取 `$ZombieCharred/CharredCorrect/AnimLib`，
DLC 动画没有这个节点 → 被樱桃炸弹 / 辣椒烧死时会取空。场景里把该组件的 script 覆盖成基类
`component_charred.gd`（只把本体 reparent 出去）。

### 5. 不播动画时所有部件都堆在 (0,0)

部件的 position 全由动画轨道给，初始都是原点。**图鉴 / 开局预览 / 卡面**是在 `ready_show()`
之后同一帧把 `Body` 摘走的 —— 必须 `play()` 后立刻 `seek(0.0, true)` 把第一帧推进去，否则摘到一堆散件。

### 6. 贴地偏移是算出来的

`BodyCorrect.position = -(脚底中心)`：`Zombie_outerleg_foot` 首帧左上 (44.6, 109.3) + 42×21
→ 底边中心 (65.6, 130.3) → 场景里写 `(-66, -130)`。实测浮空 / 陷地就只改这一行。

### 7. 归属：先放 DLC，再挪到玩家对战

靶子僵尸的素材来自 DLC，但**玩法**只属于玩家对战。第一版放在 `mods_builtin/dlc/`，
确认玩法后整块挪到 `mods_builtin/player_battle/`（连带 `.import` 的 `source_file` 一起改路径），
`dlc_mod.gd` 同步还原 —— 否则玩家对战要新增一条对 DLC 模组的依赖。

### 8. 不给它僵尸卡

`ZombieRuntimeKit` **不装**：靶子不是玩家能放的单位，只由关卡摆。装了它反而会出现在僵尸卡页里。

### 9. 转换出来的 idle 不循环 → 站着站着就不动了

转换器的 `Animation` 资源没写 `loop_mode`（默认 0，播一遍停在最后一帧）。靶子的常态就是 idle，
必须手改 `Zombie_target_idle.tres` 的 `loop_mode = 1`；**重新转换会覆盖这个手改**，别忘补回。
`replace_in_file` 对这份超大 tres 匹配不上 `[resource]` 段，用 PowerShell 直接插的行。

### 10. 血量要按 DLC Edition 的 wiki，不是原版主机版

`zombie_base.tscn` 的 `HpComponent.max_hp = 270` 是本体僵尸口径，别直接沿用。
正确来源是 **DLC Edition wiki**（这个整合包就是它）：
`https://pvz-dlc-edition.fandom.com/wiki/Target_Zombie` → **200 HP**，受创 60 / 110 / 160
三档换外观、累计 200 死。在 `zombie_target.tscn` 里覆盖成 `max_hp = 200`。

⚠️ 两处容易抄错的：
- 官方主机版 wiki（wiki.gg / fandom 主站）也写 200，但那是 **PS3/Xbox 对战模式**的靶子僵尸，
  不是本整合包的实现；两边数值恰好一致，但口径不同，注释里要写清是 DLC Edition。
- 中文 `wiki.pvz1.com` 的「僵尸图鉴」表里写 **270**（那是把本体血量直接抄上去的），别用。

三档受创外观（`Zombie_target_body2` / `damage01~03`）还没接 —— 要接得给
`HpStageChangeComponent` 配 `body_change` 资源，属于下一轮的事。

### 11. 「场外最右」有两层意思，别摆到出怪点上

第一版摆在红线右侧的第 8 列（草坪内，跟植物/僵尸混在一起）；改成「场外」时又差点直接用出怪点
（x ≈ 950，那是**屏幕外**的进场线，看不见也打不着）。用户要的是**像小推车那样**：小推车站在
草坪左边缘外（x = 20），所以靶子站草坪右边缘外（最后一列右边缘 + 12px）—— 可见、不占格子。

## 最简路径（下次接一只 DLC 僵尸）

1. 拷 reanim + 全部部件贴图到 `<模组>/reanim/<名字>/`（**先扫一遍动画引用了哪些通用部件**，本体僵尸的手脚头常被复用）。
2. 转换器 `-om auto` 出动画，把 `.tscn/.tres` 挪到 `<模组>/animation/character/zombie/<名字>/`；在 `AnimLib` 上加一个具名库装需要的段。
3. 角色场景 = `zombie_base.tscn` instance + `AnimComponent` 换 empty + 动画实例挂 `Body/BodyCorrect` + 贴地偏移 + `CharredComponent` 换基类 + 自己脚本（播 idle / 死亡收尾）。
4. 注册：`ZombieRuntimeRecipe`（`base_scene` 指自己的场景、`zombie_script` 留空），`install()` 里注册、`uninstall()` 里 `is_runtime_zombie` 判一下再撤。
5. 想要卡才装 `ZombieRuntimeKit`；关卡摆目标物不装。

## 补充：受击动画（同日）

- **现象**：靶子被打只换招牌贴图 / 闪白光，**没有受击动作** —— DLC reanim 里有 `Zombie_target_hit`
  （0.83 s），但脚本只接了 idle / death。
- **改法**：`ready_norm_signal_connect()` 里连 `hp_component.signal_hp_loss` →
  `_on_hp_loss()` 播 `ANIM_HIT`；`_on_animation_finished()` 判到 hit 播完回 `_play_idle()`。
  打死那一下不播 hit（`is_death` 已置位，直接交给死亡段）。
- **探针**：`probe_player_battle_target_win.gd` 补「掉血当帧切到受击段 / 播完回待机」两条；整份探针 PASS。
