# 2026-10-09 · 文档规范 · 给联机模组写规范文档（房间 / 房主开关卡 / 战斗域边界）

> **任务类型**：文档规范
> **推荐度**：**推荐**（下次写「模块级规范文档」照这个走）
> **耗时与成本**：约 1 轮，未开游戏（纯文档，不触达代码）
> **验证方式**：免验证（只改 md，无 `.gd` / `.tres` 改动，编译门禁与联机行为都不受影响）
> **补充自**：[2026-10-08_为联机模组做准备.md](2026-10-08_为联机模组做准备.md)（那份建了 `src/mods/netplay/` 地基与 [联机模组.md](../参考存档/联机模组.md)，本次是它的规范层补充）

## 目标

把用户对联机的三条要求固化成一份规范文档：① 房间机制；② 所有关卡由房主打开 / 退出；③ 进关后大部分逻辑本地处理，只有战斗相关（场上植物 / 僵尸 / 阳光 / 选卡）走联机。

## 步骤

1. 先读 [联机模组.md](../参考存档/联机模组.md) 摸清已有实现（会话 / 命令 / 卡片协商 / 准备流 / 战斗同步），再读 `src/mods/netplay/` 的 `netplay_session.gd` / `netplay_mod.gd` / `netplay_battle_sync.gd` / `netplay_command.gd` 核实现状 —— 规范里每一条"现状"都要有代码出处，不能照文档抄。
2. 定落位：按 [docs/README.md](../README.md) §1 三层判定 —— 这是**项目相关**的模块约定（不是仓库级硬约束）⇒ 进 `docs/参考存档/`，文件名 `联机模组规范.md`，与已有的机制文档 `联机模组.md` 分工（那份讲实现现状，这份讲约定）。
3. 按 [docs/README.md](../README.md) §5 加 `<!-- AGENT-DOC: spec -->` 标记 + 「面向 AI Agent」元信息头，强制级别写**应该**（不是必须 —— 硬约束只有 [项目规范.md](../项目规范.md) §1 那 8 条）。
4. 正文按三条要求分章：房间（定义 / 状态 / 生命周期 / 三类消息方向 / 加入掉线 / 界面）、房主开关卡（4 条规则 + 进关键值 + 退关页面 + 通关裁决 + 现状差距表）、战斗域 vs 本地域（口诀 + 两张清单 + 三步判定法 + 落到代码的两个动作 + 边界纪律）。
5. 登记三处指针：[参考存档/README.md](../参考存档/README.md) §1 索引补一行、[联机模组.md](../参考存档/联机模组.md) 元信息头加"约定"链接并在 §一 末尾写清分工、根 [AGENTS.md](../../AGENTS.md) §2 路由表的联机那一行补规范入口。

## 关键决策与理由

- **新开一份而不是塞进 `联机模组.md`** —— 那份已经 400 行，塞进去等于把"约定"和"现状"混在一起，改代码时不知道该信哪段。两份之间用**双向指针 + 冲突以规范为准**解决漂移。
- **强制级别写"应该"而不是"必须"** —— [参考存档/README.md](../参考存档/README.md) 明确本目录全部为参考级；模块级约定用「应该（偏离要写理由）」，同时不跟 [项目规范.md](../项目规范.md) §1 的 8 条硬约束抢位置。
- **"不做房主迁移"直接定死** —— 需求没提，但不写死下一个 Agent 会自己发挥；理由（权威状态只在房主那一局）写进正文。
- **现状差距单独列表（§2.5）** —— 规范不能假装代码已经做到：客户端现在**能**自己进关、退关也不通知任何人，这两条明确标为待办。
- **判定不清的默认答案是"本地"** —— 提前把表现层接进同步表只会让命令表膨胀且难拆。

## 踩坑

1. 改根 `AGENTS.md` 的路由表时，整行替换因表内对齐空格对不上而失败 → **正解**：只替换最小的唯一片段（链接 + 括号开头那几个字），不要整行复制。
2. 一开始想直接改 `联机模组.md` 加一节"规范" → **放弃原因**：与"同一件事只在一处写"冲突，且机制文档已经太长；改成新开一份 + 指针。

## 给后来者的最简路径

1. 读 [联机模组.md](../参考存档/联机模组.md) 摸现状 + 读 `src/mods/netplay/` 关键脚本核实。
2. 新建 `docs/参考存档/<模块>规范.md`，带 `AGENT-DOC` 标记与元信息头（级别写**应该**）。
3. 正文分章讲"该做成什么样"，另开一张「现状差距」表标出代码还没做到的部分。
4. 登记三处：所属目录 README 索引、对应机制文档（双向指针 + 分工说明）、根 `AGENTS.md` 路由表那一行。
