## 目标

台词文本此前已逐 key 对齐，本次把残留的**行为差异**全部对齐，共五组：

1. **挂机闲话**：首次间隔 2 秒（原 `mAmbientSpeechCountDown = 200`）、之后 5~10 秒随机（原 `RandRangeInt(500,1000)`）、
   不连续重复同一句（原「上次说过的权重归零」）、2018「我吃掉在地上的东西」通关冒险后才出现（原权重 `20 : 0`）；
2. **气泡等语音**：气泡不许先于戴夫语音消失（原 734~743 行的 `IsFoleyPlaying` 续期）；
3. **悬停轻量语义**：同句重复悬停只刷新驻留不重念、移出后气泡再停 1 秒（原 `SetBubbleText(..., 100)`）、
   进场 / 关箱 / 弹窗期间不响应（原 `CanInteractWithButtons`）；
4. **打断与冻结**：点商品必停戴夫（原 `PurchaseItem` 开头）、翻页关箱停戴夫（原关箱分支）、
   弹窗期间冻结挂机计时（原 `mWaitForDialog`）、空格 / 回车推进开场白（原 `KeyDown`）；
5. **开箱联动**：后备箱不再按固定时序打开，念到 303 / 3100 才开（原 `AdvanceCrazyDaveDialog`），
   开场白讲完才解锁货架（原 click-to-continue 期间按钮禁用）。

## 关键决策与理由

- **悬停改走 store_manager 中转**（原来信号直连戴夫）：守卫条件（`_is_busy` / 弹窗）是商店的状态，不该塞进通用戴夫节点；
- **「同句刷新」用资源引用比对**（`curr_dialog_detail == detail`）：商店里每句描述都是同一 `.tres` 实例，够用；
- **收起协程用「代次」防串**：悬停 / 收起 / `stop_talking` 互相打断，靠 `_external_close_generation` 让旧协程自动作废，
  不引入额外 Timer 节点；
- **不动发疯动画**：文件头注释写明 crazy 动画中途切换会让平底锅帽子转 360，`stop_talking()` 只收声关气泡，
  动画等它自己播完（原版也是停语音为主）；
- **冒险通关判定**在 `crazy_dave.gd` 里复制了两行（口径同 `Goods.is_adventure_finished`），不反向依赖 `src/store/`；
- **不做的**：普通进店仍会重放 303/304（原版再次进店无开场白）—— 这是仓库既定口径（见台词那篇），不在本次范围。

## 踩坑

1. 编译门禁 `result=FAIL` 但 `real compile errors = 0`：报错来自别人未跟踪的 `probe_slot_visual.gd`，
   先 `git status` 归因再动手，别顺手替别人修在制文件。
2. 原版 tick 口径：100 tick = 1 秒（800 = 8 秒、100 = 1 秒、500~1000 = 5~10 秒），换算错了整排参数全错。

## 给后来者的最简路径

1. 改戴夫行为先看本文「差异 → 落点」表；改台词看台词那篇；改货架判定看《商店全面对齐原版》。
2. 动 `crazy_dave.gd` 的收起 / 闲话协程时，先想清楚代次守卫，别用 `await` 裸等（会被悬停打断）。
3. 后备箱开箱是**事件驱动**：台词资源 `on_talk_event = &"store_open_hatch"` → `StoreManager._open_hatch()`，
   新增「念到某句做某事」照这个机制加，不要写死台词序号。

## 人工验证方法（本次未开游戏）

1. 进商店：招牌滑入后戴夫念开场白，**后备箱此时是关着的**；念到第二句（303）才「砰」地打开；
   开场白没点完之前货架点不了、悬停不念描述。
2. 开场白支持鼠标点击 / 空格 / 回车推进；点完后约 2 秒出第一句闲话，之后每 5~10 秒一句，
   不会连续两句话说同一句；**没通关冒险时永远不会说**「我吃掉在地上的东西」。
3. 悬停商品：戴夫念描述，气泡要等语音播完才消失；移出后气泡再停约 1 秒；
   同一件商品上反复来回划，不会每帧重念。
4. 点商品：戴夫立刻收声；买不起弹「金币不足」、买得起弹确认框，弹窗期间戴夫不会插话，关掉弹窗才恢复。
5. 翻页：关箱瞬间戴夫收声；翻页期间悬停 / 点击无效。
6. 通关 5-1 自动进店：戴夫念 3100 时后备箱打开（不是更早）；买坚果包扎术后 3400 念白至少 8 秒。
