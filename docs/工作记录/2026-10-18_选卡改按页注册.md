# 2026-10-18_选卡改按页注册

> **本次任务**：把「进选卡界面」的登记从**按株追加**改成**按页登记** —— 一页的排版（格位 / 顺序 / 留空）由模组自己定
> **耗时 / 轮次**：1 轮；**没开游戏**（编译门禁 + 9 支无头探针：`probe_selectable_plant` / `probe_water_bowl` / `probe_pvz2_mod` / `probe_arknights_elite` / `probe_dlc_kingcactus` / `probe_card_candidate_pool` / `probe_almanac_extra_page` / `probe_bowling_debug_mode` / `probe_mod_page`）
> **推荐度**：推荐（同 2026-10-13「新增的东西不能挤走原有的东西」那条：版式决定权交给提供方）

## 目标

上一版（[可选植物列表门禁](2026-10-16_可选植物列表门禁.md)）是「多登记一株 = 在列表末尾多占一格」：
选卡界面按**植物总数**切页（每页 48 格）。后果是每装一个模组就往后挤一格，多一株就凭空多出一页
（水盆单独占一整页、DLC 16 株和别的模组的卡混在同一页），排版由「谁最后装」决定。

本次改成**按页登记**：

- 原版常规植物：本体自动排，按每页格数连续切页，顺序固定（这部分不变）；
- 模组新增植物：模组自己 `AllCards.register_plant_choose_page([...])` 登记一页，
  **数组下标就是格位**，`PlantIds.NULL` 留空一格，页序 = 登记顺序，接在原版页之后；
  一页装不下（超过网格模板的 48 格）才顺延到它自己的下一页。

## 最简路径（步骤）

## 弯路 / 踩坑（三段式）

- **试过**：让 `register_plant_choose_page()` 收下「没有卡位的植物」（等模组晚点再插卡）。
- **因为**：校验放在登记时，模组必须先 `PlantRuntimeKit.install()` 再登记页，顺序反了会直接报错。
- **结论**：保持「先装植物再登记页」并**大声报错返回 -1** —— 顺序写反是模组侧一眼能修的错误，
  静默收下反而会让「页里有个空格」一直查不出来。查询侧仍然跳过「页里有、目录里没有」的卡（兜底）。

- **试过**：模组页里的植物也照 `set_plant_choose_replacement()` 走原位替换。
- **因为**：替换表管的是「原版页那一格出谁」；模组页是模组**自己排的版**，写哪张就该出哪张。
  两套一起生效会让「精英关 + 模组页」的格子内容莫名其妙地变，还会和原版页的输出去重打架。
- **结论**：替换只作用于原版页；模组页里的条目按登记时写的那张卡出。同一张卡在别处已经占过格，
  这一格留空（容器 / 禁选 / 预选都按 `card_id` 找格子，一张卡不能有两个）。

- **踩坑**：`Array[Card]` 用 `resize()` 造空页格位 —— 记住 `resize()` 填的是 `null`，
  判断用 `== null` 而不是 `is_instance_valid`（空格上本来就没有节点）。
  `_create_blank_card_pages()` 里模板要 `remove_child` 后再 `duplicate()`，否则第一页会多出一份。

## 推荐度与理由

推荐：本次只动了「页从哪来」这一层，消费侧（容器池 / 禁选 / 预选 / 重选上次卡片）一行协议都没改 ——
它们仍按 `card_id` 找容器，只是容器落在「模组指定的格位」上。
后来者注意三点：

1. **新增一株要上选卡界面的植物，写 `register_plant_choose_page()`，不是往列表里 append** ——
   少这一行，植物能被关卡脚本发牌、能种，但选卡界面里没有它（`probe_water_bowl` 会当场报红）。
2. **页是模组的资源，卸载时自己撤**（`unregister_plant_choose_page()`）；忘了撤不会崩（卡没了那格跳过），
   但页会一直留在快照里。
3. **图鉴的「扩展植物」页看摊平顺序**（`get_plant_types_in_choose_order()`），不还原格位与空位；
   改版式时别去动那份摊平口径，否则同一株在两处会落在不同位置。

## 人工验证方法（未开游戏，6 条）

1. 默认（不装模组、不开调试）进任意关卡选卡：植物只有 1 页、48 格，页码 `1/1`。
2. 只装「水盆」：第 2 页第 1 格是水盆，第 1 页一格不变，页码 `1/2`。
3. 再装「PVZ2」：第 3 页依次是菜问 → 潜伏芹菜 → 火焰豌豆 → 豌豆荚；前两页不变。
4. 再装「DLC」：第 4 页是 DLC 那 16 株（装配顺序），不会和 PVZ2 / 水盆混页。
5. 点模仿者：模仿者页的页序与格位与普通植物页完全一致（模组页也一样）。
6. 逐个关掉模组：对应那一页消失，剩下的页序前移，已选卡片 / 重选上次卡片不会点到空格。
