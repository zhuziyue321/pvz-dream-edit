# 2026-10-05 · 其它 · 拆掉 `LevelPrefabs` 门面，流程方法并进 `LevelScriptBase`

> **任务类型**：其它（重构 / 减少一层转发）
> **推荐度**：**推荐**（同类「门面 → 基类方法」的收拢照这个走）
> **耗时与成本**：约 1 轮对话；未开窗口，跑了三个无头探针
> **验证方式**：无头探针 `probe_4_5_flow` / `probe_tutorial` / `probe_last_stand` 全 PASS（画面无需人工复核：本次零行为改动）
> **补充自**：无

## 目标

关卡脚本里 `await prefab.show_zombie()` 那层 `LevelPrefabs` 门面拆掉 —— 这些函数应该和
`init_level_items` / `should_run_tutorial` 这些**平级**长在 `LevelScriptBase` 上，
关卡脚本直接写 `await show_zombie()`。

## 步骤

1. **`LevelPrefabs` 的 29 个方法搬进 `LevelScriptBase`**（`src/levels/core/level_script_base.gd`）：
   `mg` → 基类字段 `_mg`，私有转发 `_run()` → `_run_event()`（`LevelPrefabs` 里那句
   「主游戏已释放就立刻返回」的保护原样搬过来，教程协程靠它收尾）。
2. **注入点改一处**：`LevelTimelineManager._run_level_script()` 里
   `level_script.prefab = LevelPrefabs.new(main_game)` → `level_script._mg = main_game`。
3. **删文件**：`src/levels/core/level_prefabs.gd` + 它的 `.uid`（硬约束 §1-5：连 uid 一起带走）。
4. **批量去前缀**：`src/` + `test/` 下 117 个 `.gd`，正则 `\bprefab\.` → 空
   （一次性 PowerShell 脚本，见下方踩坑）。
5. **同步文档**：`docs/参考存档/` 下 5 份 md 的 `prefab.` / `LevelPrefabs` 说法改成
   「`LevelScriptBase` 上的流程方法」，并给 [关卡时间轴.md](../参考存档/关卡时间轴.md)
   补上缺的 `wait_battle_start` 事件与 `show_zombie` 的出怪表参数；
   `src/levels/AGENTS.md` 的目录清单去掉 `level_prefabs.gd`。

## 关键决策与理由

- **保留 `run_flow(mg: MainGameManager)` 的参数**：130 个关卡脚本的 `run_flow` 里都在用
  `mg.curr_game_round` 之类，改签名要动 130 个文件，与本次目标无关 —— 参数与 `_mg` 指向同一个对象。
- **基类字段取名 `_mg` 而不是 `main_game`**：见踩坑 1。
- **不改工作记录里的旧说法**：历史记录描述的是当时的做法，保持原样（规则见工作记录 README §1 第 4 条）。

## 踩坑

1. **基类字段不能叫 `main_game`** —— `minigame_12_column.gd` 自己就有一份
   `var main_game: MainGameManager`（`init_level_items` 时存、收摊时置空），
   GDScript 子类重声明同名成员直接报错。
   → **正解**：基类字段用带下划线的 `_mg`（关卡脚本自己要存主游戏引用时不会撞名），
   并在字段注释里写清「为什么带下划线」。
2. **批量改 `.gd` 要用 `[System.IO.File]` + `UTF8Encoding($false)`** ——
   PowerShell 5.1 的 `Set-Content -Encoding utf8` 会加 BOM，Godot 虽能读但会污染 diff。
   → **正解**：`ReadAllText` → 正则替换 → `WriteAllText(..., New-Object System.Text.UTF8Encoding($false))`，
   换行符原样保留。
3. **删带 `class_name` 的脚本后要重启一次 Godot**：全局类表还留着 `LevelPrefabs`，
   编辑器里可能仍提示可引用（见 [参考存档/关卡时间轴.md](../参考存档/关卡时间轴.md) 同类坑）。

## 给后来者的最简路径

1. 门面方法的函数体整段搬进基类，`mg` 换成本类字段、`_run(` 换成基类的转发方法。
2. 注入点（执行器）改成给基类字段赋值，删门面文件与 `.uid`。
3. 全仓正则去 `prefab.` 前缀，再全局搜一遍 `prefab` 确认只剩无关词（`card_prefabs` 之类）。
4. 跑 `probe_4_5_flow`（多轮 / 清场）+ `probe_tutorial`（教程系列）+ `probe_last_stand`（`wait_battle_start`），
   三个 PASS 即可 —— 这类纯搬运改动不用开窗口。
