# 2026-10-06 · 其它 · 给关卡脚本加「卡槽自定义种子包」快捷工具，并在僵尸迷阵落地四张

> **任务类型**：其它（新增通用口子 + 一关专属玩法）
> **推荐度**：**推荐**（下次做「卡槽上放一张不用来种植的卡」照这个走：上下文只给一个口子，玩法全留在关卡脚本）
> **耗时与成本**：约 1 轮对话，带窗口跑 `probe_beghouled`（全过，其中 STEP5.5 是本次新增的 7 条断言）+ 回归 `probe_hand` / `probe_card_slot_conveyor` / `probe_tutorial`
> **验证方式**：带窗口探针实测（画面观感仍需人工看一眼）
> **补充自**：[2026-10-05\_补全僵尸迷阵植物升级逻辑.md](2026-10-05_补全僵尸迷阵植物升级逻辑.md)（本条是它的后续：同一套升级，换了个入口）

## 目标

1. 给关卡脚本一个**快捷工具**：能在出战卡槽里造一张「特殊种子包」，卡面照抄某个已注册身份（植物 / 僵尸 / 僵王 / 模仿者），
   **点击行为由关卡脚本自己写**（不进手持管理器、不去种植物）。
2. 僵尸迷阵（迷你 5）用它造四张卡：双发射手贴图 1000（豌豆射手→双发射手）、大喷菇贴图 500（小喷菇→大喷菇）、
   高坚果贴图 250（坚果→高坚果）、模仿者贴图 100（刷新 / 重排场上所有植物）。

## 步骤

1. 先确认「点击 → 种植」这条链路的终点在哪：点卡走 `Card._on_button_pressed()` →
   `EventBus "main_game_click_card"` → `HandManager` 拿卡去种。要自定义就得**在 `_on_button_pressed()` 里先分出去**，
   别等到手持层再拦（那时卡已经变成手持物了）。
2. `Card` 上加两样通用东西（都不含玩法判断）：
   `CardContext.Custom` 枚举值 + `custom_click: Callable`，以及 `is_disabled_forever` + `set_card_disabled_forever()`
   （一次性卡买完置灰；**不能用现成的 `set_card_disable()`** —— 阳光一变 `judge_sun_enough()` 会把它重新点亮）。
3. `CardImitater._on_button_pressed()` 里补一句：Custom 上下文直接 `super._on_button_pressed()`。
   模仿者那张卡是 `Card` 的子类、覆写了点击，不补这句模仿者贴图那张卡点不动。
4. `LevelScriptBase` 上加 `create_custom_seed_packet(身份, 阳光, 回调, 冷却)`：
   取源卡 → duplicate → `make_reference_unique()` → 挂到 `cards_placeholder[curr_cards.size()]` →
   append 进 `curr_cards` → **入树之后**再写 `sun_cost` / `cool_time`（`_ready` 之前写，卡上的数字和冷却遮罩是空节点，写不进去）→ `judge_sun_enough(sun_value)`。
5. 关卡数据把 `max_choosed_card_num` 1 → 4（本关玩家不能自己挑卡，四格全给种子包）。
6. 关卡脚本 `_init_beghouled()` 末尾建这四张卡：三档升级各绑 `try_buy_upgrade(index)`，买成 → `set_card_disabled_forever()`；
   第四张绑 `try_shuffle()`（本就 100 阳光），成功 → `card_cool()`。
7. 探针 `probe_beghouled` 加 STEP5.5：四张卡的阳光消耗、点第二张买成升级并扣钱、买过被永久置灰、点第四张刷新花 100。

## 关键决策与理由

- **扣阳光 / 冷却不自动化，交给回调决定** —— 出战卡槽那套是「`signal_card_use_end` → 扣阳光 + 冷却」，
  但 `try_buy_upgrade()` / `try_shuffle()` **内部已经扣过阳光了**，再 emit 一次会扣双份。
  所以工具只管「点到就把卡交给回调」，扣不扣由关卡脚本说了算（要那套就自己 emit）。
- **模仿者那张不能用 `is_imitater = true`** —— `ResourceCardReference.is_valid()` 明令禁止「模仿修饰 + 编号 999」这个组合，
  那样造出来的引用是非法的，工具会直接拒绝。改成 `create(Plant, P999Imitater)`（不带修饰），
  再在工具里按「编号 999 没有出战模板」退回 `AllCards.imitater_card`（它不在 `PlantCards` 里，所以没登记成模板）。
- **不把升级按钮从底部 UI 删掉** —— 需求只说「加四张卡」，没说撤按钮；两处都能买同一档升级（`try_buy_upgrade` 自带幂等）。
  想只留卡槽的话，把 `BeghouledUI` 的升级 / 重置按钮去掉即可，管理器不用动。
- **卡槽补位要清掉被一起复制出来的卡** —— `add_one_card_placeholder()` 是 `duplicate()` 现有占位，
  而 `Node.duplicate()` 必带子节点：占位里已经放了卡时补位，会多出一张不在 `curr_cards` 里、点了没人管的卡。
  工具里补完位立刻把新占位里的 `Card` 子节点清掉（本关 `max_choosed_card_num` 已配 4，这条只是兜底）。

## 踩坑

1. **`var x := <表达式>` 报「Cannot infer the type」** —— `is_instance_valid(...) and ... == ...` 这类表达式静态类型推不出来；
   `Global.main_game` / `AllCards.xxx()` 也因为 autoload 没有 `class_name` 而推不出来。
   → **正解**：改成显式类型（`var is_main_game: bool = ...`、`var mg: MainGameManager = Global.main_game`）。
   一处推不出来会连带一串 `Failed to compile depended scripts`，别去追那些下游报错。
2. **模仿者那张卡第一次没造出来（日志「卡牌身份为空」）** —— 就是上面那条 `is_valid()` 的限制，现象不是「模板找不到」而是「身份非法」。
   → **正解**：看日志落在哪个分支；工具里两个分支都打了日志，照日志改引用即可。
3. **`set_card_disabled_forever()` 只调 `card_not_can_click()` 看不出置灰** —— 本卡 `cool_time` 是 0，遮罩 `max_value` 也是 0，画出来是空的。
   → **正解**：置灰时把 `_cool_mask.max_value` 按 `maxf(cool_time, 1.0)` 拉满再 `value = max_value`。

## 给后来者的最简路径

1. 关卡脚本里一行造卡：`var card := create_custom_seed_packet(身份引用, 阳光, 回调, 冷却)`，
   回调签名 `func(card: Card)`；买过一次就停用的在回调里 `card.set_card_disabled_forever()`，
   **条件不满足时置灰**（比如现在没有弹坑可填）用 `card.set_card_blocked(true/false)`（见文末补充）。
2. 关卡数据把 `max_choosed_card_num` 加到「玩家卡 + 自定义卡」的总数（占位在 `CardManager.init_manager()` 里一次性建好）。
3. 卡面要哪种角色就给哪种身份引用 —— 模板从 `AllCards` 取，取不到先确认这个身份有没有登记（`AllCards.is_battle_card()`）。
4. 跑探针：`powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_beghouled -Windowed` → `[BEGHOULED] result=PASS`；
   改了 `Card._on_button_pressed()` 就顺手回归 `probe_hand` / `probe_card_slot_conveyor`（正常种植那条路同一个函数）。

## 人工验证方法（本次没盯画面的部分）

- 进迷你游戏第 5 关，出战卡槽五格：双发射手（1000）/ 大喷菇（500）/ 高坚果（250）/ 模仿者（100）/ 毁灭菇（200），价格写在卡上。
- 阳光不够时五张都是灰的、点了响蜂鸣；攒够阳光点第一张 → 全场豌豆射手（包括以后补位长出来的）全变双发射手，**这张卡变灰且再也点不动**。
- 点第四张 → 花 100 阳光把场上植物整体重排一遍，重排后不该出现「已经连成三个」的静止连线，也不该无处可走。
- 第五张「填坑」：**场上没有弹坑时它是灰的**（别的卡都靠阳光，这张靠条件），有坑且阳光够才亮；
  点一下填掉一个坑并长出植物，坑填完了它自己变灰。
- 底部那条按钮栏已经没有了（升级 / 重置 / 填坑都移到卡槽），界面上只剩顶上「配对 N / 75」。

## 补充（同日后续）：底部按钮条全移除，填坑也进卡槽

> 接本条上文。用户看完四张卡后追加的要求：**底部按钮条全部删掉**（升级 ×3 / 重置 / 填坑），
> **填坑也做成卡槽里的第五张种子包** —— 同一种操作不该有两个入口。

### 这轮改了什么

1. `beghouled_ui.gd`：删掉整条按钮栏（`_build_button_bar` / `all_buttons` / `_on_button_pressed`
   连同 `BAR_*` `BUTTON_WIDTH` `EXTRA_BUTTON_NUM` 常量）。现在这块界面只剩顶部进度文字 + 居中提示语。
2. `beghouled_manager.gd`：删掉 `_build_button_infos()`；`_refresh_ui()` 只刷进度，
   **顺带 `crater_num_changed.emit(弹坑数)`**；`_on_plant_free()` 留坑后补一次 `_refresh_ui()`（让填坑卡点亮）；
   删掉「阳光一变就刷新」的订阅（阳光够不够现在由卡片自己判，本体不该再跟阳光挂钩）。
3. `Card` 加**第三种「不能点」**：`is_blocked` + `set_card_blocked()` —— 给「条件不满足」用，
   `judge_card_ready()` 里单独判一道，所以**阳光变化冲不掉它**（这正是现成 `set_card_disable()` 做不到的）。
4. 关卡脚本：`max_choosed_card_num` 4 → 5，第五张 200 阳光填坑（暂借毁灭菇贴图 —— 坑就是它炸出来的），
   订阅 `crater_num_changed` 做「有坑点亮 / 没坑置灰」。

### 三种「不能点」别混用（这次最容易踩的）

| 状态 | 写法 | 会被阳光变化覆盖吗 |
| --- | --- | --- |
| 阳光不够 | 什么都不写，`sun_cost` 自己判 | ——（就是它自己在判） |
| 条件不满足 | `card.set_card_blocked(true)` | **不会**（`judge_card_ready` 单独判一道） |
| 一次性用完 | `card.set_card_disabled_forever()` | 不会 |

`set_card_disable()` 是老接口，**会被阳光刷新重新点亮**，做「条件置灰」一定不要用错。

### 探针踩到的两个坑（都是探针自己的问题，不是玩法）

1. **STEP5.6 摆的「死局」其实不是死局**：原来用两种植物隔格排棋盘格，
   而棋盘格里**任意相邻交换都会在另一个方向凑出三连**（交换 (r,c)↔(r,c+1) 会在列 c 上凑出竖三连）。
   → **正解**：三种植物按 `(row + col) % 3` 排对角线 —— 横竖都没有三连，且怎么换都换不出三连，是真死局。
2. **等「提示结束后盘面已刷新」等错了东西**：原来 `await _wait_unlocked()` 等 `is_resolving`，
   但直接调 `_ensure_board_playable()` 这条路**不置这个锁**，于是 1 秒后就断言，4 秒的提示还没走完。
   → **正解**：等「又有步可走了」（`while not mgr._has_possible_move(): await 0.5`）。
   这两个断言之前一直在走 skip 分支没被执行过，换成真死局后才第一次跑起来 —— 摆场类断言要先确保自己真的成立。

### 验证

带窗口跑 `probe_beghouled` → PASS（STEP4 改成点第五张卡填坑，新增「有坑时亮 / 填完坑被封住」等断言）；
回归 `probe_card_slot_conveyor` / `probe_tutorial` 均 PASS。

## 补充（同日后续 2）：刷新 / 填坑两张卡换专用卡面（不再借模仿者 / 毁灭菇贴图）

> 接本条上文（对应本轮追加的第五张卡）。用户提供了专用美术 `assets/image/ui/ui_card/seeds.png`
> （9 个 50×70 整卡种子包横排），要求：裁出**第 4 个**（土坑图案）当填坑卡面、
> **第 5 个**（刷新箭头图案）当刷新卡面，卡面整张直接用，**上面不再叠任何东西**。

### 改了什么

1. 裁图：`seeds.png` 每包 50×70（与 `Card` 的 `custom_minimum_size` 一致），
   第 4 个 = x150、第 5 个 = x200，存成 `SeedPacket_Beghouled_Fill.png` / `SeedPacket_Beghouled_Refresh.png`
   （同目录），并跑一次 `godot --headless --import` 生成 `.import`。
2. 关卡脚本：加 `PACKET_FILL_TEXTURE` / `PACKET_REFRESH_TEXTURE` 两个 preload 常量 +
   `_set_packet_face(card, texture)`（**换 `card_bg.texture` + 清掉 `character_static` 里的模板角色形象**）；
   刷新 / 填坑两张卡建出来后各换一次卡面。身份引用（模仿者 / 毁灭菇）只是**取模板用的壳**，卡面已经与它无关。

### 踩坑

- **按 450/10=45 等分裁会裁歪**：`seeds.png` 是 **9** 个包（每个 50px），不是 10 个；
  没有透明分隔列（整图不透明），等分推不通。→ **正解**：扫「相邻列颜色差」找边界，
  在 x=50/100/…/400 处有整齐的强突变，据此定出等宽 50。
- 新贴图必须先让 Godot 导入一次（`.import` + `.godot/imported/*.ctex`），
  否则直接跑游戏（不进编辑器）时 `preload` 加载不到。
