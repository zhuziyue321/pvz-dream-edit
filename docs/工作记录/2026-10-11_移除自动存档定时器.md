
# 2026-10-11 · 其它 · 移除 SaveService 的 60 秒自动存档定时器

> **任务类型**：其它
> **推荐度**：**推荐**（下次要删「看起来是基础设施、实际只在启动处被调用一次」的东西，照这个顺序查：定义 → 调用点 → 测试脚手架 → 文档）
> **耗时与成本**：约 1 轮对话，未开游戏（编译门禁 PASS）
> **验证方式**：免验证（删的是定时器，存档入口 `save_now()` 与其 20+ 处业务调用点一行未动）+ 已给出人工验证方法
> **补充自**：无（关联 [2026-10-11_新建用户继承上一个账号存档](2026-10-11_新建用户继承上一个账号存档.md) / [2026-10-08_批量回归跑批与存档损坏兜底](2026-10-08_批量回归跑批与存档损坏兜底.md)）

## 目标

删掉全局的定时自动存档：游戏不再每 60 秒落一次盘，存档只在购买 / 关卡结算 / 切用户 / 花园变更等关键节点手动 `save_now()`。

## 步骤

1. 先确认「自动存档」在仓库里到底指什么 —— 搜 `autosave|auto_save|自动存档`，命中的代码只有 `SaveService` 的 `start_autosave` / `stop_autosave` / `_on_auto_save_timer_timeout` 这一套，`save_now()` 的 20 多处业务调用是另一回事，不动。
2. 删 `src/core/autoload/save_service.gd`：三个函数 + `_auto_save_timer` 变量，并在文件头补一句「什么时候存档」的口径（**删完不写这句，后来者会以为漏了功能又加回来**）。
3. 删 `Global._ready()` 里的 `save_service.start_autosave(60.0)`（**唯一的调用点**）。
4. 删 `test/autopilot.gd` 里「关掉自动存档避免污染日志」那段 —— `stop_autosave` 随之不再被引用。
5. 同步 4 处文档：`架构总览.md`（SaveService 职责行 + 启动链路那一行）、`docs/参考存档/未使用代码与资源清单.md`（删掉 `stop_autosave` 那条）、`test/inject/sample_report.txt` 示例输出、`test/scenarios/probe_save_corrupt_guard.gd` 头部注释。
6. 跑 `test/check_scripts.ps1`（`real compile errors = 0`）。

## 关键决策与理由

- **只删定时器，保留 `_save_locked` 损坏保护** —— 因为锁写防的是「下一次 `save_now()` 把空档固化」，手动存档一样会触发，删了定时器不等于这个坑消失；只把注释里的「60 s 后自动存档」改成「下一次 save_now()」。
- **注释里凡是解释"为什么要锁"的地方都跟着改口径** —— 留着「自动存档每 60 s 跑一次」会让后来者以为还有定时器，进而觉得这层保护多余。
- **工作记录里的旧描述不改** —— 那些是历史事实（当时确实有定时器），按 §1-4 只在必要时加过时标注，本次未加。

## 踩坑

1. `save_now()` 的注释里写着「用 verbose 避免自动存档定时刷屏」→ 定时器没了这句就没意义，改回普通口径 → **正解**：删定时器时顺手扫一遍同一文件里提到「自动 / 定时 / 60 s」的注释，别只删函数体。
2. `test/inject/sample_report.txt` 是 autopilot 的示例输出，里面照样印着「已关闭自动存档（避免日志噪声）」→ 它是给人比对的样本，不同步就会对不上 → **正解**：改脚手架行为时把 `test/` 下的示例输出一起搜一遍（搜 `自动存档` 就能捞到）。

## 给后来者的最简路径

1. 搜 `自动存档|autosave`，分清「定时存档」和「手动 save_now()」两类命中。
2. 删 `save_service.gd` 的 3 个函数 + 变量 → 删 `Global._ready()` 的 `start_autosave` → 删 `test/autopilot.gd` 那段。
3. 同一文件内把「60 s / 定时 / 自动」措辞改成「下一次 save_now()」，别把 `_save_locked` 一起删。
4. 同步 `架构总览.md`（两处）+ 未使用代码清单 + `test/` 示例输出 + 探针注释，跑门禁。

**人工验证方法**（若想开游戏）：进商店买一个道具 → 退出到主菜单 → 重新进游戏确认金币 / 道具仍在（说明手动存档还在工作）；再在禅境花园挂机 2 分钟以上，期间不动任何会存档的操作，退出重进确认没有「凭空多出一次落盘」的日志（说明定时器确实没了）。
