## 目标

把商店与一代 PC 原版逐条对账后发现的差异**全部**对齐，共三类：

1. **判定层**：花园解锁关卡、独轮车 Coming Soon 条件、售罄 / 即将推出文案。
2. **交互层**：买不起的处理、卡槽扩充弹窗、智慧树「去看看」、坚果包扎术台词、进店专属开场、5-10 不跳商店。
3. **表现层**：固定 8 格洞位、页码、翻页按钮置灰、ESC 退出、关箱 / 开箱动画、夜间背景、悬停高亮。

## 关键决策与理由

- **花园口径改成 5-4**：原版 `AwardScreen` 在 `aLevel == 45`（刚通完 5-4）就进花园教程，
  而 5-5 开场戴夫的 1301~1303「花园很漂亮，对吧？」本身就建立在「花园已经到手」上 —— 旧的 5-5 口径让这句台词穿帮。
  改成 44 后第三页（花园工具）也随之与原版 `mLevel >= 45` 对上。
- **保留 `visible` 语义但新增 `is_on_shelf()`**：不可用商品要占格位就得 `visible = true`，
  老探针 `probe_card_lock` 里 `not g.visible` 的断言会假红，改判 `is_on_shelf()` 并在注释里写清原因。
- **弹窗在代码里搭**（`store_dialog.gd`）：节点少、样式沿用 `PanelDialogBG` / `PanelButtonBG`，
  手写 `.tscn` 反而容易踩「注释 / 缩进让节点静默丢失」那类坑。
- **4-4 不加进店开场**：原版那边是 `SetupForIntro(601)` 送魔法塔可（带金币动画），本仓库把塔可放在 4-4 通关奖励里，重复说一遍只会矛盾。
- **不做**：原版成就 `Morticulturalist`（本仓库没有成就系统）、试用版商品 / `STORE_ITEM_PVZ`、`mPurchases` 统一存储模型。

## 踩坑

1. `GoodsWheelBarrow` 原来直接 `$StoreIcon`，但那个商品节点**没有** `StoreIcon` 子节点 —— 一进商店就报
   「Node not found」。补 `StoreIcon`（`Zen_WheelBarrow.png`）并把脚本里的赋值删掉。
2. 递归改 `mouse_filter` 会顺手把 `Button` 内部的 Label 改成 `STOP`，把点击吃掉；下架只要改**根节点**过滤 + `button.disabled`。
3. `probe_store_rules` 直接调 `_on_prev_page_button_pressed()` 并立刻断言：翻页改成动画后必须 `await`，
   所以保留 `_show_page()`（立即换页）给探针 / 调试用，动画走 `_flip_page()`。
4. `store.tscn` 的翻页按钮原本 `texture_normal` 错用了 `Store_*ButtonDisabled.png`，一页时看起来像禁用；
   正解是 `normal / hover / pressed / disabled` 四张各就位。

## 给后来者的最简路径

1. 先做一张「原版函数 → 本仓库落点」差异表，再按 判定 / 交互 / 表现 三层分批改，每层跑一次 `test/check_scripts.ps1`。
2. 涉及「关卡序号」的门槛，先确认原版读的是 `mLevel`（下一关）还是已通关序号，否则整排门槛会一起错一关。
3. 改货架显隐前先想清楚「要不要保格位」：要保就 `modulate` + 按钮禁用，别动 `visible`。
4. 收尾：`test/run_autopilot.ps1 -Scenario probe_store_rules`（本机被占用时先让用户关掉 Godot）。

## 人工验证方法（本次未开游戏）

1. 主菜单 → 商店（3-4 后）：进场有招牌下滑 + 开箱；一页时翻页按钮是**灰的**且没有页码；
   多页时页码显示「1 / 3页」，翻页有关箱 / 开箱停顿。
2. 钱 < 商品价时点商品：弹「金币不足」；买得起：弹确认框；按住 ESC 退出商店。
3. 买卡槽扩充：弹「更多卡片槽！…选择 7 植物种子了！」；买智慧树：弹「拜访智慧树？」选「是」直接进花园智慧树页。
4. 通关 3-4 / 5-1 后自动进店：戴夫先说 301/302（车钥匙）或 3100（新货），再说 303/304。
5. 通完 5-4：主菜单出现花园按钮（不是 5-5），商店第三页同时解锁。
6. 买了蘑菇园或水族馆后，第四页独轮车不再是「即将推出」，可花 $200 买下并变成「已售出」。
7. 未通关冒险时进 5-2 看第二页：冰西瓜 / 玉米加农炮 / 模仿者 / 坚果包扎术的位置**留空位**（后面的商品不左移）。
8. 夜晚关卡后进商店：背景换成夜间版 `Store_BackgroundNight`。
