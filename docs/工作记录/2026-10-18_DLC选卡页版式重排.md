# 2026-10-18_DLC选卡页版式重排

> **本次任务**：把 DLC 模组那页选卡从「按装配顺序连续排」改成按用户指定的三行版式摆（含幽灵椒的预留空位）
> **耗时 / 轮次**：1 轮；**没开游戏**（编译门禁 PASS；当时有 godot 进程占着共享输出文件，无头探针按规矩没抢跑）
> **推荐度**：推荐（版式本来就该由模组自己一段常量说清，而不是靠 `install()` 里的数组先后隐式决定）

## 目标

用户给的版式（每行 8 格，与网格模板 `columns = 8` 一致）：

- 第 1 行：投掷蘑菇 / 光照蘑菇 / 臼炮蘑菇 / 血橙 / 闪电芦苇 / 飓衣甘蓝 / 电击蘑菇 / **幽灵椒**
- 第 2 行：蜜蜂射手 / 甜菜守卫 / 拳击白菜 / 芦荟 / 橡木弓箭手 / 缩小紫罗兰 / 柠檬榴弹 / 增幅鹅河菊
- 第 3 行：水盆
- 环轨仙人掌（紫卡）摆在**整页最后一格**（第 6 行第 8 格）

两个现实约束：幽灵椒（GhostPepper）**只有动画、还没接成植物**（`DLC植物导入.md` §8 登记表里没有它）⇒ 该格留空占位；芦荟 / 环轨仙人掌不能从选卡页消失 ⇒ 按上面的位置插进去。

## 最简路径（步骤）

1. `mods_builtin/dlc/dlc_mod.gd` 新增 `#region 选卡页版式`：`CHOOSE_PAGE_SLOTS := 48`（= 网格模板 8 列 × 6 行）
   + `CHOOSE_PAGE_LAYOUT`（`格位下标 → 植物` 的 const 字典，没写的格子留空）。
2. 新增 `_build_choose_page_entries(installed)`：`entries.resize(48)`（`Array[StringName]` 的 `resize` 正好填
   空 `StringName` = `PlantIds.NULL`），再按字典把格位填上；**版式里写了却没装上的那一株换成空位**
   （`register_plant_choose_page()` 只要有一株没卡位就整页返回 -1，不能让它拖垮整页）。
3. `install()` 不再 `choose_types.append(...)`，改成收 `installed` 集合后调上面那个函数登记页。
4. 面板文案（`create_detail_control()` 的「卡位」那行）与 [卡片与选卡流程.md](../参考存档/卡片与选卡流程.md)
   的「参考现状」段同步新版式；`probe_water_bowl.gd` 里「水盆是最后一株」的注释改成「落在第 3 行第 1 格」。
5. 跑 `test/check_scripts.ps1`（compiling 全量 + 145 个 scenario）确认 `real compile errors = 0`。

## 弯路 / 踩坑（三段式）

- **试过**：想直接在 `install()` 的配方数组里调顺序了事。
- **因为**：那个数组同时决定「装配顺序」和「选卡页顺序」，而且幽灵椒预留格、环轨仙人掌摆第 47 格这类位置
  根本表达不出来（中间要留 30 个空格）。
- **结论**：另起一张 `格位 → 植物` 的常量表；装配数组恢复成「按功能分组」的语义，不再兼当版式。

- **踩坑**：`Array[StringName].resize(48)` 填的是空 `StringName` —— 这正好等于 `PlantIds.NULL`（`&""`），
  所以不用再手写一遍 48 个 `NULL`；但换成 `Array[Variant]` 就是 `null` 而不是 `&""`，判空要跟着换。

- **踩坑**：`register_plant_choose_page()` 是一票否决 —— 版式里只要有一株没卡位就整页 -1。
  以前 `install()` 是「装成功才 append」，改版式后这个保护得自己补回来（否则某一株装失败 = 整页没有）。

## 推荐度与理由

推荐：版式只有一处（`CHOOSE_PAGE_LAYOUT`），注释与面板文案从它派生；幽灵椒接上后**只改一个数字**（7 号格填 id）。

后来者注意：

1. 格位下标是**页内格位**（每行 8 格），不是 `card_id`；48 格 = 6 行，第 47 格才是「第 6 行第 8 格」。
2. 空白格会保留在 UI 上（不会往前补），图鉴扩展页用的是**摊平顺序**（跳过空位）——
   水盆的摊平下标 = 原版 48 株 + 本页前 15 格 = 63，仍在第 2 页（`probe_water_bowl` 的那条页码断言照样过）。

## 人工验证方法（未开游戏）

1. 装 DLC 模组进任意关卡选卡 → 翻到最后一页：第 1 行 7 张卡 + 末尾一格空、第 2 行 8 张、第 3 行第 1 格水盆，
   左下到右下 30 格全空，最后一格是环轨仙人掌。
2. 点模仿者 → 模仿者页的格位与普通页完全一致（同一份快照）。
3. 关掉 DLC 模组 → 那一页整页消失，前一页一格不变。
