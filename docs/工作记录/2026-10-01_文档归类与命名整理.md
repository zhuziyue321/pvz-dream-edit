# 2026-10-01 · 文档规范 · 三类文档分层落位并整理命名

> **任务类型**：文档规范
> **推荐度**：**推荐**（下次做同类整理照这个走）
> **耗时与成本**：约 1 轮对话，未开游戏（只改 `docs/` 与代码 / 资源注释里的文档路径，不触达玩法行为）
> **验证方式**：免验证 —— 纯文档与注释改动；人工验证：随机点开 3 份 md 的目录链接 + 全局跑一遍相对链接可达性检查（见「最简路径」第 5 步）
> **补充自**：[2026-10-01_机制类文档降级到工作记录.md](2026-10-01_机制类文档降级到工作记录.md)（本次把该记录的落点又拆了一层）

## 目标

把 `docs/` 收拾成**三层互不混排**的结构：规则 / 方法论留在 `docs/` 顶层，项目相关的机制文档搬进 `docs/参考存档/`，逐次任务的流程记录留在 `docs/工作记录/`；
顺手把文件名里的 `参考_` 前缀去掉（目录名已经说明它是参考），并把重复 / 过小的文档合并掉。

## 步骤

1. 先按用户的分层要求判定三类：**「怎么写」→ `docs/` 顶层**、**「某个模块怎么实现」→ `docs/参考存档/`**、**「这次任务怎么做的」→ `docs/工作记录/`**。
2. `Move-Item` 把 20 份 `工作记录/参考_*.md` 搬进新建的 `docs/参考存档/`，同时改名：去掉 `参考_` 前缀，`子弹说明文档.md` → `子弹说明.md`，`项目规范具体规则存档.md` → `规范细则存档.md`。
3. 合并：`动画系统.md`（12 行）与「插件」章节并入 `项目目录说明.md`；`角色手持物与杂项.md` 与 `手持物实现.md` 重复的手持物摘要删掉，改名为 `杂项存档.md`。
4. 全局替换引用 —— 三轮 PowerShell 替换（md + `.gd` + `.tres`）：
   ① 文件名映射 → ② `docs/工作记录/参考_` → `docs/参考存档/`、相对形态 `参考_X.md` → `X.md` → ③ 兜底 `参考\_`（被转义的下划线）。
5. 补两个新入口：[`docs/参考存档/README.md`](../参考存档/README.md)（19 份明细索引）与 `docs/参考存档/AGENTS.md`（目录指针）。
6. 重写三张索引：`docs/README.md`（新增 §1 三层判定表）、`docs/AGENTS.md`、`AGENTS.md` §2 路由 / §5 维护 / §6 指针表。
7. 给两条会失效的历史记录在文末追加「补充 / 评价」并顶部标「部分已过时」。

## 关键决策与理由

- **用目录而不是 `参考_` 前缀区分类型** —— 上一次把参考文档塞进 `工作记录/` 时靠前缀区分，结果目录 README 得专门解释「本目录混排两类文件」；拆成独立目录后这句话可以删掉。
- **新目录名 `参考存档` 而不是 `参考`/`reference`** —— 与仓库既有的中文命名（`项目规范.md`、`工作记录/`）一致，且文件名不必再带前缀。
- **`规范细则存档.md` 放在 `参考存档/` 而不是顶层** —— 它已经降级为参考，放顶层会破坏「顶层只放规则 / 方法论」这条自洽。
- **小文档合并而不是保留** —— 12 行的文档单独存在时，索引里占一行但内容不够读，并入 `项目目录说明.md` 后「animation 目录 → 怎么产出的 → 用什么插件」是连贯的一条线。
- **历史记录只追加不改写** —— 旧记录里写的落点已经过时，但那是当时的真实决策，按 `工作记录/README.md` §5 加「补充 / 评价」而不是改原文。

## 踩坑

1. 正向替换的顺序会导致漏网：**先把 `参考_项目规范具体规则存档` 整体改名后，路径替换规则 `工作记录/参考_` 就再也匹配不上**（生成 `docs/工作记录/规范细则存档.md` 这种不存在的路径）→ **正解**：先做「文件名映射」，再做「目录路径」替换，最后跑一遍剩余旧前缀的兜底。
2. 被转义的下划线（`参考\_项目规范具体规则存档.md`）替换不掉 → **正解**：再补一轮 `参考\_` → 空字符串的兜底替换。
3. 替换后必须**校验链接可达**，肉眼扫不干净（这次 45 个文件里有 6 处断链全是脚本产不出正确相对前缀导致的）。
4. 显示文案里的旧路径（`看到 docs/工作记录/规范细则存档.md` 这种）不会被路径规则覆盖 → **正解**：改完索引顺手搜一遍「工作记录/」确认剩下的都是任务记录。

## 给后来者的最简路径

1. 先定层：规则 / 参考 / 记录，三类各自一个目录，不要用文件名前缀区分。
2. 搬文件时一次性同时改名（不要先搬后改名 —— 两轮引用替换更容易漏）。
3. 全局替换按「文件名 → 目录路径 → 转义兜底」三轮走，文件范围要包含 `.gd` / `.tres` 注释。
4. 给新目录补 `README.md`（明细索引）+ `AGENTS.md`（指针），再改上层三张索引。
5. 最后跑一次链接检查：遍历所有 md 的 `](...)`（跳过 `http` 与模板占位），解析成绝对路径 `Test-Path`；全过再收尾。
