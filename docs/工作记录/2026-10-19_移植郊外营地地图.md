## 步骤

1. **先确认「郊外」是哪张图**：DLC 维基页面列表里没有「郊外/Outskirts」，`Camp` 与 `Forest`
   都 `#REDIRECT [[Woods]]` —— **Woods = 第 7 章**，地点是玩家营地（wilderness 郊外），
   对应底图 `background7.png`（1400×600，森林环绕 5×9 草坪 + 右侧溪流 + 左上露营车）。
   章曲 Woody Tombstones（Tamir Monteagudo & Andreko）；白天、天降正常阳光
   （早期掉小阳光，Update 2.5 移除）。
2. **几何核对**：把 `map_front` 的格心（col_x + 210 底图偏移、row_y）用 System.Drawing 画到
   `background7.png` 上生成叠加预览 —— 红点全落在草坪格内，**草坪按原版网格绘制、与前院对齐**，
   所以 `map_woods.tres` 直接照抄 `map_front` 几何（与月夜屋顶照抄 `map_boss` 同理）。
3. **素材**：`background7.png` → `pak/images/background7woods.png`、
   `background7_gameover_mask.png` → `background7woods_gameover_mask.png`（露营车车门）、
   `WoodyTombstones.ogg` → `assets_custom/audio/BGM/woody_tombstones.ogg`。
   `background7_layer.png`（前景灌木层）**未移植**（见待办）。
4. **三件套**：`GameBg.Woods` / `GameBGM.Woods` 追加在枚举**末尾**（现有下标零变动）；
   `main_game_home.gd` 的 `door_downs` / `door_masks` 扩到 8（Woods 无内景叠加图，记 null）。
5. **背景子场景** `main_game_bg_woods.tscn`：结构照 `main_game_bg_front.tscn`（无 RoofSlope），
   换底图 + 挂 `Background7WoodsGameoverMask`。
6. **地图** `data/map/map_woods.tres`：几何与 `map_front` 逐格一致（探针逐行比对）。
7. **场景** `scene_woods.gd`（白天 + 掉阳光 + Woods 底图 + Woods 曲）+ 注册表 `SCENE_WOODS`。
8. **探针** `probe_woods_map`：照 `probe_moonroof_map` 改比对对象（map_front）、
   断言「无斜面 / 全 Grass / 全 LawnMover / 场景不开血月」。

## 踩坑

1. **新素材先过导入再跑门禁**：与月夜屋顶那次一模一样 —— 第一遍 `check_scripts.ps1`
   因 png 没生成 `.import` 报一串 `Failed to compile depended scripts`（scary_pot.gd 等），
   再跑一遍即绿。**新底图拷进来第一件事就是跑一遍门禁生成 `.import`**。
2. **`.tres` 别手写 `uid=`**：map_moonroof.tres 就没带 uid（Godot 自动生成），照抄这个风格最稳。
3. **场景脚本没有 `scene_name` 字段**：`SceneSettingBase` 上只有 display_name / game_sences /
   game_BG / game_BGM / 昼夜 / 雾 / 阳光 / is_blood_moon —— 「场景名」只存在于注册表键与
   `ResourceLevelData.scene_name`，场景脚本的 `_init()` 里**不要**给 `scene_name` 赋值（会编译错）。
4. ~~**房门遮罩位置是估的**~~：**次日本轮已校准**。把遮罩图的不透明像素在底图上做
   多分辨率模板匹配（8x 粗搜 → 4x → 1x），`position = (0, 189)` 处 **MSE = 0**
   —— 遮罩图就是从底图这一像素位置抠出来的，车身逐像素重合，不是估值。
   探针已锁 `(0, 189)` 断言防漂移（`probe_woods_map`）。
   ⚠️ 校准时又栽了一次「`.tscn` 注释必须用 `;`」：用 `replace_in_file` 补的 `##` 注释
   被解析器当属性行吞掉，`position` 静默回落默认 `(0,0)` —— 探针的新断言当场抓住
   （读到 `(0.0, 0.0)`）。**无论用哪种编辑方式改 `.tscn`，注释一律 `;`**。

## 验证方式

- `test/check_scripts.ps1` → `real compile errors = 0`（149 个探针脚本）。
- `test/run_autopilot.ps1 -Scenario probe_woods_map` → `[WOODSMAP] result=PASS failed=0`
  （几何与 map_front 逐行一致 / 子场景契约 / 场景设置 / 实机底图 + 8 项遮罩 + 5×9 全 Grass 格子）。
- 回归：`probe_moonroof_map` / `probe_boss_map` 均 `PASS failed=0`（遮罩数组扩到 8 没漂移）。
- **人工肉眼验收**：临时把某冒险关 `scene_name = SceneSettingRegistry.SCENE_WOODS` +
  `map_data = preload("res://data/map/map_woods.tres")` 进关看 —— 草坪格子对齐、不缺行、
  BGM 是 Woody Tombstones；露营车车门遮罩位置已有模板匹配 + 探针断言兜底，不用再看。
