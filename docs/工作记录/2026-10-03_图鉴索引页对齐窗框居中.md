> **任务类型**：其它（UI 布局 / 居中对齐）
> **推荐度**：**推荐**（下次改图鉴索引页布局照这个走：先量背景图的窗框，再摆 UI）
> **耗时与成本**：约 3 轮对话；**未开游戏**（用户自行实测，人工方法见文末）
> **验证方式**：免验证 + 已给出人工验证方法（纯布局改动，静态几何可算，不算玩法行为）
> **同类参考**：[2026-10-03\_分辨率改成800x600.md](2026-10-03_分辨率改成800x600.md)
> （同一类「按像素算居中」的活；那条是改分辨率后重排，本文是**直接量背景图取框坐标**，UI 对齐背景美术时更省事）

## 目标

图鉴索引页（`src/almanac/almanac.tscn` 的 `StartPage`）里，「查看植物」按钮 + 向日葵、「查看僵尸」按钮 + 普通僵尸，
各自要在**背景图 `Almanac_IndexBack.jpg` 画好的那个窗框**里居中（左棕框 / 右蓝框），顶部标题「图鉴--索引」也要居中。

## 步骤

1. **先量背景图，不猜坐标**。用 PowerShell + `System.Drawing` 直接读 `assets/image/Almanac/Almanac_IndexBack.jpg`
   （800×600，与设计分辨率 1:1，所以**图像坐标 ≡ 屏幕坐标**）：按亮度阈值（`0.3R+0.59G+0.11B < 160`）
   在 `y=300` 行 / `x=210`、`x=590` 列上扫连续暗区，得到两个窗框的包围盒。
2. 拿到的实测值（**这是本文最值钱的部分，以后改这一页直接用**）：

   | 元素 | 图像坐标 | 中心 |
   | --- | --- | --- |
   | 左侧棕框（植物） | x 23..396，y 171..429 | (209.5, 300) |
   | 右侧蓝框（僵尸） | x 408..777，y 172..431 | (592.5, 301.5) |
   | 顶部标题条 | x 104..688，y 26..77 | (396, 51.5) |

   两框合起来 23..777，中心 = 400 = 屏幕中心 ✓（素材本身对称）。
3. 两个 `Panel`（`StartPage/Panel`、`StartPage/Panel2`）的 offset 改成贴合窗框（中心锚 0.5，offset = 目标 − 400/300）：
   左 `-377/-128 → -4/130`、右 `8/-128 → 377/130`。
4. 按钮 / 角色在框内**水平居中**：`PlantButton` offset 由 `-86/+70`（中心 −8）改 `±78`；
   `Plant002SunFlower.position` `(162,125) → (187,141)`（187 = 框宽 374 的一半）；
   `Zombie001Norm.position` `(157,141) → (185,170)`（185 = 框宽 370 的一半）；`ZombieButton` `±89.5`。
5. **垂直位置按「屏幕绝对 y 不变」反推** —— panel 底边从 405/400 下移到 430 后，
   按钮用底锚（`anchor_top/bottom = 1.0`）就要把 offset 同步加大（`-60/-18 → -85/-43`），
   角色是硬摆的 `position`，直接加 panel 顶边的位移量（向日葵 +16、僵尸 +29）。
   这样只「对齐窗框」，不改动原本的观感高度。
6. 顺手把两个 Panel 的样式盒从 `StyleBoxFlat` 改成 `StyleBoxEmpty`。

## 关键决策与理由

- **Panel 尺寸做成"贴合窗框"而不是"保持原尺寸再居中"** —— Panel 带 `clip_children = 1`，
  它的矩形就是裁剪边界；贴合窗框后，以后往框里塞东西（阴影、特效）不会溢出框外，也不会被框边切掉。
- **Panel 样式盒必须空** —— `StyleBoxFlat` 的 `bg_color` 默认是灰的（`Color(0.6,0.6,0.6)`），
  一整块灰底会把背景图里画好的窗框（棕 / 蓝木框）盖住。同目录的 `almanac_character_show_panel.tscn`
  本来就用的 `StyleBoxEmpty`，照它的写法改。
- **标题居中以屏幕中心 400 为准，不是标题条中心 396** —— 标题条在素材里就左偏 4px（104..688），
  差 4px 肉眼不可见；以 400 为准则 offset 是对称数（±100），以后一眼就能看出"居中了没"。
- **没动 `ZombieButton` 的宽度** —— 它的纹理 `button_BG.png` 是 120×50，offset 却给到 179 宽（横向拉伸 1.49 倍）。
  这是另一个问题（变形），不属于"居中"，没顺手改，留给用户定夺。

## 踩坑

1. **改容器尺寸后，底锚子节点的 offset 必须同步重算** —— `anchor_top/bottom = 1.0` 的 offset 是相对**容器底边**的，
   容器底边从 405 → 430 时，offset 不变就会整体下移 25px（本例中原本"距框底 42px"会变成"距框底 67px"）。
   → **正解**：写死"距底距离"这个观感量，再反算 offset。
2. **`StartPage` 是全屏 `TextureRect`（`anchors_preset = 15`）且纹理就是 800×600** ——
   它的子节点局部坐标 ≡ 屏幕坐标，所以算出来的图像坐标可以直接当 offset 用；
   换成别的父节点（有缩放 / 有偏移）就不能这么抄。
3. **`.tscn` 里不能写 `##` 注释** —— 我给 `sub_resource` 加了两行 GDScript 风格的 `##` 说明，
   场景直接加载失败：`Parse Error: Expected '['`（`resource_format_text.cpp`），
   从主菜单点图鉴进去就是一片空白 + 同帧还会冒一条 `Invalid color code: #`（解析器把 `#` 当颜色值）。
   → **正解**：tscn 只认 `;` 开头的注释；想留说明就写进文档（本文件）或同目录 `.gd` 脚本，别写进场景文件。
4. **别用 ASCII 字符画去"看"图片** —— 第一次我用 10px 步长打字符图，结果整片区域都是同一个字符，
   误判成"中间全是暗的"。→ **正解**：直接采样关键行 / 列的**原始 RGB**，再按亮度阈值找连续区间。

## 给后来者的最简路径

1. 用 `System.Drawing` 读背景图，按亮度阈值扫出目标区域包围盒（图像尺寸 = 视口尺寸时，坐标可直接用）。
2. 容器 offset = 目标坐标 − 锚点基准（中心锚即 400 / 300），让容器贴合目标区域。
3. 容器内元素：水平 offset 取对称（±w/2）；垂直先定"距容器底多少 px"，再反算底锚 offset。
4. 容器若是 `Panel` 且只用来裁剪，样式盒用 `StyleBoxEmpty`。

## 追加（同日）：植物 / 僵尸两个子页也回到 800×600

索引页修完后用户提：「图鉴——植物」与「图鉴——僵尸」也要 800×600 的样式。查出来的根因是**底图用错了版本**：

- `PlantPage` / `ZombiePage` 用的 `Almanac_PlantBack_New.png` / `Almanac_ZombieBack_New.png` 是 **1066×600**（旧设计分辨率时横向补画的），
  而仓库里一直躺着原版 **800×600** 的 `Almanac_PlantBack.jpg` / `Almanac_ZombieBack.jpg`。
- 更糟的是这两个页面节点还是 `layout_mode = 0` + `offset 40/40`（**40×40 的小方块**），
  所有子节点都按这个 40×40 去解锚点 —— 页面根本没铺满。

**改法**：

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 底图 | `*_Back_New.png`（1066×600） | `*_Back.jpg`（800×600，原版） |
| 页面本体 | `layout_mode = 0`，40×40 | `anchors_preset = 15` 全屏 |
| 两页标题 | 非对称 offset（中心 389） | 对称 ±100 + `horizontal_alignment = 1`（中心 400，与索引页一致） |
| 展示面板（植物） | 右锚 −474/−157 | 右锚 −344/−27（绝对 456..773） |
| 展示面板（僵尸） | 右锚 −480/−163 | 右锚 −344/−27（同一个位置） |
| 僵尸网格 | 29..443（宽 414，内容只有 383） | 29..412（宽 = 内容宽 383 = 5×75 + 4×2） |

- 右侧展示面板统一放到背景图右侧空白区（x 445..790）的中间：`AllBg` 324 宽 → 456..780，两页对齐。
- 植物页的虚线网格区实测 **x 26..442**，8 列卡片 414 宽 → 容器 27..441 **本来就是对的**，不用动。
- 僵尸页底图没有虚线格，网格只按「内容宽 = 容器宽」修正宽度。

## 人工验证方法（本次未开游戏）

1. F5 启动 → 主菜单进图鉴（需先通关 2-4 解锁，或用调试通道直接切 `MainScenes.Almanac`）。
2. 看索引页：**两个窗框完整露出**（不再有灰块盖住木框）；「查看植物」按钮在左框内左右居中、
   「查看僵尸」按钮在右框内左右居中；向日葵在左框中间、普通僵尸在右框中间。
3. 点「查看植物」进植物页：底图铺满 800×600（不是左上角的小方块）、标题「图鉴--植物」居中于深棕标题条、
   8 列卡片落在左侧虚线格子里、右侧信息卡贴住右侧空白区、左下角「图鉴索引」按钮在底部边框内。
4. 点「查看僵尸」进僵尸页：底图铺满、标题「图鉴--僵尸」居中于蓝色标题条、5 列僵尸卡在左侧、右侧信息卡与植物页同一位置。
5. 点「图鉴索引」回来，位置不变（说明 offset 没被动画覆盖）。
