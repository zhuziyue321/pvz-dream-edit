# 2026-10-03 · 资源改名 · 顶层目录重构：`scripts/`+`scenes/` 合并为 `src/`，去编号前缀，全量修引用

> **任务类型**：资源改名
> **推荐度**：**推荐**（下次做同类全量目录重构照这个走）
> **耗时与成本**：约 4 轮对话，未开游戏（跑无头探针 `probe_init` / `probe_zom_botany` / `probe_garden_bg` / `probe_store_rules` / `probe_tutorial_1_2` 全 PASS）
> **验证方式**：跑了无头探针（画面仍需人工看一眼）
> **补充自**：[2026-10-03_关卡目录移到根目录改名level.md](2026-10-03_关卡目录移到根目录改名level.md)（同类的「移动目录 + 全量改引用」流程）

## 目标

把顶层散落的 7 个目录收敛成现代布局，并把文件名里的数字编号前缀去掉：

- `scenes/` + `scripts/` 两棵平行树 → 合并为 `src/`，**同一功能的 `.tscn` 与 `.gd` 同目录**；
- `resources/` → `data/`，并去掉 `*_resource` 后缀，`script/` 子目录取消（资源与脚本同置）；
- `level/` → `src/levels/`（`level/script/` → `src/levels/core/`）；
- `level_game_para/` → `data/levels/params/`、`shader_material/` → `shaders/materials/`、`readme_show/` → `docs/images/`、`data/*.tres` 归入 `data/ui/themes/` 等；
- 文件名去掉 `NNN_` 前缀（`plant_001_pea_shooter_single.gd` → `plant_pea_shooter_single.gd`、`01_start_menu.tscn` → `start_menu.tscn`、`animation/character/plant/011_fume_shroom/` → `.../fume_shroom/`）；
- `images/`（1085 个文件）**按用户要求保持原地不动**。

判定标准：迁移后 `res://` 引用零缺失、9 个 autoload 能起来、关卡能进、植物僵尸能实例化。

## 步骤

1. 先做**只读清查**：导出 `scenes/` `scripts/` `resources/` `level/` 的全量文件清单，确认 `scripts/` 与 `scenes/` 是「同名子目录一一对应」的平行树。
2. 写迁移脚本（`%TEMP%\pvz_migrate.ps1`），**先 dry-run 输出 `旧路径 => 新路径` 计划（1340 条）并做目标冲突检测**，确认 0 冲突后再 `-Apply`。
3. 移动时**连 `.uid` 一起搬**（`af.gd` / `af.gd.uid` / `af.gd.uid` 三件套），并清理搬空后的空目录。
4. 写引用重写脚本（`%TEMP%\pvz_rewrite.ps1`）：从计划文件构造「旧→新」字典，编译成**一个长优先的正则 alternation**，对含旧路径标记的 495 个文件做一次性替换。
5. 写校验脚本（`%TEMP%\pvz_verify.ps1`）：扫全仓库 `res://` 字符串，`Test-Path` 逐条验证，把缺失数从 47 降到 20（剩下的全是误报：中文标点截断、运行时生成的输出路径、`.godot` 里的二进制碎片）。
6. 再跑第二遍重写（`%TEMP%\pvz_rewrite2.ps1`）处理**文档正文里的裸文件名**（`plant_000_base` → `plant_base` 这类，75 个文件）。
7. 修 `.md` 相对链接（`%TEMP%\pvz_links.ps1`），把 `src/levels/`、`src/core/consts/` 下指针文件的 `../docs/` 改成正确层数。
8. 删掉 `.godot/uid_cache.bin` / `global_script_class_cache.cfg` / `scene_groups_cache.cfg`，强制 Godot 重建缓存。
9. 更新文档：根 `AGENTS.md` §1/§2/§6、`src/AGENTS.md`、`src/README.md`、`data/AGENTS.md`、`data/README.md`、`docs/README.md` §3、`docs/参考存档/项目目录说明.md`、规范细则 D-02/D-03/D-04/D-06。

### 走过的弯路

- ~~只替换 `res://` 开头的完整路径~~ → 漏掉三类：① 字符串拼接出来的目录（`const LEVEL_DIR := "res://level"` 没有尾斜杠）；② 代码里的**裸目录名**（`load_resources_with_get_files("level_game_para")`）；③ 文档正文里的裸文件名。**正解**：完整路径替换 + 目录前缀替换 + 文件名替换，三遍都要跑，最后用校验脚本兜底。
- ~~把所有 `.res` 也当文本改写~~ → `animation/**/*.res` 是 **RSRC 二进制**（`all_anims.res`），改了会损坏。**正解**：重写脚本的扩展名白名单里排除 `.res`。

## 关键决策与理由

- **`src/` 而不是 `features/`**：`src/` 是 Godot 社区更常见的约定，且 `test/` `docs/` 与之对称；`src/levels/` `src/core/` 这类子目录名能直接表达层级。
- **编号前缀只去掉「纯排序用」的**（`plant_001_` `01_start_menu`），**保留有语义的**：关卡号 `adventure_01_01`（显示给玩家）、教程步骤 `step_01`、对话 `opening_000`（有顺序）。
- **注册表 id 与文件名解耦**：`CharacterRegistry` / `BulletRegistry` / `MainSceneRegistry` 里的编号不动，文件名只留语义名 —— 编号唯一落在注册表（硬约束 §1-4）。
- **`images/` 不动**：1085 个文件的 `.import` 重导成本高、收益低，用户明确选择保持原地。
- **植物僵尸场景去掉尾部 `_zombie`**：`zombie_031_pea_shooter_zombie.tscn` → `zombie_pea_shooter.tscn`，与脚本名对齐。

## 踩坑

1. **`project.godot` 没被改写** → 因为重写脚本按扩展名白名单过滤，而 `.godot` 不在列表里 → autoload 9 条还指向 `res://scripts/...`。**正解**：单独手工改 `project.godot` 的 9 行 autoload。
2. **`res://level` 不带尾斜杠没被替换**（本文出现的 `res://level` / `res://scripts/` 均为引用的**旧路径示例**，不是真实引用，校验脚本会把它俩算进「缺失」里，属预期误报） → `level_registry.gd` 的 `LEVEL_DIR`、`test/scenarios/probe_levels.gd`、`tool_level_tres_to_script.gd` 都写的是 `"res://level"`。**正解**：单独补 `"res://level"` → `"res://src/levels"`。
3. **动画目录里的 `.tscn` 引用没被改写** → 第一轮按「含 `scripts/` `scenes/` 等标记」筛文件，`animation/**/*.tscn` 里只有 `res://animation/...`，没命中标记。**正解**：把 `animation/` `data/` `level/` 也加进标记列表重跑。
4. **同名 `AGENTS.md` / `README.md` 撞车** → `scripts/` 与 `scenes/` 各有一份，合并到 `src/` 会互相覆盖。**正解**：迁移脚本给冲突目标加 `.tmp_scripts` 后缀，之后重写合并内容并删除；`.md` 里被替换出的 `xxx.md.tmp_scripts` 链接也要全局清掉（56 个文件）。
5. **迁移脚本自身编码** → PowerShell 5 默认按 ANSI 读 `.ps1`，脚本里的中文注释会导致解析失败。**正解**：写完脚本后用 `WriteAllText(..., UTF8Encoding($true))` 转成 **UTF-8 BOM** 再执行。
6. **godot 无头跑 stdout 是空的** → 项目开了 `file_logging`，日志在 `%APPDATA%\Godot\app_userdata\GodotPVZ-Dream_me\logs\`。**正解**：跑探针用 `test/run_autopilot.ps1 -Scenario <name>`，它自带报告输出。

## 给后来者的最简路径

1. 写「旧路径 => 新路径」映射脚本，**先 dry-run 查冲突**。
2. 移动时一定连 `.uid` 一起搬；排除二进制 `.res`。
3. 重写引用跑三遍：完整路径 → 目录前缀 → 裸文件名；`.godot` 要单独改。
4. 用「扫 `res://` + `Test-Path`」脚本兜底，把缺失数清零（误报要人工过一遍）。
5. 删 `.godot` 的 uid / class 缓存，再跑 `run_autopilot.ps1 -Scenario probe_init` 确认能进关卡。
