## 目标

把 `docs/项目规范.md` 里的**具体规则**（`D-` / `K-` / `C-` / `S-` / `M-` / `V-` / `E-` 各卡片正文、常见任务流程、附录）
整体降级为**参考、非强制**并搬进 `docs/工作记录/`，`docs/` 只保留宏观硬约束。

## 步骤

1. 用 PowerShell 按行号切出 `项目规范.md` 第 74–1148 行（§1 目录结构 ~ 附录 B）作为存档正文 —— 不手工誊写。
2. 逐行降级措辞：**跳过** `#` 开头的标题行与 `](#锚点)` 片段（保住锚点不被改坏），
   正文里 `必须→建议` / `禁止→不建议` / `不得→不宜` / `应该→可以`。
3. 修正相对链接：`](xxx.md)` → `](../xxx.md)`（存档在子目录），`](../AGENTS.md)` → `](../../AGENTS.md)`。
4. 手写新的 `docs/项目规范.md`：**§1 七条宏观硬约束** + **§2 完整规则目录**（编号 + 一句话 + 存档锚点链接）+ §3 维护约定 + §4 关联文档。
5. 全局修链：`项目规范.md#锚点` → 存档对应锚点（docs 顶层 / 工作记录目录 / AGENTS.md 三套前缀分别处理，共 16 处）。
6. 同步 `AGENTS.md` §2–§5、`docs/README.md` 索引与维护约定、`docs/参考意见存档.md`、`docs/工作记录/README.md` 的措辞与路由。

## 关键决策与理由

- **用脚本切正文而不是重写** —— 存档 6 万字符、含大量代码块，手写必定抄错，脚本还能原样保留格式。
- **标题行与锚点不参与替换** —— 否则卡片内部互相跳转失效，且外部 16 处 `项目规范.md#xxx` 链接全部断掉。
- **docs 留「完整目录 + 一句话 + 链接」而不是只留一句「详见存档」** —— 后来者能先在 docs 里判断要不要点进去。
- **归档纪律（E-05）从「必须」降为「应该」** —— 卡片已降级，若 `工作记录/README.md` 仍写「必须」就等于「降级了但还有一处必须」。

## 踩坑

1. 全文替换「必须」会把标题与行内锚点一起改掉，卡片内跳转全部失效 → **正解**：按行处理，跳过标题行并用正则保护 `](#...)` 片段。
2. 存档放进 `docs/工作记录/` 子目录后，原文档里的同级相对链接（如 `开发相关.md`）全部失效 → **正解**：统一给 `](xxx.md)` 加 `../` 前缀，`AGENTS.md` 单独补一层。
3. `参考意见存档.md` 里写着「D-05 / D-06 **没有降级**，仍是硬约束」，本次降级后这句变成错的 → **正解**：降级完成后全局搜「仍是硬约束 / 没有降级 / 红线清单 / §8」这类断言并改掉。
4. `replace_in_file` 报「1075 lines removed/added」看似整文件被重写 → **正解**：那是工具的行尾归一化告警，实测 CRLF=0 / 无 BOM / 内容完整，先跑一次字节级校验再继续。
