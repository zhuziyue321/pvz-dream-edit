  只有把三处取值摆在一起才现形。本次 10 条发现里有 3 条来自这一步。
- **`push_error` 全量换成 `Log.error` 之前先确认所在函数** —— autoload 的全局名只在节点加入 root 后可用，
  若某处落在 `_init()` 里，换 `Log` 会在启动时直接崩。确认过 18 处全在普通函数（`Log` 是 `project.godot` 里第一个 autoload）才动。
- **僵王受击框不修** —— 现象是「低头了可能打不掉」，但改法依赖对 Godot Area2D 重叠刷新行为的实测，
  本机无 Godot，盲改风险大于收益，留人工验证方法。

## 踩坑

1. **子代理返回结果没内容** —— 一次派了 4 个 `code-explorer` 子代理并行查四个子系统，只回「Execution Summary: N tool uses」，
   没有 findings。→ **正解**：结论性分析任务别指望子代理回传长文本，自己用 `search_content` 定位 + 精读关键文件更快也更可控。
2. **`rg` 不在 PATH** —— PowerShell 里直接敲 `rg` 报 CommandNotFound。→ **正解**：用 `search_content` 工具（底层就是 ripgrep）；
   要「统计取值分布」这类聚合时，用 `outputMode: "count"` 或收窄 `path` + `glob` 避免 buffer 溢出。
3. **`search_content` 全仓库搜 `collision_mask` 会超 buffer 被截断** —— 结果里丢了 `.gd` 里的运行时设置。
   → **正解**：按目录 / `glob` 分批搜，或用更精确的正则（如 `collision_mask = (20|2068|4116)$`）。
4. **`to_disconnect` 的清理条件是逻辑反转而非笔误** —— 它同时装「失效连接」和「once 连接」两类，
   原作者只为后者写了清理，却把保护条件写成了对两者通用的形式。→ **正解**：改成带 `obj_id` 的结构体，
   让两类各自走自己的清理路径，不要指望一个 `if` 覆盖两种语义。

### 可复用手法：批量校验 `res://` 断链

改名 / 移动目录之后跑这一条（PowerShell，仓库根执行）：

```powershell
$all=@(); Get-ChildItem -Recurse -File -Include *.gd,*.tscn,*.tres -Path src,data | ForEach-Object {
  $c = Get-Content $_.FullName -Raw -EA SilentlyContinue
  if($c){ foreach($x in [regex]::Matches($c,'res://[^\s"]+')){ $all += ($x.Value).TrimEnd(')',',','.',"'",'"',';') } } }
$u = $all | Sort-Object -Unique
$miss=@(); foreach($p in $u){ if(-not (Test-Path -LiteralPath ($p -replace '^res://',''))){ $miss += $p } }
"unique=$($u.Count) missing=$($miss.Count)"; $miss
```

两个坑：① `Test-Path` **不认 `res://` 前缀**，必须先 `-replace` 成相对路径，否则全库报 missing；
② 中文文件名 + 文件名带空格会误报（本次 9 条"missing"里 5 条是这两类误报，`方正少儿_GBK.ttf` 其实存在）。
真断链为 0 —— 说明 2026-10-03 那两次大改名（`scripts/+scenes/→src/`、`level_date_resource→src/levels/`）的引用改干净了。
