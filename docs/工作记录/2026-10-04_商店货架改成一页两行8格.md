# 2026-10-04 商店货架改成「一页 8 格、分上下两行」

## 需求

用户给出原版货架在四个进度点的快照（3-4 / 4-4 / 5-1 / 5-10），确认分页口径为
**一页 8 格 = 上下两行、每行 4 格**（用户表里的一整条 = 一页，`/` 是页内两行的分界）。

## 最短路径（推荐度：高）

1. **数据层**：`src/core/consts/const_shop.gd` 加 `SHOP_ROW_SLOT_NUM`(4) / `SHOP_PAGE_SLOT_NUM`(8) /
   `PAGE_SHOP_LEVEL`（每页上架关卡）+ `get_page_shop_level()`；
   `const_unlock_level.gd` 抽出 `SHOP_EXPAND_SECOND_ADVENTURE_LEVEL`(41) 供常量表复用。
2. **场景**：`store.tscn` 在 `Bg/Car2/Panel` 下放 6 个 `HBoxContainer` 行容器，
   **页内第一行 offset_top=59/底部 148，第二行 163/252**（原版两行的上下位置）。
3. **脚本**：`store_manager.gd` 用 `pages = [[第一行, 第二行], ...]` 表达页；
   `_refresh_valid_pages()` 按 `PAGE_SHOP_LEVEL` 筛 `valid_pages`；`_show_page()` 一次显示一页的两行。
4. **探针**：`probe_store_rules`（4 页 + 翻页回绕）、`probe_card_lock`（3-4 只有 1 页）、`probe_shop_expand`。

## 弯路

- 先做过一版「一行 = 一页」（6 页），用户纠正为「一页 8 格分两行」，白改一轮。
  → 结论：**分页口径先问清再动手**（一行几格、一页几行）。
- `var max_level := Global.global_game_state.get_max_success_adventure_level()` 报
  `Cannot infer the type`：autoload 访问器无静态类型，**必须写 `var max_level: int = ...`**。

## 踩坑

1. autoload 返回值不能靠 `:=` 推断类型（`Global.*` 一律显式标注类型）。
2. Godot `--check-only` 在无头下不注册 autoload，会刷一堆 `Identifier not found: Global`，
   **只能用来看语法错误，不能当作编译通过的依据** —— 真验证要跑探针。

## 补充（同日：蜗牛商品落位 + 巧克力移出商店）

原版货架第四页第一行是「蘑菇园 → 水族馆 → 蜗牛 → 智慧树」，蜗牛**不是**单独一页；
巧克力**不在商店出售**（库存只来自花园掉落）。落位时又踩一个坑：

1. **`.tscn` 里不能写 `##` 注释**：Godot 文本资源只认 `;` 注释，`##` 行会被当属性解析失败，
   **后面的整个节点段被静默丢弃**（不报 Parse Error）—— 表现是场景能打开、新节点不存在，
   脚本 `get_node()` 拿到 null 才炸（`Invalid access to property or key 'visible' on a base
   object of type 'null instance'`）。已沉淀为 [M-05](../../参考存档/规范细则存档.md#m-05-手工编辑-tscn-不写注释)。
   → 排查手段：写一次性脚本 `load("res://...tscn").instantiate()` 打印子节点名，30 秒定位。
2. **巧克力不在货架上但要保留消耗品身份**：`CONSUMABLE_GARDEN_TOOL_PRICE` 里仍留 Chocolate，
   否则 `is_garden_tool_available()` 会走「买断」分支、巧克力按钮永远不出现；只是货架上没有它。
3. 蜗牛买断走既有链路（`ConstShop.SNAIL_PRICE = 3000` → `buy_garden_tool` →
   `GardenManager._init_stinky()`），商品端零新代码，只动 `.tscn` + `pages` 表。
