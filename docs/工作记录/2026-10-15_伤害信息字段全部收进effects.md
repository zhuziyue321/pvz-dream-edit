## 目标

`DamageInfo.effects` 成为**唯一真源**：`mode` / `cause` / `target` / `attacker` / `source` /
`is_instant_kill` / `is_drop_on_death` / `is_drop_2` / `trigger_sfx` / `final_amount`
与既有的 `amount` 一样，全部改成 `effects` 的**代理访问器**。
**全仓调用点一行不改**（`info.mode = x` 照写）。

## 步骤

1. **先摸清使用面**（决定能不能动）：搜 `DamageInfo` 被引用的 24 个文件 + `info.<字段>` 的 42 处。
   ⊙ 关键结论：`.effects` **只在 `damage_info.gd` 内部读写**，外部一律用具名字段 ⇒ 字典里多出「不是效果」的 key 不会炸任何遍历 / 序列化代码。**这一步是前置条件，跳过去就是赌博。**
2. `ConstDamage` 新增「元信息 key」region：`KEY_MODE` / `KEY_CAUSE` / `KEY_TARGET` / `KEY_ATTACKER` / `KEY_SOURCE` / `KEY_INSTANT_KILL` / `KEY_DROP_ON_DEATH` / `KEY_DROP_2` / `KEY_SFX` / `KEY_FINAL_AMOUNT`（值统一 `meta_` 前缀）+ `META_KEYS` 数组（打印 / 遍历时过滤用）。
3. `damage_info.gd`：11 个一等字段改成 `var x: T: get: return effects.get(KEY, 默认)`；`to_debug_string()` 用 `META_KEYS` 滤掉上下文，只打印真正的效果名。
4. 同步 `docs/参考存档/伤害系统.md`：§1 文件清单职责列、§3「效果包」整节重写 + 新增「两类 key」小表、§12 迁移记录加一行。
5. 跑 `test/check_scripts.ps1`。

## 关键决策与理由

- **做成代理访问器，而不是删掉具名字段只留字典** —— 与既有 `amount` 同一套做法：字典是真源（不会两处各存一份而漂移），具名字段保住可读性，全仓 42 处调用点零改动。**「字典是真源」和「字段好读」不是二选一。**
- **元信息 key 加 `meta_` 前缀** —— 打印 / 遍历时能一眼分开「上下文」与「效果」；也免得将来某个效果也叫 `source` 时撞 key 还**静默失效**（拼错 key 不报错）。
- **默认值留在 getter 里（`effects.get(KEY, 默认)`），不预写进字典** —— 预写会让「包里到底写了什么」失真，也和 `get_effect()` 「不自动塞默认值」的语义打架；走 `has_effect()` 查元信息的行为没人依赖。
- **`final_amount` 也一并代理** —— 它是 `DamageSystem` 回填的结算结果，跟其它元信息一样只是随包走一段，没有理由留成唯一一个独立字段。
- **不额外加 `set_effect()` 的元信息拦截** —— 目前没有遍历 / 转发 effects 的场景，加拦截是提前上浮的复杂度，靠注释里的两条纪律（别手写 `meta_*` 字符串、同一项别混用两种写法）就够。

## 给后来者的最简路径

1. 确认没有代码遍历 / 序列化 `effects`（有就得先给它加过滤）—— **前置条件**。
2. `ConstDamage` 加 `KEY_*` 常量（值带 `meta_` 前缀）+ `META_KEYS` 数组。
3. `DamageInfo` 的一等字段逐个改成 `var x: T: get: return effects.get(KEY, 默认) / set(v): effects[KEY] = v`。
4. 调试打印处用 `META_KEYS` 过滤。
5. 跑门禁。

## 人工验证方法（本次免验证，若要验照这七条）

改动是语义等价的（getter 默认值与原来的字段初值一一对应），但落在全场唯一伤害入口上，建议开一局普通白天关走一遍：

1. 豌豆射手打普通僵尸正常掉血、掉手 / 掉头正常（`mode` / `cause` / `target`）。
2. 寒冰菇冰冻后解冻减速（`EFFECT_FREEZE` / `EFFECT_SLOW` —— 验证「效果与元信息混在同一张字典里」没互相顶掉）。
3. 地刺扎洗冰车 / 投石车**（`is_instant_kill`）**、扎巨人免疫、扎雪橇车小队只掉血。
4. 铲子铲植物、僵尸死亡掉金币（`is_drop_on_death` / `is_drop_2`）。
5. 残血流失（临界值组件）**不播**受击音效（`trigger_sfx = false`）。
6. 磁力菇吸铁桶 + 击杀者判定（读 `attacker` 的载具反伤链路）。
7. 控制台开日志后看一眼 `to_debug_string()`：effects 那一栏**只剩效果名**，不该出现 `meta_*`。
