## 换算基准

`Panel` 是 `Car2` 的子节点，原点 = Car2 左上 = 屏幕 `(196, 138)`，与原版车体绘制原点一致，
所以 **Panel 内 offset = 原版坐标 − (196, 138)**（上排行 226/68，下排行 176/172）。
goods 槽 67 宽 → `separation = 74 − 67 = 7` 才是原版格距。

## 踩坑 / 方法

1. **读 PNG 尺寸别手撸字节偏移**：IHDR 宽高在偏移 16/20 是对的，但用 `Add-Type System.Drawing` 的 `Image.FromFile` 最省事、最不易错（本次手撸先读错过一轮）。
2. **翻页按钮位置依赖 Car2 宽度**：Prev/Next 按钮用 `anchors_preset = 7`（底部居中）挂 `Car2` 下，位置 = `Car2 宽/2 + offset`。`Store_Car.png` 实测 604×462 → 半宽 302，代入原版 252/596 反推 offset 正好吻合，可当作「Car2 原点 = 原版车体原点」的旁证。
3. **招牌曾被拉伸**：旧节点 508×124 把 440×108 的图拉变形；对齐坐标时顺带按原图尺寸落位。
4. 探针（`probe_store_rules` 等）只断言节点名 / 显隐 / 顺序，不碰坐标，本次零探针改动。
