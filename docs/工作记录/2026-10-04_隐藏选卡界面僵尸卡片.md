# 2026-10-04 · 其它 · 隐藏选卡界面的僵尸卡片（开关 ZOMBIE_CARD_ENABLED=false）

> **任务类型**：其它
> **推荐度**：**推荐**（再要临时下线某个玩法，照这个走）
> **耗时与成本**：约 1 轮对话，未开游戏（免验证 + 已给人工验证方法）
> **验证方式**：免验证（改动是「不生成一页 + 跳过分支」，已对空字典 / 空列表做了索引保护）+ 已给出人工验证方法
> **补充自**：[2026-10-04_隐藏关卡内手套功能](2026-10-04_隐藏关卡内手套功能.md)（同一套「单点开关」做法）

## 目标

隐藏**选卡界面的僵尸卡片**：待选卡槽不再出现僵尸候选卡页，关卡的预选僵尸卡（`pre_choosed_card_list_zombie`）
在 `CardSlotNorm` / `CardSlotCoin` 两条通道里全部失效，「重选上次卡片」也不再恢复僵尸卡。
代码与场景节点保留，改一个常量即可恢复。

## 步骤

1. **先把开关集中**：新建 `src/core/consts/const_feature_switch.gd`（`class_name ConstFeatureSwitch`），
   把上一个任务的 `GLOVE_ENABLED` 从 `ConstUnlockLevel` 迁过来，再加 `ZOMBIE_CARD_ENABLED := false`。
   全文替换 `ConstUnlockLevel.GLOVE_ENABLED` → `ConstFeatureSwitch.GLOVE_ENABLED`（6 个代码文件 + 2 个探针）。
2. `card_slot_candidate.gd::_ready()`：僵尸页初始化包进 `if ConstFeatureSwitch.ZOMBIE_CARD_ENABLED:`。
3. `card_slot_norm.gd`：`init_pre_choosed_card()` 里僵尸分支 `continue` + 僵尸列表取值加下标保护 +
   「僵尸列表更短就 break」那条也带上开关；`_on_re_card_button_pressed()` 的僵尸分支加开关 + `has()` 保护。
4. `card_slot_coin.gd::init_pre_choosed_card()`：同样处理（它不走待选卡槽，直接复制卡）。
5. 文档：[卡片与选卡流程.md](../参考存档/卡片与选卡流程.md) 顶部加「当前隐藏」小节；
   给上一条手套记录追加「开关已迁到 ConstFeatureSwitch」的补充。

## 关键决策与理由

- **新建 `ConstFeatureSwitch` 而不是就地加常量** —— 手套开关原本塞在 `ConstUnlockLevel`（因为它在解锁判定上），
  僵尸卡开关与"解锁"毫无关系；两个开关散在两个文件里，第三个就不知道放哪。
  现在**功能开关只有一处**，且迁移成本就是一次全文替换，早做比晚做便宜。
- **不调用僵尸页初始化，而不是"生成后再隐藏"** —— 省掉一整页节点的创建，且翻页列表
  `all_show_page` 里不会混进一个空页。
- **不删 `GridContainerZombie` 模板节点** —— 它在场景里默认 `visible = false`，留着不影响显示；
  `queue_free()` 反而会让 `@onready` 引用变成已释放对象。
- **所有僵尸预选分支都要加下标保护** —— 只加 `continue` 不够：`card_type_list_zombie[i]` 在列表为空时
  先越界崩溃（原逻辑还会在"僵尸列表比植物短"时 `break`，把植物预选也一起跳过）。

## 踩坑

1. 只改待选卡槽（第 2 步）不够：`init_pre_choosed_card()` 会去索引**空字典**
   `all_card_candidate_containers_zombie[...]` → 运行时报错 → **正解**：预选与"重选上次卡片"两处一起跳过，
   并用 `has()` 兜底。
2. `card_slot_coin.gd` 是第二条预选通道（金币卡槽），不走待选卡槽、直接 `AllCards.all_zombie_card_prefabs[...]`
   复制卡 → 漏改就会在金币卡槽关卡里照常发出僵尸卡 → **正解**：开关在同一个常量上，两条通道各判一次。
3. 隐藏僵尸预选卡后，**解谜模式「我是僵尸」关卡（`puzzle_zombie_*`）没有可用卡片** —— 这不是 bug，
   是用户选定范围的必然结果；要保留这些关卡就把开关改成「`is_zombie_mode` 的关卡例外」。

## 给后来者的最简路径

1. 在 `ConstFeatureSwitch` 加一个 `const XXX_ENABLED := false`，注释里写清全部入口。
2. UI 生成处：不生成对应节点 / 不连信号。
3. 数据通道（预选 / 存档恢复 / 随机池）逐个加开关，**并给所有字典 / 列表索引加 `has()` 或下标保护**。
4. 全文搜这个常量名以外的同义入口（如 `all_zombie_card_prefabs`、`card_zombie_type`），确认没有漏网通道。
5. 机制文档顶部写一行「当前已隐藏，改回 true 恢复」。

## 人工验证方法（未开游戏，需人跑一遍）

1. 进任意可选卡的关卡（如冒险 1-1）：选卡界面翻页**只有植物卡页**，翻不到僵尸卡页，页码也少了一页。
2. 进解谜模式「我是僵尸」任意一关：出战卡槽为空（这是本次隐藏的预期结果，不是 bug）。
3. `powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_hand -Windowed`
   → 选卡与手持流程无报错。
4. 把 `ZOMBIE_CARD_ENABLED` 改回 `true`：僵尸卡页与「我是僵尸」关卡的预选卡应恢复原样。
