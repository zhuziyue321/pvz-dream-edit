# 2026-10-06 · 其它 · 传送带出卡间隔接口 + 僵王战减半

> **任务类型**：其它
> **推荐度**：**推荐**（下次同类任务照这个走）
> **耗时与成本**：约 1 轮对话；跑一次性无头探针（60 秒出结果），未开窗口
> **验证方式**：一次性无头探针 PASS（断言真实数值），画面/手感仍需人工看一眼
> **补充自**：无

## 目标

1. 传送带（``CardSlotConveyorBelt``）**暴露一个可设置的出卡间隔**：运行期能改，改完计时器立刻按新间隔走。
2. 僵尸博士战斗（冒险 5-10 / 迷你游戏 20）中出卡间隔**减半**。

## 步骤

1. 先摸清出卡链路：`CreateNewCardTimer.timeout → _create_new_card()`，`wait_time` 只在
   `init_card_slot_conveyor_belt()` 里按 `create_new_card_cd / create_new_card_speed` 算一次（见
   [特殊关卡.md](../参考存档/特殊关卡.md#传送带关卡冒险模式)）。
2. 传送带本体加 `#region 出卡间隔`：新增 `base_create_card_interval`（基准，init 时算好）、
   `create_card_interval_scale`（当前倍率），提供
   `set_create_card_interval(秒)` / `set_create_card_interval_scale(倍率)` 两个接口。
3. `CardManager` 加转发 `set_conveyor_card_interval*` 两个接口 + 两个记录字段：
   传送带还没建好时只记值，`init_manager()` 里补一次 `_apply_conveyor_card_interval()`（关卡脚本可能在
   `run_flow()` 里很早就调用，那时实例可能还不存在）。
4. 两个僵王关的 `run_flow()` 在 `ready_set_plant()` 之后、开战之前调
   `_mg.card_manager.set_conveyor_card_interval_scale(0.5)`。
5. 写一次性无头探针进冒险 5-10，读 `create_new_card_cd` / `timer.wait_time` 断言，跑完删探针。
6. 同步 [特殊关卡.md](../参考存档/特殊关卡.md#传送带关卡冒险模式) 补一段接口说明。

## 关键决策与理由

- **接口做成「倍率 + 秒数」两个，而不是只加一个字段** —— 需求是「设置一个值调间隔」，秒数最直观；
  但 boss 战要的是「减半」这种相对值，倍率以 init 算好的基准重算，重复设同一个值不会叠加。
- **改完 wait_time 要把计时中的 Timer 重开** —— Godot 改 `wait_time` 不会替已跑起来的 Timer 重算流逝进度，
  不 stop/start 就会出现「设完要等旧间隔走完才生效」。
- **减半写在关卡脚本里，不写进本体** —— 硬约束 §1-8：本体不认识任何具体关卡 / 玩法名；
  只有 5-10 与迷你 20 用，两关各一行比上浮成关卡字段更省事。
- **顺手给 `create_new_card_speed ≤ 0` 兜底** —— 原本除法溢出会让 `Timer.wait_time` 拿到 inf；
  现在要拿它当倍率基准，必须先保证是有限正数。

## 踩坑

1. **想用 `godot --headless --script x.gd` 做纯逻辑校验，编译不过** → `--script` 模式不加载 autoload，
   传送带场景依赖的 `AllCards` 找不到标识符，场景 instantiate 出来是 null。
   → **正解**：要用完整游戏上下文就走 `test/run_autopilot.ps1 -Scenario <name>`（DebugChannel 注入），
   在那里 `Global` / `AllCards` / 主游戏都在。
2. **`run_autopilot.ps1` 的进程不会自己退出（脚本里没调 `quit()` 时）** → 挂着一直写自动存档日志。
   → **正解**：探针结尾必须调 `a.quit_game()`；发现残留 Godot 进程时按 StartTime 认领后 `Stop-Process`
   （**别杀带窗口标题的编辑器进程**）。

## 给后来者的最简路径

1. 改接口：`src/ui/card/card_slot/card_slot_conveyor/card_slot_conveyor_belt.gd` 的 `#region 出卡间隔`。
2. 关卡里调用：`_mg.card_manager.set_conveyor_card_interval_scale(0.5)`（倍率）或
   `set_conveyor_card_interval(秒)`，任意阶段调用都行，传送带建好前只记值。
3. 想数值验证：照 `test/scenarios/probe_zomboss_layout.gd` 的骨架（`(load(LEVEL_PATH) as GDScript).new()`
   → `Global.game_para = para` → `change_scene_to_file` → `main_game_start()`）写一次性探针，
   读 `mg.card_manager.card_slot_conveyor_belt.create_new_card_cd` 断言，跑
   `powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario <name> -MaxSeconds 120`。
