## 目标

迷你游戏第 6 关「隐形战争 / 隐形食脑者」：所有出战僵尸本体隐形，玩家只能通过间接线索判断僵尸位置；
被寒冰菇冰冻、被玉米投手黄油糊脸时现形。

## 步骤

1. 先啃关卡脚本 `minigame_06_invisi_ghoul.gd` 里原作者留下的三条 TODO，并从灰机 wiki「隐形食脑者」条目取到原版的
   **线索清单**（冰冻 / 黄油 / 落水水花 / 洗冰车冰道 / 玩偶匣与海豚音效 / 掉落防具 / 植物受伤动画 / 小推车）。
   —— 这一步决定了「哪些表现必须保持可见」，后面所有取舍都对着这张清单做。
2. 加关卡开关：`ResourceLevelData.is_invisible_zombie`，照 `is_mini_zombie` 的既有套路
   （`ZombieManager.create_norm_zombie` 塞进 `zombie_init_para` → `Zombie000Base.init_zombie` 读 → `ready_norm` 落地）。
3. 渲染侧：`BodyCharacter` 加 `set_invisible()`，`Character000Base` 加 `update_invisible_show()`（本体 + 影子）。
4. 现形钩子：`Character000Base.be_ice_freeze()`（冰冻）/ `_on_ice_freeze_timer_timeout()`（解冻）、
   `ZombieButterUtil.be_butter()` / `on_butter_timer_timeout()`。
5. 关卡脚本补原版内容：`is_invisible_zombie = true`、出怪表补洗冰车 / 海豚骑士 / 玩偶匣、
   传送带改成原版的 6 张牌（含冰蘑菇与玉米投手两张「现形牌」）、`is_day = false`（蘑菇不睡觉）。
6. 写探针 `test/scenarios/probe_invisi_ghoul.gd`（含 1-1 对照组），无头跑一遍。

## 关键决策与理由

- **隐形合成进 `body.modulate`，不逐个改 Sprite2D 的 `self_modulate`** —— 动画资源里每个身体部件都带
  `self_modulate` 轨道、逐帧写回 `Color(1,1,1,1)`，改它会被动画盖掉（第一版就是这么写的，跑起来必然失效）。
  `BodyCharacter` 已经有 `E_ChangeColors` 合成机制，加一个 `Invisible` 枚举项即可，还能与受击闪白 / 冰冻染色相乘互不覆盖。
- **只有「冰冻」和「黄油」现形，冰冻减速（寒冰射手 / 冰西瓜）不现形** —— 原版线索清单里只列了「寒冰菇的冰冻」和
  「玉米投手的黄油」，没列减速。
- **影子一起隐形** —— 线索清单里没有影子这一条，说明原版看不到；留着影子等于直接送答案。
- **掉落防具 / 死亡爆炸粒子 / 入水水花 / 洗冰车冰道不用特殊处理** —— 它们本来就会 `reparent` 出僵尸本体
  （`ZombieDropBase.acitvate_it()` → 僵尸行；`ZombieDeathBomb.activate_it()` → `owner.get_parent()`；
  `SwimBoxComponent.appear_splash()` → 僵尸行；`IceRoad` → 背景层），自动不受隐形影响。
  已知代价：挂在贴图下的粒子（洗冰车受损烟雾）会跟着隐形，原版线索清单没这条，可接受。
- **`is_day = false`** —— 底图仍是白天泳池，但要让冰蘑菇落地就能用；`is_day` 在仓库里只影响蘑菇睡觉，改它无其它副作用。

## 踩坑

1. **想用 `self_modulate` 保住粒子 → 动画逐帧把 alpha 写回 1** → 隐形完全失效。
   **正解**：改 `body.modulate`（`animation/character/**` 里没有任何 `:modulate` 轨道，只有 `:self_modulate`），
   代价是贴图下的粒子一起隐形，按线索清单权衡后接受。
2. 掉落的防具如果按「遍历 Body 子树收集 Sprite2D」实现，掉落后会带着 alpha=0 一起飞出去（防具不可见，违反线索清单）。
   **正解**：收集时整棵跳过 `ZombieDropBase` 子树；改成 `body.modulate` 后这个问题自动消失（reparent 出去就不受影响了）。
3. 冰冻 + 黄油叠加时，若「解冻」先到会把还处于黄油定身中的僵尸重新隐形。
   **正解**：`_on_ice_freeze_timer_timeout()` 里先看黄油计时器是否还在走，在走就交给黄油结束时再隐形。
4. 探针里 `var para: Resource` 再取 `para.is_invisible_zombie` 这类**子类才有的字段**有推断风险。
   **正解**：照 `probe_zombie_nimble.gd` 直接用 `var para = (load(path) as GDScript).new()`（不标类型）。
5. 无头 `--import` 报 `beghouled_manager.gd:530/531` 的两个 `Cannot infer the type`（`row2` / `col2`）以及
   `plant_cell_manager` 的同类报错是**既有问题**（Godot 4.6.2 比项目标称的 4.5.1 更严），与本次改动无关，
   会连带打出一片 `Failed to compile depended scripts`，不要误判成自己改坏了。

## 给后来者的最简路径

1. 关卡脚本写 `is_invisible_zombie = true`。
2. `ZombieManager.create_norm_zombie` 里加一行 `zombie_init_para[E_ZInitAttr.IsInvisible] = game_para.is_invisible_zombie`。
3. `Zombie000Base.ready_norm()` 里 `if is_invisible: update_invisible_show(true)`（展示 / 图鉴僵尸走 `ready_show`，自动不受影响）。
4. 需要「临时现形」的场合调 `Character000Base.update_invisible_show(false)`，结束时调回 `true`；
   非隐形关卡调用直接返回，不会误改颜色。
5. 写探针时同时跑一个普通关卡做对照组，确认没把默认关卡改坏。

## 人工验证方法（画面部分，探针覆盖不到）

1. 主菜单 → 迷你游戏 → 第 7 个按钮「隐形战争」→ 进关。
2. 预览僵尸阶段：僵尸**应该看得见**（展示僵尸不隐形）。
3. 开战后：僵尸**应该完全看不见**（连影子都没有），但以下现象仍在 ——
   水池行僵尸入水有水花；植物被啃时有受伤动画；僵尸被打掉防具时路障 / 铁桶会掉在地上；
   洗冰车开过留下冰道；小推车被触发时会走。
4. 种下冰蘑菇（传送带给的）→ 全场僵尸**显形 + 冻住**，解冻后重新看不见。
5. 玉米投手打出黄油 → 被糊中的那一只**显形**，黄油掉落后重新看不见。
