# 2026-10-06 · 关卡与地图 · 底图 / BGM / 昼夜开关下沉为「场景设置」

> **任务类型**：关卡与地图
> **推荐度**：**推荐**（下次给关卡换场景、加场景照这个走）
> **耗时与成本**：约 2 轮对话，未开窗口（跑了一次性无头探针，逐关数值比对等价）
> **验证方式**：一次性无头探针（加载 6 个关卡比对字段）+ 建议人工进 4-1 / 4-10 / 1-5 看一眼
> **补充自**：无

## 目标

同一类关卡（浓雾 4-1~4-10、生存浓雾 ×3、种子雨）把同一串「底图 / BGM / 雾 / 昼夜 / 天降阳光」抄 13 遍 ——
改成**关卡只写场景名，具体信息问场景脚本要**，且关卡脚本要能就地覆盖（例：1-5 用前院场景但播小游戏曲）。

## 步骤

1. 新建 `src/world/scene/`：`scene_setting_base.gd`（`SceneSettingBase`）+ `scene_setting_registry.gd`（`SceneSettingRegistry`）+ 6 份场景脚本（front_day / front_night / pool / fog / roof / boss，对应 `ConstLevelData.GameBg` 的 6 个值）。
2. `ResourceLevelData` 加 `scene_name: StringName`，**setter 里调 `apply_scene_setting()`**；`apply_scene_setting()` 可覆写。
3. 批量替换 13 个雾关（冒险 4-1~4-4 / 4-6~4-10、生存 04/09/14、迷你 04 种子雨）+ 冒险 1-5（覆盖示例）。
4. 文档同步：新建 `docs/参考存档/场景设置.md` + 参考存档索引补行 + 改 `关卡数据与出怪表.md` 第四大关段。

## 关键决策与理由

- **用 setter「赋值即套用」，而不是在 `init_para()` 里统一套** —— `init_para()` 跑在 `_init()` **之后**，会把关卡在 `_init()` 里写的覆盖值冲掉；setter 让「写在 `scene_name` 后面的同名字段即覆盖」天然成立，1-5 覆盖 BGM 只要一行。
- **`scene_name` 留空 = 不套用** —— 老关卡 / 自制关零改动，迁移可逐关进行。原因：BGM 经常偏离场景（MiniGame / Puzzle / UltimateBattle / NoBGM，全仓有 20+ 关），一次性全量自动套用风险太高。
- **雨 / 闪电不进场景** —— 那是关卡级天气（原版只有 4-10 是雷雨、种子雨只下雨不打雷），进场景反而会盖掉关卡的 `is_rain = true`。
- **6 份场景脚本不带 `class_name`**，注册表按 `res://` 路径 `load` —— 少占全局类名，也避免与关卡数据构成循环依赖（基类与注册表带 `class_name`，被关卡数据按类名引用）。

## 踩坑

1. **新建带 `class_name` 的脚本，无头探针报 `Identifier "SceneSettingRegistry" not declared`** → 原因：`.godot/global_script_class_cache.cfg` 还是旧的，跑游戏不会刷它 → **正解**：`godot --headless --path . --import` 刷一次全局类表再跑探针（顺带发现仓库里别的 agent 新建的 `LevelTimelineEventAllowOperation` / `SpawnSun` / `StartFirstWave` 也卡在同一处）。
2. **本机探针还撞到既有编译错误** `tutorial_manager.gd:309`（`ResourceTutorialStep.E_PointerTarget` 传给了要 `PointerTargetResolver.E_PointerTarget` 的 `resolve()`）→ 不是本次改动，**未处理**，但它会让整局跑不起来，谁碰到谁修。
3. **`probe_levels` 加载 109 关会撞看门狗超时**（240 秒没跑完）→ 想核对就自己写一个只加载目标几关的一次性探针，跑完删掉。

## 给后来者的最简路径

1. `src/world/scene/` 加一份场景脚本 + 在 `SceneSettingRegistry` 登记名字与路径；
2. 关卡 `_init()` 第一行写 `scene_name = SceneSettingRegistry.SCENE_XXX`，要改的项写在它后面；
3. `godot --headless --path . --import` 刷类表 → 跑一次性探针比对字段 → 人工进关看一眼。
