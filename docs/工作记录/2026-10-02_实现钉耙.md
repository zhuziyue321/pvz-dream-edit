## 目标

实现原版一代的**钉耙（Garden Rake）**：戴夫商店 $200 买一次管 3 关，每关开局自动放在草坪上，踩到它的僵尸吃 1800 点伤害（除巨人类 / 高坚果僵尸外当场击杀），一关只放一把。

## 步骤

   `plantsvszombies.fandom.com` 与 `wiki.pvz1.com` 都超时 → **改用** `plantsvszombies.wiki.gg/wiki/Garden_Rake?action=raw`
   （`Rake` 是重定向页，真名 **Garden Rake**）。取到：$200 / lasts for three levels / 1800 damage /
   放在「从右数第 2 列」/ 没踩到也算用掉。

   - `GlobalGameState` 加 `rake_use_num` + `DEFAULT_RAKE_USE_NUM` + `is_rake_owned()/get_rake_use_num()/buy_rake()/consume_rake_use()`。
   - `SaveService` 存 / 读 `rake_use_num`（旧档兼容 `data.get(键, DEFAULT)`）。

## 关键决策与理由

- **放哪一行用地图数据 `have_rake`，而不是解析「第一只僵尸出现的行」** —— 原版是后者，本仓库没有拖拽换行的交互，
  `have_rake` 字段早已存在（`map_row_data` / `zombies_row`）只是没人消费；一行都没标时兜底中间陆地行，保证买了就能看到效果。
- **消耗放在通关结算而不是开局** —— `init_manager()` 每关只跑一次，但多轮续玩 / 读档重进会重复进入关卡；
  放在 `update_level_state_data_success()` 是唯一确定只发生一次的点（中途退出不消耗，与原版略有差异，已在代码注释写明）。
- **钉耙节点挂在 `ZombiesRoot` 之后** —— 触发时把手要弹起来砸僵尸，画在僵尸下面会被身体挡住。
- **音效复用 `bonk`**（`SoundManager` 已注册，锤子也在用），没有新增音频资源。
- **伤害 1800 走穿透攻击类型**，与 `be_squash` 同源，巨人类自然不会被秒杀（原版行为）。

## 踩坑

1. **fandom / pvz1 wiki 抓取超时（10s）** → 换 `plantsvszombies.wiki.gg` 的 `?action=raw` 才拿到正文；
   且 `Rake` 页是 `#redirect [[Garden Rake]]`，**先抓重定向目标再取正文**，不要用记忆补数值。
2. **在 `.tscn` 里写了 `##` 中文注释行** → 引擎解析不出 `Rakes` 节点，报
   `Node not found: "%Rakes"` → **正解**：tscn 不支持 `##` 注释（只有脚本注释写在 `.gd` 里）。
3. **新建 `.gd` 没有 `.uid`** → 全局类没进 `global_script_class_cache.cfg`，报
   `Could not find type "Rake"` / `"GIM_Rake"` → **正解**：跑一次
   `godot --headless --path <项目> --import`，引擎会为所有新脚本补 `.uid` 并重建类缓存。
4. **`_refresh_goods_state()` 只把 `is_have_goods` 设 false** → 状态回退（钉耙用完）后商品不会恢复出售
   → **正解**：双向赋值 `is_have_goods = not is_rake_owned()`。
5. **`run_autopilot.ps1` 报「输出文件被占用」** → 有另一个 Godot 进程在跑 → **正解**：不要杀他人进程，
   直接调 Godot 并自己重定向 `$env:APPDATA` 到临时目录（等价于脚本里的 userdir 重定向）。

## 给后来者的最简路径

1. wiki 取数值 → `ConstShop`（价格 / 伤害 / 次数，注释写来源 URL 与口径）。
2. `GlobalGameState` 加字段 + getter/setter/consume，`SaveService` 加键（旧档 `data.get(键, DEFAULT)`）。
3. 道具本体：`src/items/<道具>/<道具>.gd` + `src/items/game_scenes_item/<道具>/<道具>.tscn`。
4. 管理器：`src/managers/game_item_manager/gim_<道具>.gd` + 主场景加挂载节点（`unique_name_in_owner = true`）
   + `GameItemManager.init_manager()` 里调用。
5. 商店：`src/store/goods_<道具>.gd` + `src/store/goods_<道具>.tscn`（instance `goods.tscn` + `StoreIcon`）
   + `dialog_detail/store/<道具>.tres` + `store.tscn` 补实例与 `all_goods` NodePath。
6. 探针：`test/scenarios/probe_<道具>.gd`，无头跑一遍看 `[XXX] result=PASS`。
7. **收尾必做**：`godot --headless --path <项目> --import`（新脚本要注册进全局类缓存才能在 tscn / 管理器里被引用）。

## 人工验证方法

1. 冒险模式打到 3-4 解锁商店，进商店第一页：卡槽扩充之后出现**钉耙**，标价 $200，悬停有戴夫对话。
2. 金币 >= 200 时点击 → 确认弹窗 → 扣钱、商品变「已拥有」且按钮禁用（三关用完后会自动恢复出售）。
3. 存档文件 `user://<用户>/GlobalSaveGame.json` 里 `rake_use_num` 变成 3。
4. 进任意冒险关卡（有自然刷怪的关）：草坪**从右数第 2 列**、中间那行出现一把钉耙（贴地，把手横躺在左下）。
5. 第一只僵尸走上去 → 把手弹起砸中它（bonk 音效）→ 僵尸掉头死亡 → 钉耙淡出消失；本关不再出现第二把。
6. 通关后 `rake_use_num` 减 1（打三关后归零，商店恢复出售）。
