## 目标

1. **给模组一套好用的接口来实现植物**：新增一株植物要做的四件事（登记注册表 / 插卡 / 画卡面 / 解锁）
   不该每个模组抄一遍 —— 它们的坑是同一套、而且是静默的（不重排编号 / 取不到帧 / 撤销顺序错了都不报错）。
2. **用新接口重写水盆模组**，行为一处不变（探针全绿），模组代码显著变短。

## 关键决策与理由

- **分成「配方」+「装 / 卸助手」两层，而不是往 `CharacterRegistry` 上堆方法** —— 僵尸侧已有
  `ZombieRuntimeRecipe` 的先例，对称好认；更关键的是装一株植物不止「登记」，还有卡片 / 卡面 / 解锁三件事，
  **要有人持有那张卡的引用**（卸载时摘掉），所以是一个 Kit **实例**而不是一组静态函数。
- **卡面取帧逻辑进本体** —— 每个新增植物都要，而坑（`_ready()` 里挂不进临时容器、取回来带着血条 UI、
  `duplicate()` 会把剥掉的东西复活）已经在 `AnimationFrameUtil` 里沉淀过一次，不该再沉淀第二遍。
- **插卡位置改成最后一个容器**（1.0 插在 `PlantCards` 末尾）—— 编号是按 `[PlantCards, PlantCards2]` 顺序重排的，
  插在中间会把它后面每张卡的编号都挪一格（`PlantCards2` 里还挂着保龄球坚果那批）。
- **`add_runtime_plant_condition_bit()` 用「复制 + 按位或」而不是整份换** —— 整份换要自己把原条件抄一遍，
  抄漏一位就静默丢一种地形；条件资源还是共享对象，就地改会连累别人，所以换的是副本。
- **保留 `PlantIds.WATER_BOWL`** —— 探针与老存档都在用这个 id；但**新模组不必再让本体加常量**
  （字符串 id 时代没有号段，id 留空就自动分配），这条写进了配方与文档的注释。
- **本体零「水盆」字样** —— 新接口全是通用名（`PlantRuntimeRecipe` / `PlantRuntimeKit` / `PlantConditionBits`
  里那个 `WATER_BOWL` 位只是地形位的名字，与模组同名纯属巧合），符合硬约束 §1-1 / 模组边界规则。

## 踩坑

1. `test/run_autopilot.ps1` 的默认 Godot 路径**已失效**（文件早改名成 `godot.exe`）→
   跑出来是「stderr 2 行 + 探针根本没跑」的假象。**必须显式传 `-Godot "C:\Users\a a\Desktop\godot.exe"`**
   （旧记录 2026-10-13 已经记过一次，本次复现 —— `check_scripts.ps1` 修好了，这个还没修）。
2. **卡面取帧不能装在 `install()` 里**：`ModManager` 的 `install()` 是在它自己 `_ready()` 里调的，
   那一刻 root 正忙着布置子节点，取帧要挂的临时容器会被 `add_child()` 拒掉（帧取不到、只在日志里留一行 C++ 报错）。
   ⇒ Kit 里推到帧末（`call_deferred`），并在帧末**再认一次「这张卡还是我的吗」**（这中间可能已被 `uninstall()`）。
3. **循环依赖观察项**：`CharacterRegistry` 的参数类型写了 `PlantRuntimeRecipe`，而 `PlantRuntimeRecipe`
   又引用 `CharacterRegistry.PlacePlantInCell` 枚举 —— 本次门禁 PASS（Godot 4 容忍这种软环），
   但这两个文件以后互改时要留个心眼（真报错就把参数类型标注去掉，内部 duck typing 照样能用）。
4. 卸载顺序**不能反**：先摘卡（`AllCards.rebuild()` 还要按类型查冷却与阳光）→ 再清注册表 → 再撤解锁。

## 给后来者的最简路径

1. 写植物场景 + 脚本（与内置植物完全一样，根节点继承 `Plant000Base` / `Plant000DownBase`）。
2. 模组里 `var recipe := PlantRuntimeRecipe.new()`，填 `plant_scene` / `cool_time` / `sun_cost` /
   `condition_bits` / `place_in_cell` / `card_face_anim`（+ `card_face_fallback_plant` 兜底）。
3. `var kit := PlantRuntimeKit.new()`；`install()` 里 `kit.install(recipe)`，`install_to_main_game()`
   里补一次 `kit.unlock()`，`uninstall()` 里 `kit.uninstall()`。
4. 底部植物（花盆 / 水盆那一层）再在场景里写 `own_condition_bit`；要让已有植物认这个新位就调
   `add_runtime_plant_condition_bit()`。
5. 跑 `probe_water_bowl`（全链路探针）照抄一份自己的；门禁 `test/check_scripts.ps1` 必跑。
