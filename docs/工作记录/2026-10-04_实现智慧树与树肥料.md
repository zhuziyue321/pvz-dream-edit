## 目标

1. 智慧树（Tree of Wisdom）能在花园里看到：买下后是一张新的背景页，喂树肥料会换外观并讲一句智慧。
2. 树肥料（Tree Food）在商店**第四页第二行第一格**出售，$2500 一袋、最多囤 10 袋。

## 步骤

1. **先定口径再动手**：查 wiki 拿到「$2500 一袋 / 一次最多 10 袋 / 买树白送 5 袋 / 一袋长一英尺 /
   100-500-1000 英尺是里程碑」，台词原文从 `data/strings/lawn_strings.txt` 的 `TREE_OF_WISDOM_*` 取。
2. **数据表**：新建 `src/core/consts/const_tree_of_wisdom.gd`（照 `const_adventure_reward.gd` 的写法：
   `extends RefCounted` + `class_name` + 大常量表 + 来源注释）。
3. **商店侧**：`ConstShop` 里给树肥料加价目与「每份几个 / 上限」两个例外分支；
   `goods_garden_tool.gd` 加图标与戴夫话术；`store.tscn` 加 `RowTreeFood`（照既有行的 `offset_*`），
   `store_manager.gd` 把它挂进 `pages[3]`，`goods_garden_tree.gd` 的购买改成调 `buy_tree_of_wisdom()`。
4. **花园侧**：`E_GardenBgType.TreeBg` 解注释 → `BgPageScenes` / `PLANT_CELL_NUM_PER_PAGE` 补这一页（0 格）→
   新建 `bg_03_tree_of_wisdom.tscn/.gd`，道具 `tree_food.tscn` 补 `Body` 并挂脚本。
5. **~弯路~**：一开始想把树干每层都做成场景里的一个个 Sprite2D → **放弃原因**：10 档贴图 × 2 层 = 20 个节点段，
   `.tscn` 会臃肿；改成一张 `Trunk` 精灵在 `refresh_visual()` 里换贴图 / 位置 / 缩放，数据全在常量表里。

## 关键决策与理由

- **智慧树做成"花园的第四页"（背景页），不是摆在某个花园角落** —— 因为 wiki 明确写了
  「clicking on Zen Garden and going past the Aquarium Garden」，而且仓库里 `E_GardenBgType.TreeBg`
  早就被注释着留好了位置，走现有背景页机制（翻页环 / 页码 `N/M` / 拥有判定）几乎零新机制。
- **这一页 `PLANT_CELL_NUM_PER_PAGE` 写 0** —— 它不种植物，`init_curr_gb_page()` 走不到任何格子，
  「花园是否已满」也自动不受这一页影响。
- **树肥料照巧克力的套路走（依赖品 -> 买了解锁物才给工具栏按钮）** —— 没买智慧树就没有可喂的东西，
  按钮和道具一起藏起来，和「没买蜗牛就没有巧克力」完全一致。
- **画面用 reanim 原始坐标 + ffmpeg 先合成预览图验证** —— 从 `assets/all_reanim/treeofWisdom.reanim`
  里取出每个部件首次出现的那一帧的 `x / y / scale`，再用 ffmpeg 把 `tree_bg + tree_grass + trunk + overlay`
  叠成 png 看一眼；这一步在写 `.tscn` 之前做，避免在编辑器里反复挪。

## 踩坑

1. **tree6~9 / tree_grass 是 JPG + `_` 掩膜配对，直接拿来用是一坨黑** → 这些 ID 还没走过 alpha 烘焙 →
   **正解**：跑项目自带的 `tools/merge_alpha.ps1 -Name assets/reanim/tree8`（逐个贴图名跑）。
2. **`tree_grass` 那对的掩膜是反的**（其他几对都是白=不透明，只有它是黑=土堆）→ 烘出来是一块黑条 →
   **正解**：这一张加 `-Invert`；判据是先看一眼 `tree_grass.jpg`（彩色像素是土堆，背景是黑），
   再决定要不要反。
3. **有 `_` 掩膜的贴图不能直接用 / 也不能自己随手写 `-Invert`** → 每对先看彩色图：`背景黑=要 Invert`，
   `背景非黑=不要 Invert`。
4. **`.tscn` 里 `ItemBase` 认的是 `$Body`**，而 `tree_food.tscn` 原本把 `Bag / Seed` 直接挂在根节点 →
   `body` 拿到 null、`use_it` 里 `clone.body.visible` 直接炸 → **正解**：照 `fertilizer.tscn`，
   把贴图挪进 `Body` 子节点（并给 `Body` 一个像 `(-40,-46)` 的偏移让袋子跟手），
   同时把动画里所有 `NodePath("Bag:` / `NodePath("Seed:` 改成 `NodePath("Body/Bag:` / `NodePath("Body/Seed:`
   —— AnimationPlayer 的轨道路径是相对它的**父节点**解析的，这么改完照样能播。
5. **工具栏原本正好按 8 个 75px 摆满**（`PanelUI` 宽 594 = 8×75−7），加第 9 个会压到右上角翻页按钮上 →
   **正解**：把 8 个按钮的 `custom_minimum_size` 一起改成 66（9×66−8 = 586 < 594）；
   不要碰 `Next` 的位置，它右边的页码 Label 是相对它摆的，挪过去会跑出屏幕。
6. **`merge_alpha.ps1` 遇到同名输出会跳过**，改想法重烘同一张贴图时要加 `-Overwrite`。

## 验证方式

无头校验（未开游戏）：临时脚本逐个 `load()` 9 个脚本 + 4 个场景，全部 OK；
`bg_03_tree_of_wisdom.tscn` 实例化后 `Tree/Trunk` 与 `TreeOfWisdomClouds/AnimLib` 都能 `get_node` 到。
**画面与手感没能自动验证**，人工验证方法：

1. 商店 → 第四页：第一行 蘑菇园 / 水族馆 / 蜗牛 / 智慧树，第二行第一格是树肥料（$2500）。
2. 买下智慧树 → 戴夫应该顺势白送 5 袋树肥料（回花园后工具栏第 9 个按钮出现在最右边）。
3. 花园里点「下一个花园」翻到最后一页 → 应该是智慧树（天上有云在飘，树是幼苗，写着「0英尺高」，
   它在讨肥料）。
4. 点第 9 个按钮拎起一袋肥料，往树根上点一下 → 播倒肥料的动画 → 播完树换一档贴图，高度 +1 英尺，
   底下讲一句新的智慧；连喂几袋能看到树明显长大。
5. 回到主菜单再进花园 / 重开游戏 → 高度与台词都还在（存 `garden_data["tree_of_wisdom_height"]`）。
6. 肥料囤到 10 袋时商店这一格应该变「持有已满」的戴夫提示并禁售。
