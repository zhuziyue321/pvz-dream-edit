# 2026-10-04 · 其它 · 隐藏关卡内手套功能（单点开关 GLOVE_ENABLED=false）

> **任务类型**：其它
> **推荐度**：**推荐**（下次要临时下线任何玩法，照这个走）
> **耗时与成本**：约 1 轮对话，未开游戏（免验证 + 已给人工验证方法）
> **验证方式**：免验证（改动是常量短路 + 分支，无递归 / 无 autoload 初始化顺序影响）+ 已给出人工验证方法
> **补充自**：无

## 目标

把关卡内的手套（搬植物那个）**整体隐藏**：卡槽手套按钮、G 快捷键、搬运交互、通关 4-5 解锁判定、
4-6 戴夫赠礼对话全部不可见不可用；**代码与场景节点保留**，改一个常量即可完整恢复。

## 步骤

1. `src/core/consts/const_unlock_level.gd` 加功能开关区：`const GLOVE_ENABLED := false`，
   并让 `is_glove_unlocked()` 在开关关闭时直接 `return false`（单点短路，下游全跟着关）。
2. `hand_component_glove.gd`：`is_can_has_glove()` 开头再判一次开关；`_ready_component()` 里
   开关关闭时不订阅 `main_game_click_glove`；`_on_click_glove()` / `refresh_ui()` 也各自兜一层。
3. `card_slot_root.gd`：G 快捷键加 `ConstUnlockLevel.GLOVE_ENABLED and ui_glove.visible`。
4. `adventure_04_06.gd`：赠礼对话整段包进 `if ConstUnlockLevel.GLOVE_ENABLED:`，
   `has_dave_dialog()` 返回该常量（避免"有对话"却没播，戴夫推销让位逻辑跟着走对）。
5. 两个探针同步跳过：`probe_hand` 第 7 节手套改为条件跳过，`probe_glove_unlock` 开头跳过整支探针
   （否则 CI 回归必挂 —— 这是最容易被漏掉的一步）。
6. 文档：`docs/参考存档/手持物实现.md` 第五节顶部加「当前功能已隐藏」提示 + 本记录链接。

## 关键决策与理由

- **开关放在 `ConstUnlockLevel` 而不是新建文件** —— 因为解锁判定 `is_glove_unlocked()` 就在这里，
  下游（`GlobalGameState` → 组件）自动全关，改动面最小；规范 §5 也要求"同一件事只在一处写"。
- **不删节点 / 不删脚本**（用户选择"单点开关，默认关闭"）—— `HM_Glove` / `UIGlove` / `RealGlove`、
  `hand_glove.tscn`、`plant_cell.gd` 的手套搬运 API 全部保留，改回 `true` 即恢复，无需 git 回滚。
- **组件里多兜三层**（不订阅 / 点击返回 / UI 强制隐藏）—— 只靠 `is_can_has_glove()` 一层的话，
  将来谁误调 `change_is_enabling(true)` 就会把已下线的功能放出来。

## 踩坑

1. 只改 `is_glove_unlocked()` 会让探针 FAIL（`probe_hand` 第 7 节、`probe_glove_unlock` 整支）→
   原因是探针自己模拟通关 4-5 再重算组件启用状态 → **正解**：探针也要读同一个开关并跳过，
   不要去改探针的解锁模拟逻辑。
2. 4-6 的 `has_dave_dialog()` 若保持 `return true` 而 `run_flow()` 不播对话 →
   `DaveSellManager.is_can_sell()` 会以为本关有戴夫对话而让位 → **正解**：两者读同一个常量。

## 给后来者的最简路径

1. 在 `ConstUnlockLevel` 加 `const <功能>_ENABLED := false`，让该功能的解锁 / 可用性判定函数开头短路。
2. 该功能的组件：就绪时不订阅事件 + 点击入口早退 + `refresh_ui()` 强制隐藏。
3. 关卡脚本里由开关决定是否播相关戴夫对话，`has_dave_dialog()` 返回同一常量。
4. **全局搜一遍测试探针**，让相关探针读同一开关跳过。
5. 在对应机制文档顶部写一行「当前已隐藏，改回 true 恢复」。

## 人工验证方法（未开游戏，需人跑一遍）

1. 进任意关卡（含通关过 4-5 的存档）：卡槽右侧**不出现**手套底板，按 **G** 无任何反应。
2. 进冒险 4-6：开场**不再有**戴夫举手套的 8 句赠礼对话，直接进「展示僵尸」。
3. `powershell -ExecutionPolicy Bypass -File test/run_autopilot.ps1 -Scenario probe_hand -Windowed`
   → 应见 `--- 7. 手套组件（GLOVE_ENABLED=false，已隐藏，跳过）---` 且末行 `[HAND] result=PASS failed=0`。
4. 把 `GLOVE_ENABLED` 改回 `true` 再跑 `probe_glove_unlock` → 应恢复全部手套检查并 PASS。
