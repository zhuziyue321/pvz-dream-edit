# 2026-10-04 · 其它 · 新增「取动画某一帧当图片」工具，并用到商店的水路 / 屋顶小推车与蜗牛图标

> **任务类型**：其它
> **推荐度**：**推荐**（下次要在 UI 里摆静态形象，直接照这条走）
> **耗时与成本**：约 3 轮对话，带窗口跑探针 `probe_animation_frame`（无头也跑过一次，用来排脚本编译）
> **验证方式**：打开游戏实测（带窗口探针全 PASS）
> **补充自**：无

## 目标

1. 加一个**容易调用**的方法：给「场景 + 动画名 + 帧号」，拿到那一帧的**图片**（或静态形象节点）。
2. 先落到商店：水路小推车、屋顶小推车、蜗牛三件商品的图标换成完整形象的那一帧
   （原来分别是 `PoolCleaner_body1` / `RoofCleaner_body1` / `Stinky_shell` 单张部件图 —— 蜗牛只有一个壳）。

## 步骤

1. 先摸清动画形态：`animation/**` 是 Godot 原生 `Animation` 资源（value 轨道打在 `Body/xxx:position|rotation|visible|scale` 上），
   场景里靠 `AnimationPlayer`（+ 部分角色有 `AnimationTree`）播放 → 取帧只能落在「实例化 + 定格 + 离屏渲染」这条路上。
2. 新增 `src/core/utils/animation_frame_util.gd`（`class_name AnimationFrameUtil`）：
   - `create_frame_texture(scene, anim_name, frame, size, margin)` → `Texture2D`（异步，内部离屏渲染）
   - `create_frame_node(scene, anim_name, frame)` → 定格好的静态节点（同步）
   - 零件：`frame_to_time` / `seek_frame` / `find_animation_player` / `get_content_rect` / `apply_fit`
3. 新增 `src/ui/animation_frame_icon.gd`（`AnimationFrameIcon extends TextureRect`）：摆节点 + 填三个导出量即可，零代码。
4. 商店落地：
   - 两个小推车商品 `goods_pool_cleaner.tscn` / `goods_roof_cleaner.tscn` 的 `StoreIcon` 挂 `AnimationFrameIcon`；
   - 蜗牛走通用 `GoodsGardenTool`，加 `FRAME_ICON_SCENE` / `FRAME_ICON_ANIM` 两张表 + `_render_frame_icon()`。
5. 写探针 `test/scenarios/probe_animation_frame.gd`，带窗口跑：`[ANIMFRAME] result=PASS failed=0`。

## 关键决策与理由

- **定格用 `play + seek(t, true) + stop(true)`**（与 `coin.gd` / `zombie_boss.gd` 同一套写法）—— `stop(true)` 保留姿态，
  写成 `stop()` 会退回第 0 帧。
- **实例化后先递归 `set_script(null)`** —— 角色 `_process` 会自己往前开（小推车）、`_ready` 会取视口尺寸；
  不剥离就会在离屏容器里跑起来，`_ready` 里还依赖 `body` / `animation_player` 之类，容易炸。
- **seek 前先摘 `AnimationTree`** —— 它每帧覆盖 `AnimationPlayer` 的姿态，不摘掉定格会被冲掉。
- **等渲染用 `SceneTree.process_frame` 而不是 `RenderingServer.frame_post_draw`** —— 后者在无头下永不触发（见踩坑 1）。
- **保留原来的单张贴图当兜底**：渲染要等两帧，且失败时返回 `null`；`texture` 上先配原图，渲染成功再覆盖，
  所以最坏情况只是「图标没变」，不会变成空白。
- 工具类放 `src/core/utils/`（与 `image_combiner.gd` 同层），控件放 `src/ui/`（与 `pvz_button_base.gd` 同层）—— 按 `src/AGENTS.md` 的目录约定。

## 踩坑

1. **无头跑探针直接卡死 120 秒被看门狗杀掉** → 原因：`await RenderingServer.frame_post_draw` 在 `--headless`
   （dummy 渲染服务器）下永远不触发 → **正解**：改等 `SceneTree.process_frame` 两帧；带窗口渲染才出得来图。
2. **无头下 `SubViewport.get_texture()` 返回 `null`**，随后 `.get_image()` 报 `Parameter "t" is null` →
   无头没有真渲染 → **正解**：先判空再取图（避免打脏日志），且**这类改动必须带窗口验证**，无头只能用来验脚本编译与节点定格。
3. **GDScript 里跨行的 lambda 解析失败**：`strip_nodes(inst, func(n: Node) -> bool: return A\n or B)` 报
   `Expected closing ")" after call arguments` → **正解**：改成具名 `static func`（`_is_pose_blocker` / `_is_not_drawable`）传 Callable。
4. **探针里 `var store := a.get_tree().current_scene` 报 `Cannot infer the type`** → `current_scene` 无静态类型
   → **正解**：显式写 `var store: Node = ...`。
5. **单文件 `--check-only` 会假报 `Identifier not found: Log` / `AnimationFrameUtil not declared`** →
   那个模式不注册 autoload 与 `class_name` → **正解**：别拿它当编译结论，直接跑真实场景脚本。

## 给后来者的最简路径

1. 要图片：`var tex := await AnimationFrameUtil.create_frame_texture(preload("res://...tscn"), &"动画名", 0, Vector2(67, 68), 2.0)`。
2. 要节点：`AnimationFrameUtil.create_frame_node(scene, &"动画名", 0)`，用完记得自己挂进树或 `free()`。
3. 场景里零代码：摆 `TextureRect` → 挂 `res://src/ui/animation_frame_icon.gd` → 填 `scene` / `anim_name` / `frame`。
4. 动画名是 `AnimationLibrary` 的**键**（`&"Stinky_idle"`），不是文件名；带窗口跑一次看效果。
