# 2026-10-18_dlc模组接投掷蘑菇

> **本次任务**：照 [dlc模组接国王仙人掌](2026-10-18_dlc模组接国王仙人掌.md) 那条流程，把 DLC 模组里第二株动画接成能种的植物 —— **投掷蘑菇**（PultShroom，0 阳光 / 本行 6 格抛射孢子 / 白天睡觉），含配方、卡面、图鉴、探针。
> **耗时 / 轮次**：3 轮（写代码 → 探针 1 条红：抛物线高度没生效 → 改摆放口径后重跑）；**开了游戏**：无头探针，未开窗口
> **推荐度**：推荐（探针 45 条断言全绿；两处坑都是「场景里写了但引擎不读」的类型，探针一跑就现形）

## 目标
1. 复用 `mods_builtin/dlc/` 里已导入的 `PultShroom` 动画（`idle` / `shooting` / `blink` / `face` / `sleep` 五段），做成**抛射投手**。
2. 数值照 DLC Edition 的 wiki（Pult-shroom 页），不自己编；本体零改动。

## 最简路径（步骤）
1. **取数据**：`https://pvz-dlc-edition.fandom.com/wiki/Plants?action=raw` 能拿到总表（Pult-shroom 只填了阳光 0），单页要用 API：`https://pvz-dlc-edition.fandom.com/api.php?action=parse&page=Pult-shroom&prop=wikitext&format=json`。得到：**0 阳光 / 冷却 7.5 秒（fast）/ 20 伤害 / 攻击间隔 2.85 秒（1/2x）/ 抛射·中等（1×6）/ 生命 300 / 白天睡觉**。
2. **选题**：`animation/character/plant/PultShroom/` 五段齐全，`shooting` 1.583 秒；`PultShroomC1_*` 是换色变体，**只挑一套**（用无后缀那套）。
3. **量包围盒**：解析 `PultShroom_idle.tres` 的 `position` / `scale` / `texture` 轨道（`Sprite2D` 全是 `centered = false`，`position` 是左上角），按 `Png 尺寸 × scale` 合并 → `x[2.7,58.6] y[22.4,62.4]`（56×40 px，部件缩放 0.6）。
   ⚠️ **`PultShroom_eyes` 的贴图是动画 `texture` 轨道在运行期塞的**，场景里该 Sprite 没有 texture —— 只按场景 / 只按 PNG 清单量会漏掉底下 9.5 px。
4. **对齐口径**：拿本体小喷菇当基准（同为蘑菇）—— 它的 `BodyCorrect` 是 `(-41,-63)`、运行期内容底边在 Body 坐标 **+0.34**。所以动画节点 `position = (-30.7, -62.1)`，探针断言「与小喷菇底边差 ≤ 4 px」。
5. **场景** `pultshroom/plant_pultshroom.tscn`：继承 `plant_base.tscn` + `PultShroom.tscn`（**不设 scale**）+ `Marker2D`（篮子口 `(-4, -31.4)`）+ `DetectComponent`（`size = Vector2(456, 60)`，`Area2D` 在 `(0,-25)`、形状中心 `(228,0)` = 本行右边 6 格）+ `AttackCdTimer`(2.85) + `ShootTimer`(0.5, one_shot) + `AnimComponent` 换 `component_anim_empty.gd`；`SleepComponent.is_sleep_in_day = true`，并把 `DetectComponent` 放进 `sleep_influence_components`。
6. **覆盖 `AnimLib` 的五段库**（同国王仙人掌：转换工具只留一条 `ALL_ANIMS`，不分段）。动画场景里 `AnimLib` 是第 12 个子节点 → `index="11"`。
7. **脚本** `pultshroom/pultshroom_plant.gd`：`extends Plant000Base`，`DetectComponent` 两信号 + 冷却计时器驱动 `AnimationPlayer`；`ShootTimer` 到点时**重新** `update_first_enemy()` 取目标（不能发射前记住引用），再 `init_bullet({Enemy, EnemyGloPos, …})` 抛孢子；睡眠信号换 `PultShroom_sleep`。
8. **子弹** `pultshroom/bullet_pultshroom_spore.tscn`：继承 `bullet_parabola_base.tscn`，贴图用 `reanim/PultShroom/PultShroom_spore-1.png`（0.6 缩放 ≈ 17 px），`attack_value = 20`、`speed = 320`；抛物线高度**写在 `MovementComponent` 节点上**。
9. **配方 / 图鉴**：`dlc_mod.gd` 加 `PULT_SHROOM` 常量、`_build_pultshroom_recipe()`（`sun_cost = 0`、普通卡、`card_face_anim = &"PultShroom_idle"`、`card_face_scale/position` 按「包围盒中心落在卡面挂点 (24,30)」算 `(0.5,0.5)` / `(-15.3,-21.2)`）、`_register_pultshroom_almanac_entry()`；`install()` 的配方数组加一项，`uninstall()` 多摘一条图鉴。
10. **探针** `test/scenarios/probe_dlc_pultshroom.gd`：注册 / 卡位 / 图鉴 / 五段动画 / 摆放（与小喷菇对齐）/ 投手零件与数值 / 孢子场景 / 开火收尾 / 睡眠换姿势 / 卸载，共 45 条。
11. **跑批**：`test/run_autopilot.ps1 -Scenario probe_dlc_pultshroom`；用户开着 Godot 时它会直接 `STALE_PROCESS` 退出（**别 `-KillStale`**），改用自己的临时输出目录手动跑一遍 godot 即可（见下面踩坑第 4 条）。

## 弯路 / 踩坑（三段式）
- **试过**：直接 `https://pvz-dlc-edition.fandom.com/wiki/Pult-shroom?action=raw` 取单页。
- **因为**：403 Forbidden（`?action=raw` 只对总表那页放行，单页被挡）。
- **结论**：走 MediaWiki API `api.php?action=parse&page=Pult-shroom&prop=wikitext&format=json`；先用 `list=search` 确认页面标题大小写（`Pult-shroom`，不是 `PultShroom`）。
- **试过**：按「idle 第 0 帧的部件位置 + PNG 尺寸」算包围盒，得高 30.5 px，据此取 `position.y = -56.3`。
- **因为**：探针量出的运行期内容是 56×40，底边比小喷菇低 5.8 px —— `PultShroom_eyes` 这张部件在场景里**没有 texture**，贴图由动画的 `texture` 轨道在运行期塞进去（40×28 @ `(25,45.6)` 缩放 0.6，正好多出 9.5 px）。
- **结论**：量包围盒要**以运行期 `AnimationFrameUtil.get_content_rect()` 为准**（探针里量），静态算只当预估；摆放改成 `-62.1` 后底边与小喷菇差 0.03 px。
- **试过**：在子弹场景的**根节点**写 `parabola_height = -260`（照本体 `bullet_cabbage.tscn` 的写法）。
- **因为**：探针报 `-300` —— `parabola_height` 是 `MovementComponent` 的字段，不是子弹根的字段；写在根上等于无效赋值（引擎只警告）。本体卷心菜 / 玉米 / 西瓜 / 黄油 / 冰西瓜 / 篮球那几张卡**全是这么写的**，实际一直吃 `bullet_parabola_base.tscn` 的 `-300`（属存量 bug，本次不改本体）。
- **结论**：覆盖 `[node name="MovementComponent" parent="." index="4"]` 再写高度；探针直接断言 `MovementComponent.parabola_height`。改导出字段名时务必全仓搜 `.tscn`（与国王仙人掌那条记录里的旧坑同源）。
- **踩过**：`run_autopilot.ps1` 在用户开着 Godot（编辑器 / 游戏窗口）时直接 `result=STALE_PROCESS` 退出。
- **因为**：脚本的防陈旧输出检查是「有任何 godot 进程就拒绝跑」，`-UsrDir` 也绕不过（检查在参数解析之前）。
- **结论**：**不要 `-KillStale`、不要 `Stop-Process *godot*`**（可能是用户未保存的工作）。用独立目录手跑一遍等价命令即可：
  ```powershell
  $tmp = Join-Path $env:TEMP 'pvz_ap_x'; New-Item -ItemType Directory -Force -Path $tmp | Out-Null
  $old = $env:APPDATA; $env:APPDATA = Join-Path $tmp 'userdir'   # 先建目录
  cmd.exe /c '"C:\Users\a a\Desktop\godot.exe" --headless --path "C:\Users\a a\Desktop\Dream" -- --scenario=res://test/scenarios/probe_dlc_pultshroom.gd --autopilot-max-seconds=180 > "out.txt" 2> "err.txt"'
  $env:APPDATA = $old
  ```
- **试过**：投手沿用 `IsActivateLane = true`（本行）。
- **因为**：抛射子弹的命中同样吃行属性，投手本来就只打本行，wiki 射程也写「1×6」；不用像八方向散射那样关掉。
- **结论**：行属性照留 `true`，射程靠检测框宽度（456 px）限制，检测组件也保持 `is_lane = true`。

## 推荐度与理由
推荐。第二株几乎是把国王仙人掌的「场景 + 脚本 + 配方 + 探针」四件套换个动画与攻击方式，**本体零改动**；唯一的新知识是「抛射子弹要传 `Enemy` / `EnemyGloPos`」与「抛物线高度写在移动组件上」。
后来者注意：① 蘑菇类别忘 `is_sleep_in_day` + 睡眠信号换姿势（否则白天照打）；② 换色变体（`*C1`）只挑一套；③ 摆放位置**必须让探针量运行期内容**，静态包围盒会漏掉靠 `texture` 轨道画出来的部件。
