# 2026-10-14 · 新增内容 · 矿石桶僵尸也能在选卡界面里选到（ZombieRuntimeKit）

> **任务类型**：新增内容
> **推荐度**：**推荐**（「热注册的僵尸 / 植物想进选卡界面」照这个走）
> **耗时与成本**：约 1 轮对话，未开游戏（跑了 `probe_more_armor_mod` / `probe_bowling_debug_mode` /
> `probe_card_slot_conveyor` / `probe_almanac_extra_page` / `probe_water_bowl` + 编译门禁）
> **验证方式**：免验证 + 已给人工验证方法（无头只验到「卡片装好 / 卡面画出来 / 能造卡」，没真放一只）
> **补充自**：无

## 目标

让模组「更多的防具」那三只（铜桶 / 钻石桶 / 下界合金桶）能在**调试模式的选卡界面**里被选到。

## 步骤

1. 查链路：僵尸候选卡页只在 `GlobalGameState.is_zombie_card_enabled()`（总开关 or 控制台
   「调试模式」）时生成；待选区只点亮 `curr_zombie`（已解锁名单）里有**卡位**的僵尸。
   ⇒ 差两件事：**插一张卡** + **进已解锁名单**。
2. 新增本体侧 `src/entities/character/zombie/zombie_runtime_kit.gd`（`ZombieRuntimeKit`，
   与已有 `PlantRuntimeKit` 对称）：插卡 + 取卡面 + 进已解锁名单，卸时反向全撤。
3. `more_armor_mod.gd`：`_register()` 成功后给每只装一张卡；`on_level_para_ready()` 每局补一次解锁；
   `uninstall()` 先摘卡再注销僵尸。
4. 修 `AllCards.get_template()` / `is_battle_card()`：不再拿 `ResourceCardReference.is_valid()`
   当判据（它只认内置角色），改判「模板登记了没有」。
5. 探针补 5 条断言（卡位 / 解锁 / 卡面 / 造卡 / 卸载后撤干净）+ 修一条过期断言
   （`probe_bowling_debug_mode` 里「僵王单开第 4 页」的旧口径）。

## 关键决策与理由

- **Kit 放本体而不是模组里**：`PlantRuntimeKit` 早就是这个写法（"以前全写在模组里，每只新植物
  重踩一遍坑"），僵尸侧对称补一个，模组只填一句 `kit.install(zombie_type)`。
- **卡面必须让僵尸先活一次**：热注册僵尸 = 本体场景 + 脚本，桶的贴图是脚本在
  `build_runtime_parts()` 里换的。`AnimationFrameUtil.create_frame_node()` 会先剥脚本 ⇒
  取回来永远是本体那张铁桶脸。所以走 `CharacterShowFactory.create_show_zombie()` 让它进树
  走 `ready_show()`，再摘它身上那棵 `Body`（与内置卡面「`CharacterStatic → ZombieXXX → Body`」同口径）。
- **取形象推迟到帧末**：`install()` 多半在某个 `_ready()`（如 `ModManager`）里被调，那一刻
  `tree.root` 正忙着布置子节点，`add_child()` 会被拒（与植物 Kit 同一个坑）。
- **解锁要每局补**：读档会照存档重建 `curr_zombie`；`install_to_main_game()` 太晚
  （`card_manager.init_manager()` 已经把卡槽建好了），只能放在 `on_level_para_ready()`
  （`MainGameManager._ready()` 里，排在 `init_manager()` 之前）。
- **摘卡要在注销僵尸之前**：`AllCards.rebuild()` 要按类型查冷却与阳光。

## 踩坑

1. **★ `ResourceCardReference.is_valid()` 只认内置角色**（`PlantIds.ALL` / `ZombieIds.ALL`），
   运行期热注册的一律不算 —— 插了卡、`AllCards.create_card()` 照样返回 null
   （现象：卡位有了、卡面画了，一造卡就「无法创建未注册的卡牌」）。
   **正解**：卡片能不能用由 `AllCards`（模板目录）自己判，不拿 `is_valid()` 当判据。
   副作用：顺手修好了运行期植物（水盆）在图鉴扩展页造卡那条路。
2. **卡面取错对象 = 三张卡长得一模一样**：从**场景**取帧拿到的一定是铁桶；必须从**实例**身上取。
3. **协程不 await 的老坑复现**（同 2026-10-14 那条）：探针里新增的 `_check_cards()` 有 `await`，
   调用处写 `await`。
4. **无头探针共用同一个临时 userdir**（`C:\Users\a a\AppData\Local\Temp\pvz_autopilot\userdir`），
   存档 / 模组开关在多次运行之间**会留下来** ⇒ 某些探针（如 `probe_card_lock`）的失败条数与
   运行历史有关，判「是不是自己改坏的」要**同一条命令连跑两次**对比，不要只看一次。
5. `run_autopilot.ps1` 默认 Godot 路径失效，必须 `-Godot "C:\Users\a a\Desktop\godot.exe"`。

## 给后来者的最简路径

1. 热注册一只僵尸 → `ZombieRuntimeKit.new().install(zombie_type)`（植物用 `PlantRuntimeKit`）。
2. 每局在 `ModBase.on_level_para_ready()` 里 `kit.unlock()`；关模组时 `kit.uninstall()`
   （**在注销角色之前**）。
3. 想选到它：控制台 → 调试 → 打开「调试模式」（僵尸卡页的总开关默认关）。
4. 收尾：门禁 + `probe_more_armor_mod`（铜桶那批）+ `probe_bowling_debug_mode`（僵尸卡页）。

## 人工验证方法（本次未开游戏）

1. 主菜单 → 选项 → 控制台 → 调试 → 打开「调试模式」；确认模组「更多的防具」已启用。
2. 进任意关卡到选卡界面，翻到僵尸那一页：**铜桶 / 钻石桶 / 下界合金桶**三张卡都在，
   卡面是各自那只僵尸（铜色 / 钻色 / 合金色，不是铁桶）。
3. 选一张铜桶 → 开战 → 点草坪放下去：走出来的是戴铜桶的僵尸（等一会儿桶会变绿 = 氧化）。
4. 关掉「更多的防具」模组再进一次：僵尸页里这三张卡消失；关掉调试模式：整页僵尸卡消失。
