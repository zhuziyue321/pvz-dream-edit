## 0. 一句话概括

> **一个 Godot 4 的《植物大战僵尸》复刻工程：`src/` 是唯一代码根，按功能就近放置；架构主线是「数据驱动 + 组件化」——主场景只有一份，地图/格子/僵尸行/波次全部由 `ResourceMapData` + `ResourceLevelData` 在运行时装配；角色 = base 场景 + 若干 `ComponentNormBase` 组件，状态本体在组件里，宿主只转发。**

### 4.5 生命周期约定（硬约束 §1-3）

**禁止子类重写 `_ready()`**。角色基类 `Character000Base._ready()` 按 `@export character_init_type` 三选一分发：

```
Character000Base._ready()
├── E_CharacterInitType.IsNorm   → ready_norm() → ready_norm_signal_connect()
├── E_CharacterInitType.IsShow   → ready_show()   （图鉴/预览/种子包：禁用 HurtBox、产阳光、攻击）
└── E_CharacterInitType.IsGarden → ready_garden() （花园：禁用 HurtBox，交 GardenComponent）
```

`init_plant()` / `init_zombie()` **必须在 `add_child` 之前调用**——参数决定 `_ready` 走哪条分支。

**通信（4 条路径）**：

1. `owner` 反查角色（组件是子节点，`owner` 即角色）
2. 基类集中接线：`ready_norm_signal_connect()` 里把 `signal_update_speed` → 各组件 `owner_update_speed`；`hp.signal_hp_component_death` → 攻击/移动组件禁用 + 掉落
3. 组件间信号：`DetectComponent.signal_can_attack` → `AttackComponentBase.update_is_attack_factors` → `signal_change_is_attack`
4. 全局总线：魅惑不再切碰撞层，改由 `EventBus.push_event("character_be_hypno")` 广播，全场 `DetectComponent` 重判敌我
5. **要往「宿主那一层」挂东西就问宿主**：水花 / 尸块 / 掉落物这类不属于角色子树、但必须共享同一坐标系的节点，一律 `owner.get_sibling_layer()`（`Character000Base` 提供），**不要** `owner.get_parent()`

> **为什么第 5 条存在**：`owner.get_parent()` 等于让组件知道「宿主挂在谁下面」。宿主一旦被临时换容器，这些特效就会挂错地方、坐标全偏。由宿主自己回答它属于哪一层，宿主结构变化只需改 `get_sibling_layer()` 一处。
>
> **例外**：`src/fx/bullet_effect/bullet_effect_base.gd` 的 `owner` 是**子弹**（`Bullet000Base extends Node2D`），与 `Character000Base` 无继承关系，仍走 `owner.get_parent()`——不是漏改，改了会运行期报 `Nonexistent function`。
